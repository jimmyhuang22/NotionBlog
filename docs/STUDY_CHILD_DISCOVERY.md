# 学习子目录的有界变化发现

补齐“父页时间戳未变，深层新子页没有事件”的发现入口。已有直接来源发现负责新课程，已知页元数据轮巡负责页自身属性变化；本模块检查已发布学习父页的即时物理子目录，生成提示给已有学习变化引擎。它不发布、不授权新页，也不根据缺失推断删除。

## 运行器接法

```ts
const result = await runStudyChildDiscovery({
  queue, store: studyCheckpoint, config, sourceKey,
  source: (checkpoint, signal) => createWebsiteStudyChangeSource({
    config, client: createBudgetedReader(signal),
  }),
  signal, maxParents: 20, maxChildren: 2000, maxDurationMs: 30000,
});
```

`sourceKey` 分别使用当前配置中的课程或自动笔记来源键，queue 已配置对应键，学习检查点来自[已验证完整基线](STUDY_BASELINE.md)及后续独立 reader 确认的增量安装。主运行器持有 canonical 互斥；来源、检查点、queue 和配置摘要须一致。课程来源为 `all`，对应笔记为 `course-descendants`；旧单课配置不能沿用此轮巡。

每批重建 `StudyChangeSource` 的操作会话，使用 `document:false, children:true`。既有所属关系解析器检查父链、实际拥有的子页／数据库记录、中央 deny 和祖先资格；链接、提及、关联及引用的同步块不自动纳入。为寻找子页面必须读取父页的块列表，但不映射父页 AST、不读子页正文、不注册或下载图片。源端口必须让实际 HTTP 请求响应 signal，并沿用请求、字节和时间预算；逻辑父页数不是 HTTP 请求数。

默认每批 20 个父页，显式最多 50；子目录结果合计默认 2,000 项、最多 20,000；默认 30 秒，显式最多 120 秒。超限或超时明确停止，不扩大预算、不启动整库采集或图片验证。定时频率与实际安装由主运行器方案决定，本模块不安装排程。

## 发现规则

- 即时孩子成员、子页编辑版本或正文中的兄弟顺序变化，给父页发 `relation`。父页时间戳相同也会检查。课程目录第一层由日期／数字覆盖决定，因此不把来源枚举顺序误当第一层重排；数字属性变化仍产生元数据提示。
- 父页自身元数据／拥有关系变化，给原已发布页发 `properties`。发现不读取新子页正文；增量引擎收到父页提示后，重新检查当前来源并准备新节点、移入／移出和排序依赖。
- 明确归档、范围移出或中央 deny，仅发 `reconcile`；领域引擎分别确认来源撤回或政策处理。未知读取失败同样仅发重新核对，并计入 `unavailable`，不返回旧数据当成功、不改缓存图、不转成删除。
- 单个父页不可读时可继续轮巡其他已知父页，避免一页长期未知阻塞全来源。配置错误、坏响应、坏游标、基线／scope 变化、预算或取消停止本批；主运行器应展示 unavailable 数及待核队列，不能把轮巡完成当成全部页面可读／已发布。

## 重启、去重与同步互斥

控制游标使用当前来源下排序后的 ID 的 `afterKey`。其他栏目的发布版本变化不会从第一项重来；新增在游标之前的页面下一圈检查。目录只来自已验证学习检查点，任意 webhook ID 不能进入轮巡。

公共 queue 的独立 `study-children-v1` checkpoint 保存轮巡位置，与 `discoveryState`／直接来源成员目录分离。按当前来源的目录 slot 保存 ID 与变化摘要，slot 范围受完整学习图 20,000 节点上限约束；旧 slot 由新成员复用，不按无限历史页面身份新增 checkpoint 名称。摘要同时绑定观察和已验证缓存中的元数据／子目录，防止某个来源状态以前出现过、后来发布了不同内容而漏掉重新核对。无变化不重写 slot。

每个变化摘要和提示在 `queue.commitDiscovery` 的同一事务落盘。提示身份包含该 slot 的持久 revision；重复看到同一待处理变化不会反复增加代次，发生 A→B→A 等后续变化仍可入队。只保存摘要和私有 ID，不保存 Notion 属性值、块正文或图片地址。

本批来源读取完成后重新检查完整本机基线及控制游标，再同步提交 slot 和总游标。中途某 slot 发生 CAS 冲突时，总游标保持原位；前面已原子提交的提示在重试时去重。取消／超时的迟到结果不能提交。本模块没有 SQL publisher 或 queue ack 路径；公共运行器仍按独立回读、领域 finalize 后再 ack。

## 已验证范围

合成源和实际 SQLite 验证父时间戳未变的新深页、物理移动、消失／重排、第一层排序、恢复游标、重复提示、其他栏目版本接续、缓存改变后的重新提示、未知父页、归档／deny、坏输入、预算／基线竞态、取消／迟到结果及 slot 冲突恢复。实际本机 PGlite 完整发布、公共 queue／executor／coordinator、学习引擎和独立 reader 验证从父页提示到新子页原子发布及检查点安装。

没有访问真实 Notion、下载图片、连接云库、改现有单课发布窗口、安装轮巡、发布 main 或部署。线上启用仍需主运行器与真实完整基线、媒体端口共同验收。
