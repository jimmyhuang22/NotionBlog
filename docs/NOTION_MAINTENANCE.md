## 资料口径

- 游戏发行日采用本作品／所记版本在主流媒体或已有发行方资料中列出的日期，处理明显的原作、重制、加强版差异；没有媒体日时可用同一软件官方日作有来源的参考。试玩、测试和抢先体验注明阶段，不逐项追查全球最早地区及时区边界。
- 影视发行日保留原始首映、首次公开放映或原始开播口径；公共评分对应具体作品和季别，记录实际来源，不拿全剧、合辑或历史转载评分代填。
- 书籍页数按同一 ISBN／版次的可靠书目维护，出版日期保留来源精度。正文已读而附录未计时，阅读状态与实际已读页数保持。
- 个人评分、状态、体验日期、心得和拥有平台由用户维护。游戏个人 `Date` 与 `Year` 公式不随资料发行日调整，支持平台也不证明个人拥有。
- 未知资料保留空值；修改追加来源、核对日期及说明，历史备注与富文本保持。相同标题不能单独作为合并依据，不同版本和有个人记录冲突的页面分别保留。

字段定义与视图规则见 [作品库字段说明](MEDIA_LIBRARY_SCHEMA.md)。

## 日常维护顺序

1. 读取最新私有交接与上次成功回执，核对来源、绑定、排除和当前工作是否有并发执行者。
2. 检查新增及明显变化的条目，生成小批计划；没有变化时记录检查结果并结束本轮维护。
3. 给资料空项采用可读的主流媒体、发行方或可靠书目依据，明确版本与来源。少数仍无依据的项保持待核，有新资料再补。
4. 写入前保存候选页属性与正文，检查原值和关联身份；只处理计划里的字段，保留个人记录及已有历史。
5. 回读实际写入、正文和未授权改动的字段。平台分钟变化时，同时核对平台小时及 Game 汇总公式，不把预期的派生变化误判为个人字段被修改。
6. 保存计划、回执、失败记录与交接结论；通用口径写项目文档，真实作品和配置留私有目录。

## 验证范围与执行时间

- 普通账户同步直接使用已安装入口，执行采集、差异计划、必要写入和程序自带回读；没有变化就零写入结束。保留身份、隐私、冲突和汇总检查，不再额外导出全库、重复回放验收、运行工程测试或构建，也不重装运行版本。
- 少量资料修改只保存和回读候选页、修改字段及受影响关联，检查个人记录保持；已有待核项没有新依据时不重复调查。游戏发行日沿用上面的主流媒体口径，不追加精确日期考证。
- 程序改动按影响范围做必要测试，最终代码集中执行一次规定的 `npm run check` 与 `npm run build`。只有新代码变化、失败或尚未解决的疑点需要重测；代码未变的后续文档补充复用已有工程验证结果。
- 纯文档更新检查链接、差异和提交隐私，不重复测试与构建。平台自动 CI 仍按仓库配置运行。
- 已安装 PSN／Nintendo 每日流程本次实测约 40 秒，这是一次运行观测，不是固定耗时承诺。普通维护以秒至数分钟的短流程执行；遇到接口限流、登录失效或失败，说明原因并处理，不扩展成无关工程任务。

`核查状态=已确认` 只表示已登记问题处理完成；空状态为未分类。平台的“无需关联”与自动 `Sync Status=Excluded` 分开，不能据此删除、归档或把试玩／服务时长并入正式游戏。

## 账户同步的当前能力

手动三平台 `collect → dry-run → apply → 回读` 已在 Mac mini 实际验证，使用独立 Notion writer；网站连接继续只读。账户隐私和产品身份仍是每次运行的前提。Steam 需要一小时内的独立完整名单核验，新确认必须来自当次实际检查；PSN／Nintendo 按采集到的隐私及身份信息放行，未知条目留本地。

后续明确选择取代本环境的 Steam 人工限制：采用账户绑定的固定允许／排除名单，将 Steam 加入已有每日任务，排除与未知产品继续保留。无需每次确认名单，但用户后续在 Steam 改隐藏／私人标记时，必须同时更新同步名单；这不是实时隐私读取。未启用固定模式的环境仍按上段执行，见 [决策](decisions/2026-10-12-steam-daily-allowlist.md)。

**正式 CLI 已加入增量计划和写后回读。** 实际资料没变时保持零写入；有变化才写对应字段及采集时间，单纯的采集／源更新时间刷新不触发更新。apply 重新核对 Notion 状态和保存的精确计划，检测人工改动、重复键及关联冲突；失败回执保留已完成项与待确认请求，重新规划后只处理剩余差异。

Nintendo 的新实际采集经正式 dry-run／apply，120 条均无变化，零写入验收通过。随后正式入口实际更新 2 条 Steam 记录，其中一条累计分钟增加 60，回读和独立全库核对通过；其余 340 条平台记录、全部 Game 个人属性及 4 个候选页正文保持。故障路径继续由工程测试和真实属性快照回放验证。

每日入口在一个目录锁内串行执行 PSN、Nintendo、固定名单模式的 Steam，失败保存阶段并尝试本机通知。Mac mini 沿用唯一已注册任务，默认本地时间 09:00；更新后的固定代码经 launchd 手动触发三平台九阶段，58.24 秒完成、退出 0，Steam 两条差异回读通过，其余平台无变化。首个日历触发尚待观察，具体路径与回执留在私有交接。现有命令、身份与凭据说明见 [游戏账户同步](GAME_ACCOUNT_SYNC.md)。
