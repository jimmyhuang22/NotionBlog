# 维护回传适配器的安装与有限验收

本项是[独立维护适配器](OPERATOR_SQL_EGRESS.md)的准备方案，代码审阅和安装分别验收。实际私有文件、固定摘要、目标及回退材料保存在忽略目录；提交本说明不授权切换运行包、恢复来源或执行云查询。

## 安装前提

- 固定已审源码、独立运行副本和新缓存命名空间。核对实际 reader／writer、原 TLS、查询超时及原周期限制，不从开发工作树动态加载代码。
- 来源主流程、验收和正文小图后置均属于同一最新成功运行；连接关闭、原锁释放，未决请求、未知写入和已确认但未回读的写入均为空。运行中保留旧成功字段不能当作本轮完成。
- 原失败或暂停尚未处理时停止；维护窗口不足时等待下一窗口。不删除旧暂停标记、不改旧失败、不重放来源。并行验收负责人须明确交回冻结输入，短暂没有锁不等于已经交回。
- 安装前重新核对全部实际冻结输入及将替换文件的摘要。任何变动使旧计划失效，先重建受影响候选与回退，不能直接重跑历史安装入口或复用历史批准。

## 本次候选范围

四个现有维护入口仅改向新独立 helper；七份冻结源码与 helper／绑定使用新私有运行目录。保留原运行副本和旧缓存。

分别更新正文维护清单、主程序清单及本次授权绑定。来源成功后的缓存唤起也绑定主清单摘要，因此需同步准备该绑定的新前像／后像；驱动、唤起代码和独立消费者本身保持。新待批准授权必须是关闭状态，历史授权不自动覆盖新源码。

实际切换时再次核对原状态，在独占维护窗口保护下安装并验证全部摘要及有限本机入口。中间失败在仍持有保护时按相反顺序恢复本次前像；只释放自身创建的暂停标记和锁。回退不删除历史账本或缓存，不将回退理解为重新执行成功周期。

## 流量与观察边界

单周期四个已接入维护阶段继续共用原不可变预算：最多 2,000 次查询、64 MiB 响应信封、单次最多 8 MiB；原截止时间、查询超时、写入前检查和未知结果停止规则保持。缓存最多 128 MiB／1,024 项、单项 8 MiB。

建议新批准窗口最多观察两个原定自然周期：首轮填充与后一轮复用，维护响应信封累计上限 128 MiB；不人为补跑来源。记录各周期计划、实际共享账本、阶段与整轮结果，区分首次填充和后续复用。旧接口没有保存每查询的命中指标时，不反推或编造命中率。

这些数值不是额外增加的正常业务预算，也不是全账号硬上限；认证、TLS、核心采集发布、其他客户端与正式网站读取仍独立计量。没有通过安装新增数据库对象、权限、图片下载、账号迁移或网站部署。

## 完成标准

实际安装摘要、授权和唤起绑定匹配；每轮原资格／完整性／登记独立回读通过，响应账本无未结清请求；独立消费者继续按原任务处理刷新。自然周期失败或字节超限保留原自动暂停及回执，交回负责人处理，不自动扩大额度或重复采集。

离线候选检查只能证明接线、限制和回退输入一致，不能替代以上自然运行证据，也不能据此宣布历史账号用量已全部归因或解决。
