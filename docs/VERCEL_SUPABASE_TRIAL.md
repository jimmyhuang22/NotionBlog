# Vercel + Supabase 首阶段联调准备

记录日期：2026-10-11。状态：优先试验路线与实施顺序记录，云端联调尚未执行。

用户倾向先跑通 Vercel 与 Supabase，遇到访问、费用或功能需求后再评估迁移。本文件把这个方向具体化，保留中国内地与海外访问目标，以及现有内容公开与私有数据边界。账户、项目、区域、凭据与同步运行位置仍需落实；本轮未操作云账户或改变现有 provider。

## 可迁移的实现边界

- 网站保留同一个 Next.js + TypeScript 工程与现有统一内容入口。Vercel 承担运行与部署；业务规则放在仓库内的服务端代码，沿用 contracts/ DTO。
- 数据库采用标准 PostgreSQL 表、关系、索引和事务，建表变更保存为 SQL migrations。平台特有角色、权限及扩展须与业务表分开记录，迁移时在目标环境适配。
- 图片采用独立存储适配器，数据库记录内部资产标识、对象键和所属公开页。前端继续消费站内媒体路径，避免把供应商完整 URL 固化到正文 AST 和页面代码中。
- Notion／其他来源同步保持独立 TypeScript 任务，具有可手动执行的入口。调度器与任务本身分离，之后可迁往本地设备或云主机，不要求重写内容转换与发布规则。
- 当前没有访客登录、实时订阅或独立云函数业务需求，首阶段围绕内容数据库、文件存储和既有服务端开展。将来增加相关功能时再评估其平台依赖。

Supabase 提供完整 PostgreSQL，并有数据库导出／恢复及文件迁移说明。数据库可迁移不代表自动迁移整个平台；权限、角色、对象文件和服务设置分别处理。[数据库说明](https://supabase.com/docs/guides/database/overview)、[导出恢复与文件迁移](https://supabase.com/docs/guides/platform/migrating-within-supabase/backup-restore)。本机安装的 Next.js 部署指南也支持 Node.js 服务及 Docker，迁离 Vercel 有标准运行路径。

## 小范围联调顺序与通过条件

| 阶段 | 准备／实施内容 | 通过条件 |
| --- | --- | --- |
| 连接验证 | 免费试验环境、服务端私有凭据、标准业务表、虚构记录与小图片；网站和数据库尽量选靠近的运行区域 | Vercel 服务端能读取记录，站内媒体能访问；浏览器与部署产物无秘密；数据库匿名权限不越界 |
| 内容验证 | 复用 Notion 转换逻辑，为已批准的小样本做手动同步，增加数据库 provider，保留课程与后代层级 | 页面／API 契约一致，缺失值、正文、图片与父链正确，重跑不重复写入，失败不静默回退 |
| 发布验证 | 明确并实现同步后的更新、撤回和立即下架语义，完成任务状态、重试与互斥 | 未批准内容不进入访问结果；删除、归档、范围变更及媒体资格符合已选择规则；半批失败不发布不完整版本 |
| 搬迁验证 | 导出业务 schema／数据，在独立普通 PostgreSQL 中恢复；独立导出及核对图片清单 | 数量、关系、内容摘要与媒体校验一致；同一应用能读恢复后的数据，确认实际需适配的权限和平台设置 |
| 云端预览 | 使用独立预览地址验证网站、API、图片与同步运行路径 | 记录性能、用量及国内外访问证据，之后再扩大同步及安排正式域名 |

首阶段从小范围开始，不要求同时补完全部栏目、后台编辑器、多租户平台或双地域部署。同步运行位置还未选择，内地设备与上游 API 的跨境路径仍需测试。云端试验与正式上线、域名切换分别记录。

## 以后迁移实际包含什么

网站迁移主要是运行环境、构建、服务端变量与流量入口的调整。数据库需要检查目标 PostgreSQL 版本、角色、权限、扩展和连接池，导出业务数据后恢复并校验。图片文件需搬迁对象内容及对象键映射，不能只迁数据库中的文件元数据。同步任务需迁移调度与私有凭据，避免新旧任务同时写入。

切换前要暂停或协调写入，处理最后一批变更，验证新站，再切换域名；保留可用旧环境作为回滚路径。数据量大或需要无停机切换时成本会增加，本阶段不承诺耗时或零中断。

Supabase 官方明确数据库备份不包含 Storage API 中的实际文件；免费套餐建议自行导出并保留异地备份。[备份边界](https://supabase.com/docs/guides/platform/backups)。因此应把数据库和图片的导出恢复一起纳入验证，不能等迁移时才发现文件无法取回。

## 当前工程与下一项

现有工程只有 mock／notion provider，尚无数据库 provider、持久同步、Supabase 配置或云端联调证据。已具备统一 DTO、Notion 读取转换和媒体边界，可作为新增适配器的基础。当前前端由其他工作推进，本轮没有修改前端、接口、Token、来源名单或运行服务。

下一项是落实免费试验账户／项目与私有连接配置，按上述顺序完成虚构数据的云端连接，再完成批准内容的同步、媒体、发布和迁移验证。国内可用性仍按照 [部署访问要求](DEPLOYMENT_OPTIONS.md) 实测；先选海外免费方案不取消这个长期目标。
