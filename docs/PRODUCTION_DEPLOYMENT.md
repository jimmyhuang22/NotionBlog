## 当前目标与边界

- **新加坡 Oracle 为默认生产目标**，使用 Linux ARM64；main 是正式源码来源。Git 合并、构建通过和主机实际安装是三个不同状态，正式发布逐次授权。
- **AWS 保留，不再更新、不删除**。不得因 main 合并自动上传 AWS；保留服务器不等于其内容数据持续与新加坡一致。恢复 AWS 流量、停止实例、删除磁盘或地址都需后续明确授权。
- 新加坡正式域名已完成切换。旧预览公网入口已退役，内容导出仍依赖旧预览的本机服务定义和配置。带 candidate 字样的现役服务承接正式流量。详见[旧预览退役记录](progress/2026-11-13-retire-singapore-preview-hostname.md)。
- 当前数据库页面为 `legacy`，媒体为 `display-only`，存储为 `private-disk`，内容读取为 `published/scoped`，共享内容缓存关闭。不得照搬旧 AWS 的双 legacy、云端媒体、Nginx 端口或凭据。
- 网站 release 与私人采集／游戏／交付程序分开。网站更新不覆盖私人运行修复、不执行采集、不调整调度，也不恢复旧 Mac／东京写入流程。

## 下一次获准发布的顺序

1. 读本页、当前私人交接及用户当次范围，确认目标是新加坡正式服务；核对 main 提交、受检树、现役版本、架构、配置摘要与已验证的新加坡回退 release。
2. 先处理已知 profile 兼容差异；在匹配 Linux ARM64 的环境按双锁文件准备公开网站产物，不读取真实凭据，不把 AWS amd64 包或 Mac 原生依赖当作可用产物。
3. 仅安装网站到独立 release，保留现役配置、数据库、展示媒体、私人同步程序和现有 Tunnel 路由。已有 DNS／TLS／Access／防火墙不随版本发布重设。
4. 获准切换后检查专用启动入口、服务状态和错误日志，再从正式 HTTPS 入口验证页面、渲染、安全头、显示媒体及关闭栏目 404。共享缓存关闭时，不把 tagged-v1 专属首页预热日志当作必需项。
5. 对用户要求的视觉项目在实际正式入口验收并保存证据；其他主机通过记录不能代替。字体切片数量仅为估计，按请求成功和实际显示判断。
6. 失败按当次授权回退并停止；未授权不得补改线上配置再试。普通代码回退不恢复数据库快照或改变采集方向，AWS DNS 回退须另外确认范围。

没有当次发布授权时，只做文档、构建准备或获准的只读检查，不因为此流程存在就执行切换。
