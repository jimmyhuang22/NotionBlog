# 作品库字段说明

本说明记录既有 Notion 作品来源的字段整理约定，不包含真实来源编号、个人目录或正文。来源映射仍保存于私有配置，前端继续消费统一 DTO。已完成结果、剩余待核项与日常流程见 [Notion 数据库维护与交接](NOTION_MAINTENANCE.md)。

## 共用规则

作品身份、版本和外部资料独立于个人状态、日期、评分、进度和心得。`Edition`、`Metadata Checked At`、`Review Notes` 分别保存版本说明、实际核对日期和尚未解决的问题；游戏与影视使用 `Metadata URL` 保存核对依据，书籍保留原书目链接。

独立选择属性 `核查状态` 记录已登记问题的处理进度。作品库使用“待核查／已确认”；“已确认”只说明现有核查问题已结案，不表示每个字段完整或个人实书印次已证明。空值表示未登记，不自动判为已确认。历史说明和证据继续保存在 `Review Notes`，不因结案清空。

`Public Rating` 为 0–10 数值，`Rating Source` 说明来源；保留原公共评分文本作历史参考，不填入个人评分。按具体作品和季别读取来源当前评分；更换来源时同步记录来源名称与链接，不把全剧分数代入单季，不拿历史转载分数补填。资料无法读取时，数值保持未知。个人体验状态不是发布开关，整理来源也不自动授予网站公开资格。

| 来源 | 原标题属性 | 封面位置 | 个人记录 |
| --- | --- | --- | --- |
| 游戏 | `Name` | `Cover` 文件属性 | 原 `Status`、`Rating`、`Date`、`Platform`、手工时长与正文 |
| 影视 | `Film Name` | 页面原生封面 | 原 `Status`、`Personal Rating`、`Watching Date` 与正文 |
| 书籍 | `Book Name` | 页面原生封面 | 原 `Status`、`Reading Date`、`Pages Read` 与正文；新增 `Personal Rating` 不代填 |

标题按原富文本读取与修改，不把查询显示的 Markdown 标记当作标题错误。封面按同一作品、年份及版本核对；游戏图片上传为原生文件，影视和书籍沿用页面封面。重复候选和不同版本保留原页，在确认正文和个人记录前不合并。

获准清理时，先私有备份候选页完整属性及嵌套正文，再比较个人状态、日期、评分、版本和心得。确认的重复导入采用标签并集、保留历史说明，并把多余页移入可恢复废纸篓；不同观看意图或个人记录冲突不合并。备份包含媒体引用，不代表备份全部图片字节。私人工具导入不得触发执行入口；已有备份拒绝覆盖，缺失或未完成的基线不能作为完整验证依据。具体作品、来源编号和剩余版本问题只记录于忽略目录。

## 游戏

新增 `Edition`（文本）、`Metadata URL`（URL）、`Metadata Checked At`（日期）、`Review Notes`（文本）。发行日以明确的平台和版本为依据；无法确认地区或版本时保留旧日期并注明原因。不能根据作品支持平台填入用户实际拥有平台，原手工时长单位不明确时不重新解释。

游戏作品页 `Release Date` 按本作品／所记版本维护；用户已明确接受主流游戏媒体列出的发行日期，不逐项追查全球最早地区或时区边界。有已取得的明确版本发行依据时采用该依据，没有媒体日但有同一软件官方发行日时可作带来源的参考。移植平台原日期继续独立保存；只处理明显的原作／重制／加强版混淆，无日期时保持空，不补造日；试玩、测试与抢先体验注明相应阶段。本轮只补空项，已有日期保留。

Steam 已核验属性已迁入独立「平台游玩记录」，并保留旧专用属性作兼容。PSN／Nintendo 同样按账户、平台和产品身份分记录，确认版本后关联 Game；常用 Game 表用 `Playtime Hours` 展示平台汇总小时，真实零优先，无平台数值时才沿用原手填小时。原始平台时间保存分钟，平台发行日独立于原 `Release Date`。拥有、零时长和成就不推导通关状态，隐藏／私人排除规则继续适用。完整字段与后续运行约定见 [游戏账户同步](GAME_ACCOUNT_SYNC.md)。

软件 ID 与商店完整 SKU 分开核对；正式版、好友通行证或合辑共用软件标识时，不能据此推断个人购买版本、DLC 或升级包。未关联条目在原核查备注追加具体分类及依据，保留原始标题、软件平台、产品 ID、账号分钟数和采集时间；缺少已确认个人作品页时不自动新建或关联近似标题。

平台记录的 `核查状态` 使用“已关联／缺作品页／版本待核／无需关联”，与自动管理的 `Sync Status` 分开。“无需关联”用于当前试玩／活动或服务／工具条目，不删除记录、不归档，也不把它们的时间并入正式作品。新条目空值继续进入待匹配视图等待人工分类。

## 影视

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `Record Kind` | Select：Work／Template | 兼容历史作品与模板命名普通页；日常复用原生数据库模板，普通模板页在核对及备份后可恢复归档 |
| `Douban ID` | 文本 | 来源身份和重复核查，保留原作品链接 |
| `Edition` | 文本 | 年份、季别、特别篇、OVA 等版本信息 |
| `Release Year` | Number | 已验证的作品年份；不补造完整发行日期 |
| `Episode Count` | Number | 来源明确的正整数集数，未知为空 |
| `Public Rating`／`Rating Source` | Number／文本 | 外部公共评分及来源 |
| `Metadata URL` | URL | 核对依据 |
| `Metadata Checked At`／`Review Notes` | 日期／文本 | 核对时间与待确认问题 |

原 `Original Name`、`Type`、`Director` 等仅在同一作品身份已确认后修正。`Release Date` 采用可核实的原始首映／首次公开放映或原始开播日期；包含早于院线公映的节展首映，不使用后续地区发行、重映或个人观看日期。校正时在 `Review Notes` 保存原值、事件类型及可读来源；`Release Year` 保留已验证的作品年份，不从它补造完整日期，也不因制作年份与首次放映年份不同自动断言错误。未核实的原值保留并标记复核。演员仍是可选信息。

## 书籍

原 `Auther` 原位重命名为 `Authors`，`Watching Date` 重命名为 `Reading Date`，保留原属性及日期范围。视图跟随重命名，私有来源映射同时更新。

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `ISBN` | 文本 | 通过校验的 ISBN，保留前导零及校验字符 |
| `CN Book Number` | 文本 | 旧版统一书号，不能误填为 ISBN |
| `Edition`／`Publisher`／`Translators` | 文本 | 绑定具体出版版本 |
| `Publication Date` | 文本 | 保留仅年、年月或完整日期等来源精度 |
| `Douban ID` | 文本 | 原书目链接对应的来源身份 |
| `Public Rating`／`Rating Source` | Number／文本 | 外部评分及来源 |
| `Metadata Checked At`／`Review Notes` | 日期／文本 | 核对时间与待确认问题 |
| `Personal Rating` | Select：五星选项 | 仅供用户自己评价 |

总页数按已核验 ISBN／版次修正，已读页数与阅读状态保留。可靠图书馆目录或书目资料与现有 ISBN 一致且支持原页数时，可保留原值结案；其他印次不能代替个人出版日期。不同印次资料不一致或来源未列页数时标记待核查，不能猜测替换。正文已读但附录未计时，保留用户的已读状态与实际页数，不强制把进度改成 100%。

## 视图与后续读取

三库各有“资料与版本”和“待核查”表格；待核查筛选 `核查状态=待核查`，并接收有备注但尚未分类的新条目。已确认的历史备注不再进入工作清单。影视资料表排除 `Record Kind=Template`。原整理表保留所有活动页面便于完整盘点，常用影视画廊显示独立公共评分。

原生影视模板保留既有正文和个人默认值，只补合理的作品类型；不把模板本身加入普通作品列表。常用影视、书籍和相册视图分别命名为“已看”“已读”“相册”，保留既有过滤、分组和封面配置。平台保留总体“待匹配作品”，另设“缺作品页”“版本与范围待核”“试玩与服务”分类视图；自动同步排除项不进入这些工作清单。

课程目录的上课体验、内容实用程度、总体推荐指数、课程难度统一提供 1–5 星；保留已有选项编号、颜色和全部个人评分。前三项星数越高表示评价越高，难度星数越高表示越难，不表示越推荐。

这些变更只整理 Notion 后台。网站内容来源、栏目开关、公开规则及定时同步保持各自现有配置，真实同步和发布分别验收；网站只读凭据不扩展为写入凭据。
