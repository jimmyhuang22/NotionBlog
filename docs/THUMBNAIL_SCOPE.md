# 小图登记与独立验收的显式范围

大于固定试验集合的小图，使用同一份私有范围文件输入[SQL登记](PUBLISHED_THUMBNAIL_REGISTRATION.md)与[独立媒体验收](INDEPENDENT_MEDIA_ACCEPTANCE.md)。只有显式传入 `--thumbnail-scope /absolute/private/scope.json` 才扩展集合；省略时，登记继续最多197候选／197覆盖对象／3,886,392B，独立验收继续最多15MiB新增小图，原计划摘要保持相同。

范围文件使用600权限，只接受四个字段。例如下列虚构集合：

```json
{
  "format": "thumbnail-scope-v1",
  "maxBindings": 500,
  "maxObjects": 420,
  "maxBytes": 33554432
}
```

| 字段 | 计数口径 | 程序硬上限 |
| --- | --- | --- |
| maxBindings | 输入候选的父图／400或800档位引用；历史排除不退回输入额度 | 4,000条 |
| maxObjects | 登记覆盖证明里的全部唯一对象；独立验收选中的唯一小图对象 | 4,000个 |
| maxBytes | 登记覆盖证明里的全部小图字节；独立验收实际新增去重小图字节 | 128MiB |

三个值须为正安全整数；未知、缺失、分数、超上限字段全部拒绝。CLI范围文件最多1KiB；登记的候选文件默认最多1MiB，显式范围下最多4MiB。它仍逐条验证描述、父SHA、owner、当前成员和全部祖先资格，不因多个页面共用同一对象而省掉任何页面检查。

同一范围值纳入两种计划摘要，并在plan输出和运行回执显示。plan后修改、去掉或添加范围，需要重新审阅摘要；旧摘要不能连接数据库或发起对象读取。没有范围时不添加新计划字段，兼容原默认计划。

## 时间、SQL和读取预算

范围文件仅界定小图集合，不增加原图、执行时间、SQL字节、网络许可或公开资格。登记仍为HTTP零、`18 + 3M`次保守SQL、最多8分钟、参数JSON2MiB、结果rows JSON4MiB；独立验收仍为原图最多2GiB、总对象GET数U、`11 + 4N`次SQL、最多45分钟及rows JSON64MiB。输出预算由同一次accepted工件的实际选中集合计算，不把硬上限当作默认额度。

如果实际SQL字节或时长不能满足现有上限，应先修订具体执行方案及必要工程；不能分组重置额度、追加免费verify或延长维护窗口。完整独立验收继续只对对象去重读取一次，所有父图／档位描述在读取前后均核对；不为了每组登记重复读取全站原图。

同一份文件可以在原CLI的plan／register／verify参数末尾增加：

```sh
--thumbnail-scope /absolute/private/scope.json
```

具体执行还需要同批accepted工件、真正独立reader覆盖回执、审阅计划摘要、原canonical锁／writer及云租约交接、活体受限身份／TLS和明确窗口。范围文件不是这些证明，也不授权上传、发布、修改来源、安装运行包、迁移或站点切换。新增来源和新课程封面的候选应从真正工件选择，缓存文件不提供公开资格。
