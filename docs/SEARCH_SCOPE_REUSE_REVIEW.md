# 搜索资格复用：离线分析与候选方案

当前结论：值得准备一个默认关闭、仅针对学习笔记候选的独立实现。它可以消除同一条搜索语句内的重复资格计算；尚未修改应用、迁移、能力摘要或线上开关，也没有新的真实数据库样本。

## 找到的重复工作

现有 [filtered 搜索](../supabase/migrations/20261020003824_filtered_search_candidates.sql)先对选定类型的每条记录调用 `record_eligible`，再做必要条件筛选及正文片段提取。[引用投影](../supabase/migrations/20261017131837_scoped_search_parts.sql)随后解析候选自身地址、内部链接和媒体，又可能对同一记录计算资格。

资格判断包含物理父链与中央 deny，学习笔记越深，重复遍历越贵。本项分析底座已包含游戏日期与影视评分更新；原两请求实测仍只对应当时固定候选，不能当作新版本实测。

私人临时数据库中验证了两个原型：

- 通用版从本语句已经通过资格筛选的候选构建 ID 集合；引用目标或媒体 owner 在该集合中时复用结果，其他目标继续调用原函数。
- 限定版只在候选包含 `study-note` 时采用上述引用投影；其他搜索仍调用原引用投影。原有遍历顺序、必要条件筛选、两万条和字节上限保持。

集合只存在于本语句内。每次请求仍从当前快照重新筛选，链接与媒体仍查当前记录；调用方不能向公开接口传入预先成功的资格集合。内部 helper 必须继续禁止 reader、writer 和普通角色直接执行，最终版本复核及现有游标语义保持。

## 实际离线结果

下表均为虚构内容。计数时仅在临时库包裹资格函数；计时前恢复原函数，避免把计数开销算入收益。

| 样本 | 原资格调用数 | 通用版 | 限定版 |
| --- | ---: | ---: | ---: |
| 300 条平坦记录、30 条候选 | 330 | 300 | 330 |
| 300 条平坦记录、全部为候选 | 600 | 300 | 600 |
| 16 层父链、241 条课程／笔记候选 | 482 | 241 | 241 |

每个版本预热后交替计时九次。在本机内存 PGlite 中，深层样本原版中位数约 298 毫秒，限定版约 140 毫秒；稀疏平坦样本约 13.71／13.91 毫秒，密集平坦样本约 18.38／18.47 毫秒。首轮通用版的稀疏样本曾更慢，增加集合处理并非无条件有益，因此先建议学习笔记限定版。

这些是特定虚构数据的局部耗时，不包含真实连接、网络、托管 PostgreSQL 计划或完整 HTML。它不能解释真实样本剩余读取耗时的全部组成，也不能推出线上耗时减半。本项减少资格计算，候选正文和引用集合的回传规模不因此减少。

最终二十组行为检查通过：两种公开模式、十个查询与三种分页大小的完整结果和游标对照、三条现有搜索路径的对照、学习笔记条件分支的完整分页、课程及中间祖先撤回、候选外链接撤回、媒体 owner 撤回、仅媒体变化且 revision 不变时的旧游标拒绝、最终版本竞争、资格过期／epoch 改变以及受限角色与内部 helper 权限。分页行为用较小的完整父链语料验证，资格调用和计时使用上表独立样本。

原失败记录保留：一次私人脚本的标签字符串语法错误；一次跨记录图片 owner 的虚构样本被原发布门禁拒绝；一次在大型深链语料上穷举单条分页达到本机测试期限。分别修正脚本、恢复合法 owner、拆分计时与完整分页语料后通过，没有放宽发布、分页或退出门禁。

## 建议的正式源码范围

如用户确认，下一项按以下具体范围准备独立候选：

1. 保留原迁移与能力摘要，新建只读扩展与独立能力标识；新 helper 只接收本语句已验证候选，不缓存跨请求正资格。
2. 在现有搜索选项中增加默认关闭的 `filtered-scope` 模式，仅该模式调用新扩展；原 `on-demand`、`filtered`、`precomputed` 保持。新能力只在搜索时检查，不阻断普通课程、首页或目录。
3. 首版只对包含学习笔记的候选复用资格；其他候选调用原投影。沿用原 SQL 行数／字节上限、TS 匹配、完整排序／分页、实时引用资格与末尾版本检查，不提前截取首屏。
4. 增加新能力缺失／摘要错误隔离及上述分页、撤回、权限回归，按应用改动运行一次完整 check／build，准备可审阅 PR。安装方案另外核对当前运行方输入、结构保护、权限和回退，不重写旧冻结文件。

本方案涉及可选搜索入口与数据库能力协议，仍待用户确认后实现。本轮没有安装 SQL、生成预计算、读取真实来源、追加真实查询、启用开关、变更任务状态、合并或部署。完整分页的托管验收和新受限真实读取另定范围，六个已关闭窗口的许可与余量继续不可复用。
