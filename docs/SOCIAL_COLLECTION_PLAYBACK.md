# B站合集的最新一集播放链接

F31后端增加 `PublishedSocialCollection.latestMemberUrl: string | null` 与 `latestMemberLinkVerifiedAt: string | null`，用于作品页与首页的合集入口。现有 `originalUrl` 与 `linkVerifiedAt` 仍表示合集自身地址及其核验，不混用两份证据。单个视频、小红书、冻结v1及采集候选的 `SocialCollectionCard` 不变。

统一SSR入口和 `GET /api/social/works-v2`、`GET /api/home/feed-v2` 返回相同字段。前端对B站合集使用：

```ts
const href = collection.latestMemberUrl ?? collection.originalUrl;
```

两者均为null时不可点；不用标题、日期或猜测的BV号拼链接。卡片样式和交互由Claude接入，后端完成不表示线上卡片已经改跳转。

## 选择与核验

有些合集只有合集采样，没有单独发布的成员记录。因此使用独立成员元数据投影，不能仅把单稿视图连接到成员键。安装并启用后，season按真实 `publishedAt` 降序、发布键升序选当前可公开的第一项；链接与封面成员回退共用该投影。未知日期不猜；无可读且已知日期成员时两个新字段均为null。所选成员未核验链接时也返回null，不跳到较旧但已核验的成员。已知的单稿／作品撤回、来源禁用及合集资格过滤仍生效；合集本身撤回时整张卡片消失。

只接受实际请求并核对账号、合集身份、当前成员及发布时间的 `https://www.bilibili.com/video/BV号/`。不保留查询参数、片段、跟踪值或分P参数；不把合集列表页已检查当成视频已检查。核验时间来自独立链接证据，多P则复用自己已核验播放地址的时间；即使没有独立单稿卡片也能使用。未核验或格式不合规的新地址不交给前端。

season的公开 `latestMemberPublishedAt` 同时采用这次选中成员的真实发布时间，使“最后更新”／作品页年份与打开的成员一致；无可用日期则null，不回填采样时间、发现时间或私有／已撤回成员的日期。多P保留本视频日期。首页仍按原 `activity` 混排，不将发现合集变动的时刻误称发布时间；原始采集卡片与历史记录不改写。

## 更新与分页

独立迁移 `20261018010218_social_collection_playback_links.sql` 新增两张私有表、两个invoker／RLS读取视图，以及受限的待办／完成函数。旧采集payload、审批、统计和v1协议不变。源采样成功写入后自动维护每个合集的一份当前成员元数据；不保存多轮正文或统计快照，也不额外创建单稿卡片。删除成员会清掉对应的链接证据。

核验器是独立的同步后步骤，不把新链接失败写成旧统计采集回滚：

```sh
node scripts/social-sync/collection-playback.ts run /private/path/social-runtime retained
```

沿用既有根目录、cloud.env中的受限worker与锁；每次最多20个配置合集、20个请求／32MiB和两分钟来源工作。只请求当前待核验的新目标，已核验同一BV不重复取；未知日期不请求。首次失败停止，固定错误码留在数据库，汇总写入私有 `collection-playback-latest.json`；后续检查会继续报告既有错误并不重试。诊断后由运维明确清除该目标的failure_code再续接，不能通过重跑清空错误。候选、来源、成员或公开资格在请求中改变时不能登记成功证据。

运维把它接在B站整个同步周期成功、旧上传会话已关闭之后；合并代码不会安装或启用这个步骤。既有源同步把新集加入已批准的合集后，核验器登记新目标，新请求自然切换。固定成员批准与自动跟随仍按各合集既有配置，本功能不代为开启。来源与配置变动、取消和权限失败保持显式失败。

分页摘要包含新播放目标；目标、可读成员日期或公开资格变化会使旧游标失效，前端重读第一页。只刷新统计或相同地址的核验时间不因新字段使游标失效。未引入跨请求数据／资格缓存。

`SOCIAL_PROVIDER=mock` 的虚构合集也带这两个字段，提供虚构标准BV链接和演示核验时间供页面接线；它不是对外部真实视频存在性的证明。原先按平台筛选、总数、排序与首页演示隔离保持。

## 安装与回退

网站增加显式 `SOCIAL_COLLECTION_PLAYBACK=enabled`，默认disabled。先审阅并安装迁移，核对ACL／RLS，执行一次获授权的有界核验，受限reader确认干净地址，再在获授权的正式发布中启用。缺失扩展但显式启用会503，不回退模拟数据。开关关闭时season新链接为null、保留既有日期和列表页回退；多P仍可复用原已核验地址。旧视图和旧运行包不被迁移改写。

需要回退时关闭网站开关／回退网站部署，停止新增的核验步骤；不删除源采样、统计、审批或旧同步调度。迁移安装、首次真实请求、同步后运行接线、云端开关和网站发布均是独立运维动作，代码合并本身不会自动执行。普通本机mock页面可直接测试新字段；旧 `dev:real` 启动器未转发社交环境配置，不能据它启动成功声称此扩展已在真实预览启用。
