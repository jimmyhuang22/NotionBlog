# 社交作品保留与真实采样时间

用户已选择：统计超过刷新周期时仍保留已确认作品卡片与最后成功的数字，标注实际采样时间；新作品与合集新成员仍需审核。本项在现有社交域新增长期展示投影，和旧二十四小时试验资格分开。B 站六小时／小红书二十四小时仅是刷新周期，不再作为作品撤下计时器。

## 数据与读取

迁移新增 `retained_meta`、`retained_publications`、`retained_collections` 及三个 `retained_website_*` 受限视图。新记录默认不批准，不因绑定／采集成功而创建展示记录。操作者核对真实来源摘要、作品关联／类型、合集成员签名与已验证链接后单独批准；真实范围和 SQL 清单只放忽略目录。既有作品批准仍生效，关闭来源或删除源记录撤回其长期投影，重新启用来源不会自动重批。

长期投影只保存已有 DTO 所需的字段，保留平台口径、精确零、未知 null、近似显示和真实 `observedAt`；不复制评论原文、描述、Cookie 或图片／视频。统计失败保留最后成功投影，不改采样时间，不回退 mock。分享地址是此前真实核对过的同作品地址，`linkVerifiedAt` 仍为原证据时间；统计更新不重新生成或假续接链接，原平台仍可能要求登录或链接失效。

每次既有源 ingest 成功后，私有后置触发器只更新已经获准且身份／类型或成员版本一致的投影。新增 BV、CID／完整性变化时原展示快照保持；即使私有采集上传了未经审核的新状态，也不会替换已批准卡片。统计恢复且成员重新匹配时可以更新数字，但保留原已审核活动，不能带入后来删除的未审核成员更新。显式重新审核当前来源摘要／成员版本才接受相应内容活动；合集始终一张稳定卡片。

内部同步函数为触发器专用 `SECURITY DEFINER`：固定 `pg_catalog` 搜索路径、全限定对象、专用 SQL LOGIN／管理员会话及固定触发器上下文检查；所有公开角色、worker、reader 均无直接 EXECUTE。它不插入新名单或将未批准记录设为批准；删除来源或关闭绑定只允许撤回，函数不是 RPC；用于在源 ingest 事务里受控复制投影，worker 未取得投影表 DML 或审批能力。系统使用机器 SQL 身份，不依赖可编辑 JWT metadata 或 Auth 用户身份。

三个新表启用 RLS，reader 只获展示所需列及 invoker 视图 SELECT，无原始合集载荷、审核成员签名／来源摘要或写入权限。旧源表的 RLS／列权限、临时资格、角色、密码及同步协议保持；匿名、authenticated、service_role 和旧网站 reader 无新权限。每条源更新与相应投影更新同事务，损坏输入明确失败。

## 网站切换

`SOCIAL_DISPLAY_MODE=trial` 为默认，沿用原时间线 v2。迁移安装并逐项批准清单后可在服务端选择 `retained`；它不会启用 `SOCIAL_PROVIDER`，也不会自行批准任何记录。仅时间线 v2 和首页 v2 切换，旧单发布 v1 接口保持试验规则。缺迁移、版本不匹配、连接或映射失败返回不可用，不回退其他模式。

长期读取沿用原 DTO、数量／字节限额、同语句混排和成员折叠；以不同快照命名空间生成游标，不能混用试验模式游标。统计年龄本身不修改 DTO 或版本，只有真实数据／批准变化才使旧游标失效。不新增跨请求缓存，不重复逐作品查询已筛选发布。

## 给 Claude 的显示接入

无需更改 DTO：单发布 `publications[].observedAt` 与合集 `collection.observedAt` 已提供真实采样时刻。可用纯函数 `src/lib/content/social-sample-status.ts` 的 `socialSampleStatus(platform, observedAt, now?)` 得到 `{observedAt, nextExpectedAt, overdue}`，B 站六小时、小红书二十四小时到期标为 overdue。该函数不改数字、资格或排序，不用客户端当前时间冒充采样时间。

卡片／平台统计行显示“数据截至……”或等价采样时间；平台之间分别标注，不将多平台统计相加。过期仍显示原数字与时间，未知和近似继续按原样显示。观测时间不是作品发布时间或平台真实更新时间；首次历史成员日期、发现更新和统计采样保持不同语义。视觉和组件由 Claude 接入，本轮后端完成不等于页面标签已上线。

## 验证与运行边界

本地 PostgreSQL 兼容数据库验证过期观测保留、受限 ingest 更新、成员待审与移除后的活动、撤回／关闭／删除、权限、旧试验模式及分页。工程数据为虚构元资料；真实安装、固定清单初始化与独立 reader 回读单独记录。本项不安装刷新调度，不接管浏览器或其他同步服务，不改变 Vercel 环境／main 或部署。接入结果与下一项见[本项进度](progress/2026-10-13-social-retained-projections.md)。

依据：[Supabase 视图安全](https://supabase.com/docs/guides/database/views)、[RLS](https://supabase.com/docs/guides/database/postgres/row-level-security)。
