# 搜索候选预筛

搜索原本每次读取全部合资格条目的搜索资料，再在应用中做匹配。本扩展先用查询的必要条件排除无关记录，减少正文遍历、结果汇总与传输；最终匹配、排序、摘要、总数和游标仍由原应用函数决定。前端与公共 DTO 不变。

## 开启条件

默认继续 `DATABASE_SEARCH_PROJECTION=on-demand`，原 `precomputed` 选项保持独立。新 `filtered` 选项只支持网站 v2 与 `DATABASE_READ_PROJECTION=scoped`，要求安装并登记 [协议清单](../database/search-filtered-protocol.json) 中的独立迁移。能力检查与原三项检查合用一次 SQL，缺失或摘要不符时拒绝服务。

本扩展使用原 on-demand 遍历，不依赖预计算表，不填充、不生成数据，也不安装调度。提交代码不表示数据库已安装、网站已启用或已发布。云端安装、维护兼容审核、配置变更与发布分别按具体授权执行；同步与调度遵守用户最新指令，搜索验证不自行暂停、恢复或改期。

普通课程、目录、首页读取只检查基础读取能力；可选搜索扩展在实际调用该搜索路径时才检查。冷首次搜索仍合并基础与可选校验为一次 SQL；并发搜索共用未完成的能力校验，失败后允许下次重查。成功的能力校验可供基础读取复用，但未完成或失败的搜索校验不阻塞普通读取。若普通读取先预热基础能力，首次可选搜索另做一次合并能力检查；同时冷启动的普通读取和搜索最多各自一次检查。这是隔离可选依赖的取舍，不缓存内容、资格或权限。

后续有界验证使用 `scripts/performance/read-timing-logs.ts` 离线解析器：按安装 CLI 的请求 ID 后缀规则匹配，遍历请求行的 `logs[]`，只输出匹配部署／采样请求的白名单计时。汇总 `message` 不能代表全部日志。未知格式、截断消息和无匹配记录保持无证据，不能另找相近时间行冒充。已结束窗口的原脚本、用量和样本保留，不因解析器修复重开。

## 必要条件与回退

应用为部分不含空格的 ASCII／基础汉字查询生成有界正则。静态 Unicode 表枚举 NFKC 及小写转换的来源字符，并保留一个来源字符展开成多个查询字符的情况。例如全角 Java、数学字母和兼容汉字不能漏掉。表只含公开 Unicode 数据，由 `scripts/generate-search-filter-variants.ts` 生成。

仅 Unicode 版本与默认 locale 都匹配静态表时使用；其他运行环境、不支持的查询、超过十六个字符或完整表达式超过 2 KiB 时直接走原读取。不能为缩短表达式而丢弃某个归一化分支。可能命中或跨过 `Notion page`、`Media`、`Unavailable page` 等替代文字的查询也走原读取，避免原始文本中不存在替代文字而漏结果。长句、组合字符等仍按原完整搜索语义处理。

SQL 只对已经通过原 `record_eligible` 的记录做预筛，仍逐项检查同一快照、来源、中央 deny 和全部祖先。原两万条合资格记录上限在预筛前计数，候选输出仍受 32 MiB 上限约束。候选继续使用原正文遍历、实时内部链接和媒体资格净化，应用保留读取后的版本核对。预筛可能多保留记录；它不决定公开结果，也不新增跨请求内容缓存。

## 本机验证与限制

固定保存资料的原生 PostgreSQL 17.11 回放，单 CPU、4 MiB work_mem，三轮交替读取，实际候选代码的中位如下：

| 查询 | 原 SQL 投影／规范化／摘要 | 候选 SQL 投影／规范化／摘要 | 原／候选投影字节 |
| --- | ---: | ---: | ---: |
| Java | 632.935 ms | 267.351 ms | 7,625,846／1,840,087 |
| 学习 | 632.935 ms | 389.794 ms | 7,625,846／3,266,045 |
| 游戏 | 632.935 ms | 172.908 ms | 7,625,846／528,053 |
| office（完整表达式过大，原路径） | 632.935 ms | 639.658 ms | 7,625,846／7,625,846 |

原投影与查询词无关，表中复用同一组三次原路径读数，不能称为每个查询各有一组独立配对。全部原始样本保留，包括首个原路径较慢样本。22 组查询的所有结果页已用实际应用函数比较，完整 DTO、总数、排序和游标一致。权限、祖先／链接／媒体撤回、版本竞争和过期资格另用虚构资料检查。

回放的发布规则和媒体归属是本机模型，非托管策略完整克隆；上述不含浏览器、平台冷启动、SQL 传输及驱动解码，也不是生产 p95。原搜索 5 秒语句超时的具体内部慢阶段仍未确认。托管数据库需要新的有界安装及结果／耗时验收，不能由本机收益直接启用。详情首次连接等待继续单列处理。
