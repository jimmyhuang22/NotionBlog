## 已完成的执行链

`scripts/public-cache/commit-rollout.ts` 接受一个固定计划及其精确摘要对应的单次许可，执行 install、enable 或 disable 中的一项；安装不会隐式启用。它不建立自己的数据库连接，不读取凭据。连接由经过审阅的主机适配器在以下本机门禁之后才提供：

1. 克隆输入，核验计划／迁移完整性、目标／软件包／运行图摘要、固定表名、许可时限及预算。一次性认领 nonce 和 operation；已有或写入不明的认领不覆盖、不重试。
2. 取得并核验真实运行图对应的本机 hold。适配器必须同时验证软件包及运行图的实际字节、相关生产者和独立消费者／下架／维护的排空、暂停与原锁拥有权。摘要字段本身不是拥有权或排空证明。
3. 建立同一目标的专用事务连接。project 计划只接受已验证 TLS；private-unix-fixture 仅用于 isolated 计划。核验实际 owner、角色／会话身份、来源 lease／staging、writer 活动、原目录及固定前像。
4. 在 READ COMMITTED 事务中按固定顺序对实际存在且经计划列出的全部围栏表取得 SHARE ROW EXCLUSIVE NOWAIT 锁；普通只读访问保持。迁移只剥离经过完整文件 SHA 验证的唯一最外层 BEGIN／COMMIT；正文摘要也须匹配。执行后仍持有这些锁，检查完整后像，再发送唯一 COMMIT。
5. 激活／运行回退同样重取围栏、要求空意图和精确开关前值，CAS 更新一行。目录、角色、原缓存与来源指纹、可选维护配置必须与独立审阅的固定前后像吻合；不按现场结果生成期望，不写维护 guard。
6. 观察到 COMMIT 标签后关闭原连接，重新连接，在有界只读事务中核账并 ROLLBACK，观察关闭，再核验及释放本项 hold。每一步先保存必要的不可变意图回执；已提交但核账、日志或关闭失败分别报告，不能降为“已回滚”。

扩展目录仍使用原 14 函数／ACL／表／约束／延迟触发器 pins。新增事实查询还覆盖原围栏表结构／ACL、附属约束与索引、schema 权限、缓存和维护函数、挂到这些表或缓存函数上的触发器、角色与成员关系摘要、来源及原缓存状态摘要。只返回摘要和必要的身份／表名／布尔，不返回正文、密码或媒体定位；它是明确清单的组合检查，不是项目所有数据库对象的完整安全审计。实际目标的期望仍须从已保存材料及已审安装预测中独立固定。

## 许可、预算与适配器要求

单项许可最长为批准后 30 分钟内开始、批准后 120 分钟结束业务，之后最多 15 分钟清理；不自动续期。每项最多 3 次连接、80 次 driver 调用和 256 KiB 逻辑结果，计划可收紧；业务阶段为收尾保留 4 次调用。每次结果另限 32 KiB。install 正文是一项多语句 driver 调用，其内部 DDL／函数执行不冒充只执行了一条 SQL；最终项目提案必须分别列出 driver 调用、固定正文及平台口径，不能把逻辑回传预算当计费硬上限。

安装和启用是不同动作，可在一次用户批准的完整窗口中由外层控制器签发绑定各自计划的一次性许可，但总账、总期限及清理预留必须共同计数；本核心不自行拆分或扩大总授权。未接入共享总账前不能用于这样的真实组合。预算、业务期限或实际前像不符立即停止，不重试 SQL、连接或写入。固定 SQL 自带语句／锁／idle-in-transaction 时限；主机适配器还必须实施原连接、查询、socket 关闭和总窗口边界，不能以 Promise.race 丢下后台写入来伪造结束。

连接适配器的 command 必须返回真实 CommandComplete 语义，包括 UPDATE 的行数；COMMIT 得到 ROLLBACK 时不能包装成成功。connect 失败也必须清理自己创建的 socket；close 只有观察到连接结束才能成功返回，失败不重复 close 或开启下一会话。TLS／目标证明由该受审适配器绑定实际连接，普通调用者传入一段字符串不构成证据。本核心不是为不可信调用者提供的权限隔离 API。

`scripts/public-cache/commit-rollout-journal.ts` 提供纯本机的持久化实现：规范 `.local` 私有目录、nonce 和 operation 独占创建、0600 不可变逐步文件、文件与目录 fsync，以及目录身份前后核对。未知或部分文件保持原状；原始异常文本不进入报告。记录保存失败会阻止继续或保留 hold；即使最终回执未能持久化，函数仍返回内存中已观察到的提交状态，不能据缺文件认定未提交。

## 未知结果与回退

COMMIT 发送阶段出现异常或标签不符，一律保守为 unknown，保留 hold，不重放写入、不在同一动作中自动重连核账。即使清理 socket 使未提交事务实际回滚，也不倒填提交结论。后续核账需由外层控制器在原许可仍有效且确有预留时，或新的具体许可下，用既有只读核对函数与精确前后像辨别；不能再次运行同一 operation。该恢复主机适配仍未接入真实目标。

disable 只回退运行模式，保留扩展、原事件、generation 与新函数定义；不删除意图、重置来源、恢复维护、清缓存或执行 DDL 回滚。非空意图、目录／角色漂移、无法确认连接关闭均停止，不能为了释放 hold 强行继续。
