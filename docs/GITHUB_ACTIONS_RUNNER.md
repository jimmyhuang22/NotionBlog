# GitHub Actions 检查

## 当前状态

2026-10-22 迁移验收结束后，专用 Mac mini 原生运行器已退役：新旧仓库均无原生注册，系统服务已卸载并持久停用，本机注册文件已清理，账户、目录与守卫保留。当前私人仓库没有可承接任务的原生运行器，**不要再次手动派发私人检查**。恢复平台检查及其节奏须另行约定；公开后的标准托管检查仍需实际验收。见[清理记录](progress/2026-10-22-private-ci-retirement.md)。

日常 develop PR 按影响完成本机验证，无冲突、正文注明受检提交／验证方式／限制并核对实际合入差异后自行普通合并，不等待平台检查。当前私人 PR 的平台应用检查为 `SKIPPED`，不算通过；本机结果也不能写成平台通过。没有两小时集中检查，已知代码、协议或构建失败仍须先解决，见[合并规则决定](decisions/2026-10-22-develop-merge-local-verification.md)。main 发布的平台验收要求与发布期间暂停 develop 合并的规则保持；CI 停用期间如何满足 main 平台验收仍待用户另行决定。

## 工作流保留的路由

工作流按仓库的实际可见性选择运行环境，Node 版本固定为 24；下表说明保留的配置，私人手动路径当前不可用：

| 仓库状态 | 触发方式 | 运行环境 |
| --- | --- | --- |
| 私人迁移验收（已停用） | 保留所有者手动入口，当前不要派发 | 原专用 macOS ARM64 自托管运行器已退役，标签配置仍保留 |
| 公开后 | 发往 main／develop 的 PR，或手动选择分支 | 标准 GitHub 托管 `ubuntu-latest` |

私人阶段的 PR 事件跳过此任务；退役前的迁移验收曾由所有者手动选择已审分支。平台实际验收须核对仓库、SHA、运行器及全部步骤，不能把跳过的 PR、排队或本机通过视为 Actions 已通过。工作流没有 push 或定时检查，本项不修改工作流或重新启用运行器。

工作流安装根目录与 `scripts/game-sync/` 两份锁文件的依赖，再执行 `npm run check` 和 `npm run build`。检查使用离线 fixtures、隔离 PGlite 和本地媒体；不配置 Notion、数据库、媒体或生产部署凭据。Token 仅有 contents 读取权限，checkout 不保留凭据。已退役的私人运行器曾使用专用非管理员账户、受管服务、磁盘与任务前守卫，不使用开发检出，不迁入个人环境。

## 复用既有运行器（历史接线背景）

以下保留退役前的接线边界，不是当前可执行的复用步骤。新的私人运行环境须另行审查和配置。

既有运行器是仓库级注册，只能接收其绑定仓库的任务。新仓库即使最终与旧库同名，仓库 ID 也不同，修改 YAML 标签不会自动搬迁注册。

接线前保存当前注册及受管服务配置，核对运行器 idle 并防止新旧任务同时争用。注册、移除与服务配置通过官方短期注册方式和既有运维管理入口处理；不提取 Git 凭据，不改磁盘权限、系统隐私权限、账户权限或守卫。单个运行器只承接一个任务，失败保留记录。源码、旧工作区和业务同步不随 CI 重新绑定移动或恢复。

旧库的两小时调度、树缓存和历史通过回执不复制到新库。`scripts/ci/check-plan.ts` 保留原实现和测试，新工作流暂不使用其历史缓存，首次实际验收执行完整检查与构建。CI 接线候选与实际注册／成功验收分别记录。

## 公开前的交接

本次退役已停止服务并移除原生自托管注册；公开前仍须复核无在途任务和无残留注册。只改 `runs-on` 或依赖 PR 条件不能阻止他人提交修改工作流。保留旧私人运行根及可恢复的受管配置。需要继续私人 CI 时，在保持私人的仓库单独管理，不将外部 PR 分派到个人机器。

随后核对标准托管运行器路径、主分支保护与实际平台检查，并审查私人阶段 CI 日志中可能出现的机器或文件路径信息。工作流通过不自动授权公开仓库、部署或恢复业务同步；正式发布仍按 [AGENTS.md](../AGENTS.md) 执行。

本轮已按具体授权删除该次自托管验收的云端日志和单个可重建 npm 缓存；删除后日志不可读取，仓库 Actions 缓存与产物均为零。验收成功状态、步骤结果和受检提交元数据仍保留，原始日志与复核材料仅存私人目录。这项清理不代表已经删除所有平台历史或公开仓库。

GitHub 当前将自托管运行器和公开仓库标准托管运行器列为免费使用；私人仓库的托管分钟额度与之不同。官方说明：[计费](https://docs.github.com/en/billing/concepts/product-billing/github-actions)、[仓库级运行器范围](https://docs.github.com/en/actions/concepts/runners/self-hosted-runners)、[原生运行器安全边界](https://docs.github.com/en/actions/reference/security/secure-use)。
