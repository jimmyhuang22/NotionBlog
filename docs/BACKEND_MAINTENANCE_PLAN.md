# 同批次发布的维护与验收方案

本方案把首次 full、小图登记、独立媒体读回、代表访客与回退串成一次有明确截止的操作。它是执行准备，不授权更改政策、安装、调度、网站配置或正式部署。实际目标、来源、凭据摘要、代码/构建绑定、窗口与回执只保存在私有操作目录。运行与发布拥有方统一执行，前端和工程会话不并行启动另一套 writer。

## 窗口和唯一执行者

由原运行拥有方交接 canonical state、worker/session/manual 锁、在途发布及后置小图步骤、云租约和调度状态；不抢锁，不另建锁空间。缺少云租约交接时，本机无锁不能作为开始证明。调度停用和恢复须在具体维护批准中列明；不影响其他独立任务。

具体起点 T0 在批准后绑定。建议主窗口上限180分钟，另留回退120分钟；这是最大停止额度，未批准具体日期，也不表示预计运行时长。

| 阶段 | 上限 | 最晚结束（T0之后） | 接续条件 |
| --- | ---: | ---: | --- |
| 最终核对与原writer交接 | 15分钟 | 15分钟 | 最终输入、角色/TLS、回退准备与原锁/租约交接 |
| 唯一首次full | 90分钟 | 105分钟 | 同次 accepted full 与累计预算回执 |
| 必要时seal原工件 | 2分钟 | 107分钟 | 原身份查明接受状态，不重新采集 |
| initialize／必要时recover | 15分钟 | 122分钟 | 同工件、两个缓存和学习目录 ready |
| 小图登记＋独立媒体＋切换前访客 | 共45分钟 | 167分钟 | 同批次绑定、对象字节与代表服务端路径全部通过 |
| 经授权切换＋切换后检查及退出 | 共13分钟 | 180分钟 | 实际配置回读、明确验收边界和运行交回 |

每次接续使用阶段绝对截止，实际时长取阶段上限和剩余时间的较小值。启动晚、恢复或失败不重新得到完整时间。seal/recover只用于原操作状态不明，已有成功证据不重复执行。登记最多8分钟，切换前访客预留5分钟；独立媒体的实际时长必须扣除已用登记时间及这5分钟。切换后访客也占原13分钟中的5分钟，不新增窗口。

## 冻结与同批次接续

1. 冻结最终commit/tree、运行组件与manifest、Node/双锁、实际生产构建、来源/政策摘要。包含[首次full守卫](HOST_HTTP_BUDGET.md)、[旧发布共享预算](QUALIFIED_SHARED_BUDGET.md)、连接修复、[小图登记](PUBLISHED_THUMBNAIL_REGISTRATION.md)及最终受检访客工程。working tree不作为交付包，Git合入不等于安装。
2. 核对实际受限writer、独立数据库reader和对象reader/writer的目标、最小能力、verifyTLS、凭据期限与当前政策。URL解析和历史IAM回执不能代替活体证明。访客不含Notion或写入凭据；登记环境只含数据库writer/独立reader与TLS/CA，不含Notion/COS凭据。
3. 媒体拥有方交回独立读回证明链与最新累计指针；固定小图成功按SHA取并集，不把PUT或匿名403当成功，不重置或恢复已结束窗口。完整当前有效候选必须覆盖；不重复生成或上传已验证小图。
4. 用同一canonical writer按已审来源执行唯一full。已有unknown/inFlight先原身份lookup/seal/recover，不盲重发promote或重新采集。正常接受工件、目录、raw/media和缓存都属于同一发布；历史快照不能替代。
5. 基于实际accepted full将既有小图分为仍适用且有覆盖、合法非成员、父原件变化、仍适用但缺覆盖。登记计划过滤最后一类不能声称完整覆盖。绑定原独立回读receipt字节SHA，再离线审plan/digest；实际同次关系、资格及祖先通过后SQL-only register，出现未知写入保留回执，不自动重试。
6. [独立媒体读回](INDEPENDENT_MEDIA_ACCEPTANCE.md)使用登记实际选中集合及同次工件，核SHA/MIME/长度和前后资格。全对象验收由该入口完成，代表访客不重新回读整个图库。

既有停止额度沿对应入口：登记最多197项，18+3M次SQL（M≤197时≤609）、8分钟、2MiB参数JSON、4MiB行JSON、两个native Client、HTTP全零；独立媒体HTTP=U、SQL=11+4N，单只读Client，来源/外部原图/PUT全零。实际U/N、字节与duration必须从同次工件派生。验证恢复也消耗剩余预算，不能新增免费操作。

## 代表访客的守卫与边界

访客工程由独立工程会话交付，发布拥有方接收最终受检CLI/组件和生产构建，再绑定同次工件、已登记且独立验收的小图选择、只读profile、站点配置、revision/config/epoch。隔离本机生产Next在导入路由前安装SQL/fetch守卫；保持正常网站入口不变。

前后各一次，单段最多5分钟、64次HTTP、64MiB回应、256次应用SQL和8MiB行JSON；合计128HTTP、128MiB、512SQL、16MiB行JSON。HTTP同时累计访客根请求和代理内部COS GET，回应在两个接收点分别计数；失败尝试、错误/部分正文和迟到行不退款。最终CLI的连接尝试及SQL参数JSON防御额度也明确记录。不能将这些应用字节当作TLS/PG帧或云计费上限。

前后共享一个绑定操作，阶段slot排他且账本持久。失败、取消、SIGKILL或丢回执不能新建操作刷新本次授权额度。新操作先由运行拥有方核对剩余总账，不能自动替代。超限、失败、资格/版本变化、重定向、Source/外部图/写SQL即停止；在途请求及连接有界退出，计量或排空不明必须失败。

代表内容包括动态列表/年份/正文、课程列表/详情/目录、真实深层笔记API和HTML、有内容时关于接口、原图及400/800请求、未知内容/媒体404。核对真实provider、公开成员、结构、no-store与图片SHA/MIME/长度，不回退mock。至少一个已登记400变体应实际命中；空选择或原图fallback只能证明原图路径，不能报告小图成功。完整布局、最长目录与最大层级由前端沿同次内容交回。

本机结果只证明受检构建的服务端路径，不证明线上域名、Vercel部署、浏览器hydration、社交首页或跨地区网络。切换后的本机post也不等于云站切换成功。线上另列有限页面/API/媒体URL、HTTP/body/时限、实际部署身份、网络地点及结果，纳入具体窗口。远端实际SQL无法从HTTP客户推断；没有云端观测/强制接线时保留未验证，不填零或借用本机计数。内地测试网络缺失时明确待验收，不通过重复full补证。

## 失败、回退与交回

未改变政策/网站且门禁失败时，停止后续阶段并交回原运行拥有方，不改mock或自动重跑。已改变政策可能使旧qualified失效，恢复旧env不能保证恢复访问，应明确不可用空窗。持久published模式与旧qualified期限分开；当前政策/成员、reader/对象凭据和对象可用仍决定可读性。旧资格过期明确拒绝，不手工延长旧批次。

回退需当次明确授权及原锁/租约交接，保留120分钟：用冻结旧范围和qualified/notion入口真正发布新鲜批次（≤90分钟），独立读回、恢复网站与运行交回（≤30分钟）。停止新触发，等在途/unknown查明；保留新指针、对象、队列、缓存、失败和历史，不删除来“回滚”。

旧回退共享额度草案为Notion5000、Storage4000、Auth16、图片5000、总14016；来源回应256MiB、Auth回应16MiB；图片回应3GiB＋Storage回应2GiB＋全部请求体3GiB；SQL10000保守Pool/Client调用、参数/行JSON各64MiB。fail_run清理最多20秒/4次SQL/参数与行各64KiB，不增加业务窗口。额度需绑定实际入口/manifest，不把工程具备写成已经安装或实际执行。

总回执交回代码/构建/来源/profile摘要、原writer/租约、full批次和工件、初始化ready、小图分组/登记ACK/unknown、独立字节结果、前后访客账本、配置回读、主/回退实际时间与余额。具体身份、来源ID、正文、凭据和签名URL仅留私有目录。

日常维护沿已审增量与原唯一writer调度，变化任务才读Source/媒体，unknown先recover；小图登记仍绑定当前父SHA/资格，不能跨批次照抄关系。不定时重复全量对象验收或反复刷新网页保持资格。固定最小健康检查；无变化结束，故障保留最后成功与失败证据。代码/输入/权限变动只重验受影响范围，运行安装和云站发布按各自具体授权执行。
