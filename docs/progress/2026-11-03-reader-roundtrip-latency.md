## 修改

- 使用现有 `pg` 版本的流水能力，将只读事务的四次依次等待改成两组：`BEGIN READ ONLY` 与 `SET LOCAL`，然后参数化业务查询与 `COMMIT`。先确认两条设置成功才发送业务查询，每组都等待全部结果；失败、取消和未知提交结果保留清理与连接销毁边界。
- SQL 条数、业务查询上限、结果字节、请求截止时间和数据库只读约束仍计入原预算；诊断中的 `database-roundtrip` 改为计算两组网络等待。写入路径不启用流水。
- 顶部导航首次挂载不预取所有栏目；悬停、键盘聚焦或触摸一个入口后才启用该入口的默认预取。
- 已获准字节缓存的版本图片在 tagged 模式下使用一天私有浏览器缓存，200／304 一致；源站撤回检查、可变／实时图片和错误边界保留。

## 接口与 provider

- 现有缩略图校验、ETag、撤回资格和 304 响应语义不变。
