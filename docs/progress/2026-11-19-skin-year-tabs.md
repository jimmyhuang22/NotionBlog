## 改了什么

- 岛屿、千禧下，影视、书籍、游戏页的年份筛选改为一排文字，选中的那年下面一道圆头短线：岛屿是黄色，千禧是光泽蓝，千禧选中的字也变蓝。状态筛选、排序按钮、动态页的年份条都不变。
- 按下当前年份时不再下沉、不再出现内阴影；加载时年份占位改成一排字宽的短条，与墨水相同。

## 怎么验证的

- 本机没有书架数据，所以只在线上只读验证：把这次新增的 11 条规则原样叠加到线上游戏页（`/library/games`）。验证了岛屿浅色 1280 与 390、岛屿深色 1280、千禧浅色 1280 与 390：
  - 线宽为字宽（28 像素）、高 4 像素；岛屿为黄色，千禧为渐变蓝；
  - 当前年份没有底色；
  - 加载占位高 14 像素、无圆角；
  - 没有横向溢出。
- 按下“2025”后，滑块（线）移到 2025，位置和宽度与该链接一致。按下当前年份时没有位移、底色和阴影。
- Node 24.21.0：`npm run check` 3477 个测试通过，`npm run build` 通过。线的圆角用 `999px`（样式检查只允许刻度内的圆角，4 像素高时与 2px 看起来一样）。
