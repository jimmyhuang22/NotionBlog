# 2026-10-17：作品库去掉“全部”、影视卡片只写评分、切换不重叠（Claude）

来由：反馈 F23。决定见 [决策记录](../decisions/2026-10-17-library-no-all-and-film-cards.md)。

## 改了什么

- `librarySections` 每个栏目有 `defaultStatus`；页面没有或给了无效的 `status` 时用它；状态切换不再有“全部”。`libraryHref` 对默认状态省略 `status`。
- `cardParts`：影视卡片只写评分（或“未评分”）；`coverBadge`：非电影的类型放在封面左上角（`.library__badge`，深色半透明底白字，像素主题方角）。影视标题限一行、`title` 提示完整标题。书籍、游戏卡片不变。
- 切换重叠：原因是 F18 里给筛选切换加的过渡只关掉了新旧画面的淡入淡出，没有藏起旧画面，筛选块滑动的 0.3 秒里旧列表的快照还盖在新列表上。`motion.css` 让筛选切换时旧画面不显示（`::view-transition-old(.filter) { opacity: 0 }`）。动态页的年份切换用同一规则。

## 怎么验证的

- 正式站点（改前）：从“看过”点“想看”逐帧录屏，约 1.26 到 1.47 秒之间新列表的空封面卡下面露出旧列表的海报，重现了重叠。
- 本机生产构建（演示数据，改后）：同样的点击逐帧录屏，约 0.08 秒新列表整体替换，任何一帧都没有两套列表，只有筛选块在滑。
- 本机：影视、书籍、游戏打开分别是看过、已读、通关（`aria-current`），默认状态的链接是栏目本身，其他状态带 `status`；影视卡片第二行“未评分”／星级，演示数据的“动画”显示为封面角标；标题一行省略。390 宽墨水、像素深色，1280 千禧：没有横向溢出。
- 对比图（真实条目，手机宽度）给用户选了长标题与书籍游戏卡片：放在忽略的 `.local/theme-options/2026-10-17-library-cards/`。
- `tests/library.test.ts`：默认状态省略地址、每个默认状态都在切换里、影视卡片与角标规则。类型检查、测试与两种构建见合并请求说明。

## 限制

- 只在演示数据下看过改后的页面；正式站点要发布后看。
- 游戏 214 款没有状态的，在 Notion 补好并恢复同步之前，列表里看不到（用户已知）。
- 没有封面的影视（显示竖排书名）若有类型角标，角标会盖住书名左上一点；真实数据里多数有封面。
