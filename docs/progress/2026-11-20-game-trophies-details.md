## 做了什么

- 第二轮原型：线上《艾尔登法环》详情页注入，名称、图标和全球比例取自这款游戏的 Steam 公开成就页，获得情况、等级和日期是编的。比了五组：手机上的稀有卡片、两个平台、稀有度写法、展开后的分组、白金；另拍了墨水浅 / 深色、岛屿、千禧、苹果 1280 和墨水 390。对比页在前端忽略目录 `.local/previews/game-trophies-20261120/`（`round-2.html` 原图，`round-2-lite.html` 压缩版），生成脚本未提交。
- 用户五组全部选推荐，写进决策。
- 用户问图标能不能直接用 Steam 链接：不行，站点 CSP 只允许本站图片，国内访客走上海、平台图床不稳定，交接里本来就要求存站内媒体；这次补了原图尺寸和隐藏奖杯不给图标两条。

## 怎么验证的

- 只改文档：核对了记录格式、链接和差异，`npm run privacy:check` 通过。没有运行 check / build。
- 原型截图里 1280 与 390 都没有横向溢出；四套皮肤只看了 1280。没有用真实的个人奖杯数据验证。
