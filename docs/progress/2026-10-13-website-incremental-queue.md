# 2026-10-13：网站增量同步持久队列（Codex）

编辑登记：独立 `codex/website-incremental-queue`，新增本机队列模块、针对性测试与说明；不编辑主重构的 SQL、publication writer、运行入口、学习目录或媒体代码，不改 Dagu／Dashboard／线上配置。最初按本对话约定从最新 main 起分支；用户继续重构后普通带入最新 develop 的持久发布基础，PR 对齐当前集成分支 develop，不代合 main。

使用现有 Node SQLite 实现变化事件去重与页级代次合并、发现游标事务／版本检查、有限 claim 与租约隔离。准备中再次编辑不会被旧完成回执清除；准备阶段中断可恢复，已尝试提交的操作保持待核对，不能因过期而盲重发。云提交适配器未来负责服务端操作查询和独立 reader，本模块仅保存、匹配其操作键及摘要。

私有文件和 sidecar 核验、独立 schema 标识与固定来源摘要保护状态；status 仅返回计数。没有新增依赖或常驻程序；依赖锁相同，复用已有安装。针对性用例涵盖真实 SQLite 重开、两个连接、分页回滚、处理中再次编辑、失联回执、范围漂移、私有文件与外来数据库。

验证：15 项针对性通过，包含真实子进程在提交标记落盘后异常退出、重开仍等待核对；类型检查通过。最终集中 `npm run check` 通过 1,247 项、类型／三协议及 491 文件隐私检查，`npm run build` 与 40 服务端 trace 检查通过。首次测试的临时目录没有转为真实路径，被原私有目录规则拒绝；已修正测试目录并保留规则，非法 proof 测试的类型转换也已纠正。没有为测试放松权限或提交保护。

仅本地虚构事件与临时 SQLite 状态；没有访问真实来源／云库／图片，也没有触发发布、部署或暂停排程。下一项是接口稳定后接入页级内容准备、媒体、学习依赖和幂等增量发布，再做必要代表变更验收。该模块尚未接入运行器，不把离线验证称为实际增量发布已完成。
