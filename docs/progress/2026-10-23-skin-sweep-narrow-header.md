## 修复

- 岛屿：380 以下去掉站名的加宽字距（`[data-skin="island"] .site-header .site-header__brand { letter-spacing: 0; }`，选择器要高过岛屿原有的 `:is(.hero h1, …)` 那一条），站名宽 144.2，320 宽回到两行。
- 千禧：站名小一档的断点从 380 放宽到 389。
- 接手说明的页头一段补上这两条。

两处都先在正式页面里临时注入验证：岛屿 320、325、330、360、380 宽页头都是 96；千禧 381、384、388、389 宽都是 96，390 起照旧 106。
