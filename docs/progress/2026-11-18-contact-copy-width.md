## 改了什么

用户在线上发现：点“复制”后按钮字从“复制”变成“已复制”，按钮变宽，整张卡片跟着变大。不是有意设计。

- “复制”按钮里放一个看不见的“已复制”占位，与当前字叠在同一格，按钮宽度固定为最长的那个词；卡片随之不变。
- 复制失败时的字从“请手动复制”改为“已选中”（地址已被选中，读屏仍读“无法自动复制，地址已选中”），也在同样宽度内。
- 两个按钮现在一样宽（都按三个字）。

## 怎么验证的

- 本机正式构建配占位地址（与 #367 相同的临时配置入口，验证后已还原、未提交），给无头浏览器开了剪贴板权限走成功路径：岛屿与墨水 1280，复制前后卡片都是同一尺寸（岛屿 215×124、墨水 221×124），两个按钮都是 74 宽，按钮字变为“已复制”。
- Node 24.21.0：`npm run check` 与 `npm run build`，结果见合并请求。
