# 2026-10-21：设计自检第三轮的六项改动（Claude）

编辑登记：Claude 本轮修改 `src/app/motion.css`、`src/app/timeline.css`、`src/app/library.css`、`src/components/library-grid.tsx`。契约、接口与媒体路由、fixtures、依赖、栏目开关、全局入口与后端代码未改。选择见 `docs/decisions/2026-10-21-design-review-3.md`。

## 改了什么

- 页头换栏目：新页面的进场改为延迟 0.18 秒、时长 0.3 秒（`motion.css`）。
- 作品页：排序按钮按下（`is-turning` 或链接进入等待状态）时，`.works__stage` 淡到 45%，0.1 秒延迟、0.2 秒过渡；减少动态效果时直接变淡，不过渡（`timeline.css`）。平台切换不受影响。
- 影视、书籍格子：悬停句的日期以所在年份组（或年份筛选）为准，同年时去掉开头的“YYYY 年 ”（`library-grid.tsx` 的 `headingYear` 与 `withinYear`）。按名称排序时没有年份标题，照旧写年份。
- 详情页：只有一张邻居卡片时占一半宽并靠它那一侧；无记录提示改为一行字，墨水主题加一笔淡墨、手帐用荧光笔（`library.css`）。
- 搜索：摘要里的命中词去掉下划线，只换成强调色（`library.css`）。

## 怎么验证的

- `npm run typecheck`；除 `website-v2-runtime` 与 `qualified-shared-budget` 外的全部测试（2375 项通过；这两个文件要复制并运行 Node 24 的程序，本机的 Homebrew Node 跑不了，留给平台检查）。
- 页面（`next build` + `next start`，演示数据）。develop 现在的本地构建会把栏目开关固定为关闭（`next.config.ts` 的离线模式），为了看影视页，只在本机构建时临时打开栏目开关，没有提交这处改动。用无头 Chrome 真实点击：
  - 1440 宽，墨水：悬停句在 2026、2025 组里是“7 月 23 日看过”“8 月 24 日看过”，“日期未记录”组照旧。
  - 最新一部的详情页只有“较早看过”：1440 宽下卡片 485 像素、靠右；390 宽下 172 像素、靠右；没有横向滚动。
  - 无记录提示在墨水（有一笔）、手帐（荧光笔）、苹果、千禧（只有字）下都没有边框。
  - 搜索：四套主题下标题命中词有下划线，摘要命中词没有，颜色是各主题的强调色。
  - 作品页把网络延迟设为 700 毫秒后按“播放最多”：舞台不透明度约 180 毫秒开始下降，280 毫秒降到 0.47，新列表到后回到 1。
  - 从“动态”点到“学习”：`page-aside` 0–180 毫秒，`page-along` 从 180 毫秒开始，持续 300 毫秒。

## 限制与下一项

- 都在演示数据下验证；正式站要发布后再看（指定影视样本页、搜索“Notion”）。
- 390 宽下半宽卡片放较长的作品名会折成两行，例如演示数据的“[演示] 虚构记录 14”；真实书名大多较短。
- 学习首页的海报墙（O-07）没有动，等用户想调整学习区时再出原型。
