## 改了什么

- **搜索面板**：看大图或关于卡片开着时，按 `/` 或 ⌘K 不再把搜索面板叠在上面。
- **主题按钮**：去掉 `aria-haspopup="true"`。它告诉读屏软件这里会弹出菜单，但面板里实际是单选组和开关。`aria-expanded` 和 `aria-controls` 保留。
- **导航栏**：`splitNav` 改成只在栏目变化时重新计算。原来每次渲染都会生成新数组，导致墨线定位的布局 effect 每次都重跑，并且重复挂上 `resize` 监听。同时删掉没用到的 `primary`。
- **博客标签链接**：补上 `prefetch={false}`，和文章列表一致。
- **作品库详情的面包屑**：链接改用 `libraryHref` 生成，不再手写，生成的地址不变。
- **邮箱等非网页链接**：不再加 `target="_blank"`，不会多开一个空白标签页；网页链接照旧在新标签页打开。
- **站点配置**：`getSiteConfig` 用 React 的 `cache` 包起来，同一次请求里只读取和解析一次。原来一次请求要读文件、解析四到六次。下一次请求照常重新读取，所以换头像或链接仍然不用重新构建。
- **作品库“按标题排序”**：前端的排序类型和网格里关于 `title-asc` 的判断删掉了，因为页面只接受 `date-asc`。后端内容接口仍然支持 `title-asc`，没有改。
- **样式**：
  - 删掉四套主题里都定义了、但全站没有一处使用的 `--mint`、`--lilac`；
  - 删掉苹果主题里被更具体的规则盖住、从未生效的 `.tree-find` 样式，画面不变；
  - 搜索面板快捷键提示的 `font: 12px …` 改成 `font: var(--text-xs) …`，大小相同；
  - 字号档位测试现在也检查 `font:` 简写里有没有写死的像素值。
