# 2026-10-31：手机上相册照片全部单列（Claude）

编辑登记：Claude 本轮只改 `src/app/library.css`（删掉相册 520 宽以下的一条规则，换成一行说明）。组件、契约、接口与媒体路由、fixtures、依赖、栏目开关、全局入口与后端代码未改。

## 来由

[发布 229](2026-10-31-release-229-live.md) 让电脑上相册里单独摆放的照片与分栏照片同宽。手机上原有一条 520 宽以下的规则让单独照片两张一排、说明用最小字号，分栏照片却是一张一排，两者一大一小。用户看了三种方案（现状、全部单列、全部两张一排）的对比，选“乙 全部单列”（2026-10-31）。

## 改了什么

- 删掉 `@media (max-width: 520px)` 里相册的两张一排和小字号说明。手机宽度下，相册基础网格（每格最窄 260）本来就排成一列，间距 18，说明字号与分栏照片相同。单独照片仍裁成 4:3。
- 520 宽以上不变：电脑和平板上，单独照片两栏，与分栏照片同宽。

## 怎么验证的

- Node 24.21.0，以最低优先级运行：`npm run check` 通过，3249 个测试全部通过，0 失败；`npm run build` 通过，49 份服务端追踪隐私检查通过。
- 在正式页面上把线上样式表换成本次构建出的样式表，用无头 Chrome 1x 截《26年回国后的一些食物》：
  - 390 宽：牛腩、亚洲杯、炸鸡、阿耐四张单独照片都占满一列，宽 354，与分栏照片同宽；相册总高 4341，与对比原型的乙相同。
  - 1280 宽：仍是两栏，与发布 229 一致。

## 限制与下一项

- 只看了墨水浅色；其他主题、深色、Safari 与真机未测。
- 另外两本相册只用分栏，不受影响。
- 随下一次发布上线后，在线上复核 390 宽。
