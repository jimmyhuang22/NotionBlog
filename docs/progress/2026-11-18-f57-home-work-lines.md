# 2026-11-18：F57 首页连着两三件作品改成轻记录（Claude）

编辑登记：Claude 修改 `src/components/home-works.tsx`、`src/components/social-work-card.tsx`、`src/components/home-timeline.tsx`（注释）、`src/app/timeline.css`、`tests/reading-design-refinement.test.ts`、`docs/FRONTEND_GUIDE.md`；新增决策 `docs/decisions/2026-11-18-home-work-runs.md`。契约、接口与媒体路由、取数层、fixtures、栏目开关、依赖与后端代码未改。

## 改了什么

用户反馈首页小红书“占了很多空间”，看过对比原型后选甲（交接包 F57）。

- 首页同一组连着 2–3 件作品（`HomeWorks`）：每件一条轻记录 `HomeWorkLine`，上下排（`ul.work-lines`，间距 10）；分组行不变。4 件及以上仍是横滑条（`LINED_RUN = 3`）。
- 一组跨了几天时，每条轻记录在平台那一行写出自己的那一天；同一天不写。
- 横滑条里的小红书卡（`SocialWorkCard small`）同一天不再重复日期，改写平台名（新增 `showDay`，作品页默认照旧写日期）。
- 竖封面从顶部裁：横滑条的竖卡和轻记录的竖小图。
- 首屏第一张封面优先加载，两三件时给第一条。四个主题都适用。

## 怎么验证的

- 新增两个测试：2、3 件是轻记录，4 件是横滑条，同一天的横滑条不写日期；跨天时每条写日期，同一天不写。
- Node 24.21.0：`npm run check` 与 `npm run build`，结果见合并请求。
- 本机正式构建，用一次取回的正式首页数据（`/api/home/feed-v2?limit=30`）在一个不提交的临时页上渲染真实时间线，封面经脚本从正式站点代取；无头 Chrome，1x。四种情形：真实的 11-17 两件（小红书＋B 站合集）、在其中加一件更早一天的（跨天 3 件）、加到 5 件（横滑条）、第 3 件没有封面且标题很长。
  - 真实两件按正式站点时区（墨水浅色）：这一组高 159（1280）／174（390），原型甲为 163／178；不写日期，“新增 1 个视频”在标题旁。
  - 宽度：1280、860、390、320，320 与 390 没有横向溢出；长标题两行截断。
  - 主题：墨水浅色与深色，岛屿浅色与深色，苹果，千禧。
- 没有在线上看过；键盘焦点沿用单件轻记录的规则，没有单独逐条按 Tab 试。
