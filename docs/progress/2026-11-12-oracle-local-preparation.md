已运行 3392 项完整本机检查，全部通过；本机 build 与断网 Linux ARM64 自托管 build 均通过，各核对 50 个 server trace。初次沙箱内检查因回环监听限制中断，未计为通过；后续检查保留离线网络阻断，在允许回环监听的环境执行。新增磁盘/JWT 定向测试覆盖损坏、权限、链接、过期及错误身份；实际 HTTP 回归验证启用 JWT 后的拒绝／放行及 SIGTERM 完整退出，Mac 与 ARM 均通过。
