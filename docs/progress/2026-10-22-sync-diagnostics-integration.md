# 2026-10-22：同步图片诊断与独立收尾源码收编（Codex）

## 编辑登记与范围

本项从新 develop 的独立短期分支移植旧 #383 的必要源码差异，不合入旧 Git 父链。只编辑网站同步下载、worker／CLI／主机收尾、对应回归及本项说明；保留当前发布前来源修复和失败记录。清理组由已登记的后端交接任务处理，本项不重复其 `scripts/database-retention/` 改动。

## 修改与接口

- 图片终态诊断随错误保留，当前采集与接续增加实际 owner／媒体定位；私人侧文件和普通回执的边界保持。
- 临时 DNS、内部响应头／图片期限沿用原三次尝试及预算；调用方取消、权限和内容拒绝继续停止。
- 新增独立 finalizer：诊断失败不阻止关闭连接，两个池分别启动关闭，最后必需回执保留发布事实和清理结果。主机释放 worker 锁失败时仍处理自己的手动锁与临时输入。
- 页面 DTO、provider、来源、依赖、SQL及发布／资格协议不变。冻结 JSON 与生产版本校验器原样保留；测试固定当前诊断字节并明确断言旧转换继续拒绝，未把新源码写入旧允许清单。

操作边界见[固定同步入口](../WEBSITE_SYNC_RUNTIME.md)。运行源码存在不表示冻结主机已换包，也不授予新采集、恢复或部署窗口。

## 验证与限制

本项使用现有 Node 24、相同锁文件的本机依赖及离线演示验证。54 项专项测试通过，另新增一项当前发布前重采集成回归：新图片被拒绝时保留准确诊断，未暂存或发布残缺内容。覆盖并发首错、DNS／期限／取消、采集与接续定位、诊断／回执故障、关闭异常／挂起、锁替换和旧转换拒绝。

集中运行一次完整 `npm run check`：类型、三份冻结协议、2,495 项测试及 1,603 个候选文件隐私检查全部通过，零失败／取消／跳过。`npm run build` 通过，48 份服务端追踪排除私人运行文件。测试使用隔离入口封锁外部 Node 连接，并允许回归所需的临时本机端口。文档格式、相关链接和暂存隐私另行复核，不把本机结果写成平台通过。

本轮没有真实来源请求、业务 SQL、运行包安装、调度调整、锁获取、任务恢复、旧 PR 关闭、分支合并或部署。网站内容同步是否运行以原拥有方最新授权为准，本项不重复恢复或暂停；清理与其他来源继续各自现行状态。
