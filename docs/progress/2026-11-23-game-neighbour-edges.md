## 做了什么

- 用户看过 [#454](https://github.com/jimmyhuang22/NotionBlog/pull/454) 的本机预览后说，两侧已有把手，页尾两张卡片可以去掉。
- 页面：游戏详情。1100 宽以上且指针可悬停时（也就是把手出现的地方）页尾的“上一款 / 下一款”卡片和它的加载占位不再显示；更窄的窗口、手机、平板照旧。
- 把手从“重复的装饰”改成这一处真正的链接：放进 `<nav aria-label="上一款和下一款">`，进 Tab 顺序，键盘聚焦时和悬停一样展开；箭头与小图对读屏隐藏。两套链接同一时间只显示一套。
- 左右方向键改为按下当前看得见的那一个（把手或页尾卡片）。

## 怎么验证的

- 本机构建的演示站点加未提交的预览页（线上《女神异闻录5皇家版》数据），岛屿浅色：1440 与 1100 宽页尾卡片不显示、把手显示；1099 宽相反。1440 宽从奖杯一节的最后一个按钮按 Tab，依次到上一款、下一款把手，聚焦时展开；方向键 → 打开把手指向的游戏；1099 宽方向键 ← 打开页尾卡片指向的那一页。
- Node 24.21.0 的 `npm run check`（3531 项全部通过）与 `npm run build` 通过（`8d3073c`，不含临时预览页）。
