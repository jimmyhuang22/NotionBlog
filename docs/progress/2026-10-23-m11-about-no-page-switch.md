# 2026-10-23：点头像打开“关于”不再触发换页（第四轮审查 M-11）

负责 UI/UX 的 Claude。Fable 第四轮审查唯一的高优先级：首页头像上的“关于”入口是 `href="/about"` 的链接，点击时阻止默认跳转、改为打开弹层；换页机制（`page-switch.tsx` 的 `followed()`）只看“默认行为被阻止、站内、路径不同”，把它当成了跳转——整页复制变暗、页头下出现进度条，而地址永远不会变成 `/about`，要等 15 秒才撤，期间打开的主题菜单、搜索等都压在这层下面。

## 改了什么

- `src/components/page-switch.tsx`：带 `aria-haspopup` 的链接（原地打开东西，不离开本页）不再启动换页。规则写在换页一侧，以后别的弹层入口只要标明 `aria-haspopup` 就不会再被误判。按住修饰键点击仍按链接在新标签打开，与此无关。全站目前只有这一处带 `aria-haspopup` 的链接。

## 验证

演示数据，`next dev`（临时在本机打开“关于”栏目，未提交），无头 Chrome 1280 宽，点击后逐帧记录 1.2 秒内换页标记、复制层与进度条：

- 修改前：点头像，70 帧都有换页标记、复制层和进度条，同时弹层已打开。
- 修改后：点头像，0 帧；弹层正常打开，地址仍是 `/`。
- 修改后点页头“动态”：换页照常启动（复制层与进度条出现）。
- `npm run check` 与 `npm run build` 见合并请求。
