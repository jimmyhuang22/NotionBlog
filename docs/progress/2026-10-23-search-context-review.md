## 发现与方案

确认同名结果仍缺课程／父级信息。完整笔记已有课程关系及面包屑，但公开搜索 DTO 和精简 SQL 输出未提供该数据，不能只给前端传一个地址后猜课程，也不能把已有完整 DTO 当成精简 provider 已支持。

提供“来源行”和“课程标签”两个本地可交互方案，均展示同一顺序、同一课程及父级信息，不新增父级导航或搜索范围。包含两个入口、跨课程同名、同课不同父级、缺编号时长课程名、深路径、缺上下文及其他栏目。建议来源行，以较轻层级补足判断信息。

评审列明拟申请的可选显示 DTO、当前资格和受检版本、批量元数据投影、冻结 SQL 兼容及各 provider 验收边界。初次评审时尚未选定或实施；用户后续选定来源行并批准最小共享字段，后续实施单列记录，真实安装和开关启用不随原型批准自动执行。

## 验证与局限

最终原型脚本语法通过；新预览浏览器通过 19 项交互检查，覆盖原生轮播、跨课程和同课不同父级的可辨认名称、原阅读目标的本地模拟选择、空结果、缺失上下文／其他栏目及键盘关闭重开。两种方案、两个入口、四类示例、七种主题明暗组合与 736／390／320 宽度共 336 组布局检查未出现横向溢出，操作高度至少 44 像素，相同状态下两方案的轮播高度一致。核对最终桌面、窄屏、深色与长路径截图，浏览器无运行异常。

首轮自动化的上一个方案按钮选择器错误保留；原型完整页提交改为沙箱内本地交互，修正隐藏的重开按钮与轮播高度后重启预览并复验。前轮及手工切换导致标签不一致的截图不作为最终证明，最终切换均使用包装器原生轮播。原型只比较展示结构，使用近似主题色与本机字体，不证明正式页面、真实 provider、性能、真机或完整读屏通过。
