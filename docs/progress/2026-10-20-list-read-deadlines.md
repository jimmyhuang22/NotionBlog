# 2026-10-20：作品与首页读取期限及故障定位（Codex）

编辑登记：接收 S12 后端交接，从最新 develop 独立分支实现请求期限与相关 SQL 清理。认领服务端预算、网站数据库执行器、作品与首页统一入口、对应测试及本项文档；不修改页面、组件、搜索投影、冻结运行包、调度或云配置。

现状：原作品 HTTP 没有覆盖整次读取的期限；首页原预算只在 SQL 前后检查，不能及时结束连接排队或在途读取。现将作品 API 与 v2 首屏、首页 API 与 v2 首屏统一为单次七秒读取期限，嵌套调用不重新计时。连接取得与逐次 SQL 使用剩余时间；取消销毁本请求客户端，晚到连接不发送 SQL 并归还，失败不自动重试。无预算的原调用仍使用原 pool.query 路径，身份、TLS、角色上限、数据库协议与公开资格保持。

超时保留现有 503 和错误码，增加 Retry-After；400／404 和成功 DTO 保持。日志只记录固定阶段、允许的代码、池计数及不含个人值的读取总耗时。七秒是服务端读取期限，不将其外推为任何网络／冷启动条件下完整页面八秒上限。平台部署、自然一天观察及反馈方浏览器复验仍独立进行。

历史诊断：指定时间窗口的数据库日志存在 reader 角色连接拒绝，另有媒体 worker 角色拒绝和认证超时；不能把多服务重复日志相加，也不能在缺少原请求 ID 时确定它们就是报告中的单次故障。托管函数日志接口拒绝访问，使用当前 CLI 的相同目标有界读取也失败，保留原错误，不将其当作“无错误”。当前只读角色连接计数为零不能否定历史错误。没有为重现而访问真实页面、下载图片、重新同步或调整权限。
