## 改了什么

- **T-09**（`prose.css`）：540 以下 `.prose__h--1/2/3` 改用 `--text-2xl`、`--text-xl`、`--text-lg`。
- **X-11**（笔记页、`study.css`）：折叠的“本页目录”后加“· N 条”（N 是目录条数），右端用两笔细线画一个箭头，展开时转向上；减少动态效果时不转动画，直接换方向。
- **W-10**（`study.css`）：700～1099 宽的面包屑上下各加留白，文字中线与“课程目录”按钮对齐，标题与这一行之间约 30px。
- **M-12**（`motion.css`、`library.css`、`timeline.css`）：`.is-arriving` 从 45% 起亮、去掉 60ms 前置，依次间隔仍是 25ms；列表区变暗的过渡只在变暗时生效，新列表到了立即回到 100%。影响作品页排序、影视／书籍／游戏的年份与状态筛选、动态年份和搜索栏目。学习总览的筛选不变：它是旧行的复制层在新行上方淡出，新行若从 45% 起会和旧行叠在一起，所以那里仍从 0 起。
- **M-13**（`library.css`）：`.cover--waiting` 去掉墨线、改用 `.skeleton` 同款淡墨底并呼吸，片名灰色、1 秒后浮出；真正没有封面的书脊不变。
- **H-09**（`library.css`）：墨水与苹果下 `.work ~ .reading__article` 去掉卡片，其中的 `.prose__toc` 变成上下细线之间的一行链接，前面一个“本文”小标。
- **H-10**（`prose.css`）：墨水与苹果下，含 `.rt-warning` 的标题宽度随文字，文字用墨色，`::before` 用名字下那一笔（`--pen-stroke`）画一笔 55% 的警示色。`::after` 仍留给目录跳转时的强调笔划。
- **C-06**（`highlight.ts`、`prose.css`）：自定义一个只写角色的 shiki 主题，每个片段的颜色是 `var(--code-ink)`、`var(--code-key)` 或 `var(--code-note)`；`.shiki` 把三者设成本主题的 `--ink`、`--accent`、`--muted`。运算符（含 Java 文法里被识别成三元运算符的冒号）和标点不着色。原来的 GitHub 两套主题和逐色调亮的替换表一并去掉。
