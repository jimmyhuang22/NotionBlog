# 2026-11-20：作品年份筛选后端（Codex）

从 develop 的 `acb69df` 开始，接续 [#400 后端要求](2026-11-20-works-years-request.md)与 [#403 版式决定](../decisions/2026-11-20-works-years.md)。编辑范围包括社交作品 v2 的查询契约、分页仓储、真实与演示提供者接线和接口交接。

## 接口

- `GET /api/social/works/v2` 与服务端 `socialTimelineRepository.listWorks` 接受 `year`。支持数字年份和 `undated`，可与所选平台及其播放或点赞排序叠加。列表总数与游标按年份筛选。
- `yearCounts` 复用 `LibraryYears`，统计同一份合格快照里该平台各年与无日期的条数。列表选择单年时仍返回该平台的全年份条数。按站点时区使用 `socialWorkPublishedAt` 分年，跨平台作品归首要平台。
- 该功能在作品 v2 分页时计算，无数据库迁移或额外来源读取。封面仍只为当前页补齐。

## 验证

- 39 项专项检查通过，覆盖两种排序与年份叠加、站点时区跨年、合集与跨平台归类、无日期、总数与统计范围、分页和换年份后的旧游标拒绝。v1 路由仍拒绝年份参数。
- 在离线构建的本机 HTTP 服务请求两平台 2025 年的指标排序接口。演示数据每个平台 2025 年 8 件、无日期 3 件，全部年份合计 28 件。切换到 `undated` 后重用原游标返回 400。
- Node 24.21.0 下 `npm run check` 的 3498 项测试全部通过，`npm run build` 的离线构建、构建隐私和本机自托管启动检查也通过。
