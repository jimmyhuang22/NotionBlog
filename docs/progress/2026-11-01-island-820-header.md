# 2026-11-01：岛屿主题 820 宽顶栏不再折成两行（Claude）

编辑登记：Claude 本轮只改 `src/app/globals.css`（820–1023 宽一条岛屿规则）。组件、契约、接口与媒体路由、fixtures、依赖、栏目开关与后端代码未改。

## 问题

[发布 236 上线核对](2026-11-01-release-236-live.md)时发现：岛屿主题在 820、821 宽，七个栏目与站名挤不进一行，顶栏折成两行（高 106），822 起恢复（62）。820 是 iPad Air 竖屏宽度。原因是 2026-10-20 R-03 量“820 起放得下”时字体没有按真实加载量，岛屿的站名更粗，实际差两三个像素。用户让现在修。

## 改了什么

- 820–1023 宽时，岛屿的栏目内边距从 9 收到 8；墨水仍是 9，其他宽度不变。

## 怎么验证的

- 在正式页面上，字体加载完后只注入这一条规则（保留线上原样式和真实字体），岛屿浅色与深色从 761 到 1100 逐像素量顶栏高度：全部是一行（62）；820 宽时站名与第一个栏目之间 44 像素。
- 不注入时同样的量法，岛屿 820–821 为 106，墨水、苹果、千禧 761–1100 都是一行（与发布 236 记录一致）。
- Node 24.21.0：`npm run check` 3249 项全部通过；`npm run build` 通过。

## 限制与下一项

- 没有在 Safari、真机或 iPad 上看。
- 随下一次发布上线，上线后在线上复量 820。
