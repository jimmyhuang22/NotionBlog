# 2026-11-23：学习区可读地址实现（Codex）

按[学习区地址决定](../decisions/2026-11-23-study-readable-urls.md)实现网站 v2 名称登记与读者投影。课程以编号为短名，笔记以课程和页面短名共同定位。首次发布、旧目录回填及撤回后恢复都在现有数据库身份和快照规则内登记。同一课程内改标题或调整父级继续使用已登记名称。旧网站 ID 地址在启用新模式后直接返回 404。

课程、目录和树节点、正文站内引用、面包屑、前后篇、搜索、规范链接和站点地图统一使用新路径。通用笔记数据接口继续使用其记录定位键，网站详情按课程和短名访问。作品库与学习区共用站内链接改写逻辑。可读地址由 `DATABASE_STUDY_URLS=title` 启用，部署与回退按[生产手册](../PRODUCTION_DEPLOYMENT.md#学习区可读地址上线)执行。

隔离库验证了首次分配、同课及跨课重名、多层子页、Unicode、角色隔离、祖先撤回与恢复、增量新增和标题修改。以正式站 13 门课程及 961 个已公开页面的目录字段在本机 PGlite 演练，974 条路径全部唯一且可双向解析。正式站只读取公开目录元数据，响应共约 38 KB。

用实际 Next 构建与隔离发布数据库验证三组新旧课程及笔记地址的 12 次 GET／HEAD，并核对项目入口、目录接口、正文链接、规范链接、搜索、站点地图和撤回父页后的子页 404。新地址返回 200，旧 ID 地址直接返回 404。同步启用作品名模式后重复通过。工程构建及 52 份服务端追踪的隐私检查通过。

Node 24 完整工程检查通过 3,538 项测试。正式库安装、保留作业与交付的名称表核验，以及两站应用切换按正式上线步骤执行。
