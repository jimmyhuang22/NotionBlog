# 2026-10-20：减少请求内重复读取与日期换算（Codex）

- metadata 由每种类型只登记一项，改为按读取预算作用域分组后再按类型登记。在 A／B／A 请求交错时保留 A 原有在途读取，两个独立请求只发起两次 SQL。无作用域仍独立读取，成功／失败后立即清理，不共享跨请求内容或已经完成的资格结果；每个等待者取得独立副本。
