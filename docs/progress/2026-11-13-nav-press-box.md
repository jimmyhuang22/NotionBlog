# 2026-11-13：栏目按下时字后面的方框（Claude）

编辑登记：Claude 修改 `src/app/globals.css`、`src/app/skins.css`。契约、接口与媒体路由、取数层、fixtures、栏目开关、依赖与后端代码未改。

## 起因

发布 #323 上线后用户反馈：切换动态／学习／作品时，“点击的时候背景还是有一个方框”。在正式站点只读录屏后确认有三处，前两处是我上一轮没找到的：

- 页头栏目被按下时，字后面垫一块直角的底色（第五轮按压反馈里给“行与文字”的墨晕），松手后约 0.2 秒才淡掉。这才是用户最早说的“长方形视觉暂留”；上一轮我把它判断成了加载占位块。
- 岛屿主题：刚离开的栏目的黄色胶囊淡出时，圆角先没了，淡出的那 0.2 秒是个方块。
- 加载占位原先等 0.32 秒出现，而正式站点一次栏目切换约 0.45 秒返回，占位刚淡到四成就被内容替掉，仍会闪一下。

## 改了什么

- `globals.css`：页头栏目与“更多”按钮不再有按下的底色，按下时字变强调色；记号本来就在按下时滑走。菜单项、筛选、目录等其余“行与文字”的按压不变。
- `skins.css`：岛屿的页头栏目一律圆角，不只当前项。
- `globals.css`：加载占位改为等 0.7 秒再以 0.4 秒淡入。

## 怎么验证的

- Node 24.21.0：`npm run check` 通过，3419 个测试通过，0 失败、0 跳过（含构建与隐私检查）。
- 本机正式构建，演示数据，无头 Chrome，900，1x：鼠标按住“学习”0.3 秒再松开，四套主题各录一条。墨水下字后没有底色；岛屿、千禧、苹果下按下与离开的栏目都是圆的，没有方块。每个请求加 450 毫秒延迟时，内容到达前没有占位闪现。

## 限制与下一项

- 只在演示数据下验证过，没有真机；触屏上的按压只能靠发布后在手机上确认。
- 正式站点手机宽度切到“作品”的一次轻触录屏里，标题与工具条有约 0.2 秒整块消失；用脚本点击取样时结构正常、没有复现，原因未查明，留作下一项。
- 0.7 秒是按正式站点当前约 0.45 秒的返回时间取的；返回时间落在 0.7～1 秒之间时占位仍会短暂出现。
