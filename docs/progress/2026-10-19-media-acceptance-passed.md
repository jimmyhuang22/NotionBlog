# 2026-10-19：小图与看大图的正式站复验通过（Claude）

编辑登记：Claude（“前端修复：头像弹层和导航栏目”对话）本轮没有改代码，只新增这份记录。

## 起因

2026-10-16 后端登记了 4052 条小图关系，正式站的复验两次未通过。2026-10-17 那次，小图大多要等约 12 秒才退回原图，课程封面一度显示“封面暂时无法显示”。此后后端修了读取路径。用户要求重跑同一份 14 组样本。

## 怎么测的

- 在正式站点上、网站内容同步空闲时进行（状态非运行中、无写入锁；具体站点地址保留私有）。
- 2026-10-18 22:56 UTC 起，无界面 Chrome，1280 与 390 两个宽度。
- 每张小图不跟随跳转直接取一次，比对字节与 SHA-256；每个样本页面打开一次；正文图片再打开看大图。

## 结果

| 项目 | 结果 |
| --- | --- |
| 小图（正文 800、动态与相册 400、作品库与相册封面 400／800，共 20 个请求） | 全部 200，字节与 SHA-256 一致，每个 0.2 到 1.1 秒 |
| 预期保留原图的两个样本 | 跳转到原图，2.4 到 2.9 秒 |
| 页面 | 档位与设计一致；图片 0 到 2.8 秒内显示；没有失败状态、横向滚动或控制台错误 |
| 看大图 | 先显示页面上的小图，正文样本 3.0 到 6.0 秒后换成原图；原图例外约 0.5 秒；都能用 Esc 关闭 |

对比 10-17：那时 20 个小图请求里只有 3 个拿到小图，其余要 9 到 36 秒，其中 5 个 503。
