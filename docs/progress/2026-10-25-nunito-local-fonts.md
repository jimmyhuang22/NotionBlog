# 2026-10-25：Nunito 本地字体与离线冷构建（Codex）

## 编辑登记与实现

用户批准字体资源／全局入口最小修复、离线验证、PR 与常规 develop 合并。基于 f409c32，编辑 layout、skins 的说明注释、新字体 CSS／资源／许可和本项记录；无其他主题排版修改。五个字体共 137,344 字节，内部元数据均为 Nunito 3.602，normal、wght 200–1000；原字节摘要记录在字体 README，版权与官方 OFL 一致。

用本地 CSS 保留五个 Unicode 子集和原 Arial fallback 度量，html 继续通过 --font-nunito 变量类应用；无 preload。Next webpack 输出带摘要资源，五个产物字体 SHA256 均与原字体相同。不改 provider、DTO、数据或运行协议，不新增依赖，不放宽离线网络守卫。

## 验证

无 .next 缓存的离线 webpack build 通过，49 条服务端 trace 排除私人运行文件。完整离线 check 通过：3,014 项测试全部通过、零失败、零跳过；类型及数据库／网站／媒体协议通过。记录格式与隐私检查通过。产物中五个字体均保持原 SHA256，未发现 Nunito preload。

本机专用 Chromium 使用请求拦截提供全部 HTML／字体，拒绝外部目标。对旧生成 CSS 与新 CSS 在 390／1280 宽度、真实字体成功／失败回退共四组比较：截图逐字节相同，文本范围／换行／行高／字体栈／字重相同；非岛屿主题未请求 Nunito。样本包括拉丁、中文混排、粗体、越南语与西里尔文字。最初夹具遗漏 UTF-8 声明导致乱码，该结果不作多语言证明；修正夹具后仅重跑针对性比较，通过并人工查看中文正常。这是隔离字体对比，不冒称完整网站视觉回归或所有浏览器像素一致。
