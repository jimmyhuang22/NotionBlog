# 2026-10-24：B 站 JSON 来源离线改造（Codex）

编辑登记：本项在独立短分支和工作树修改 B 站采集、分类、协议握手、SQL 校验及其测试和说明；不改共享根的其他任务文件或实际业务运行包。用户明确同意本阶段仅离线开发和测试，真实访问、迁移、安装、恢复与部署未授权、未执行。

## 修改与接口

新增如实标注的单视频／合集 JSON 来源，保留旧 SSR。两种表示共用严格字段和完整成员验证，原始 JSON 摘要沿采集、分类、媒体旁记录、outbox、精确 ACK 和播放关联传播；没有伪造 HTML 或扩大 DTO、公开绑定和角色权限。

默认关闭的可选配置绑定既有范围摘要与独立 SQLite。新分类、周期、发现、待审和执行回执隔离，旧暂停和待审不被空目录或新配置抹掉；新来源异常保留人工恢复，缺少能力、准备凭据／范围不符或状态目录不匹配时不发来源请求。

新增事务式兼容迁移，精确核对原校验函数前像，保持函数身份和 ACL，再增加能力标志。完整范围、权限、成员／分 P 和日期检查继续生效；代码不自动安装 SQL 或迁移本机状态。

## 验证与限制

`npm run check` 完整通过：2,609 项测试，失败／跳过均为 0；覆盖解析、旧 SSR、隔离 SQLite／执行、发现与播放关联，以及 PGlite 迁移／权限。源码隐私检查通过；`npm run build` 在隔离演示模式通过，48 项服务端产物追踪排除私人运行文件。

首轮检查保留 7 项失败：检查启动时的 `umask 077` 改变了权限反例夹具，另有周期入口提前读配置影响既有暂停状态。前者改回标准检查环境，后者修复为先保留人工暂停、延后读取来源配置，再完成上述全量检查。首次构建因工作树外依赖软链接无法由 Turbopack 解析而失败；改用既有依赖的本机副本后构建通过，无安装或依赖变更。平台检查未在本轮执行，不把本机或模拟结果写成平台／生产验收。

当前 JSON 接口可用性、实际数据字段及运行效果仍待具体有界验收。来源要求登录、授权或校验时停止，不启用 Cookie、验证码或其他接口回退。真实安装、正常缓存后置预算、任务持续预算和回退前后像仍须准备并明确批准；三个现有社交任务保持暂停，网站同步和历史维护不由本项恢复。
