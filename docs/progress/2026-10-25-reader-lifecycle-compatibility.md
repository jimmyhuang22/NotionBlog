## 修改与目的

来源执行线已准备连接生命周期修复：原池的空闲关闭时间短于续租间隔，续租不断重建连接，最终触发原生连接次数上限。新候选仅在已准入的 source-child 中保留健康空闲连接，直到应用显式结束池；原连接／查询预算、TLS 和停止检查不放宽。该修复仍是离线候选，不能视为新一轮采集成功。

原隔离候选的 host 仍绑定更早的 preload，因此不能直接安装旧七份配置并假定包含这项修复。本轮另建私人组合候选，原样采用来源候选的连接复用、停止守卫和 preload 三个模块；以最新来源 host 为基础，接入已有同步公开账号检查、reader 环境与 URL 一致性检查，以及 reader-isolated 应用入口。新 host 只接受本候选的 preload，拒绝旧入口。

复制的 1,802 项固定输入均核对摘要；其中 1,750 个应用文件保持既有隔离候选原字节。原来源包与隔离包不改，未重复运行应用完整检查或构建。公共 DTO、provider、依赖、数据库迁移和线上权限不变；实际变更仅在忽略目录的离线 host 组合中，本次公共提交只保存进度。

## 验证

最终 14 项检查全部通过、无跳过：

- 四项实际 host 本机检查：正常绑定、网站身份拒绝、URL 不符拒绝、旧 preload 拒绝。
- 四项实际 reader-isolated 子入口身份检查：独立同步公开账号通过；混用组、网站账号、证据身份不能越过公开读取边界。有效公开账号只走到虚构刷新钩子，未运行真实 Auth 或来源采集。
- 一项后置 SQL 适配器检查：身份检查不长期缓存，计数完整，公开账号不能读取私有证据。
- 五项池生命周期检查：复现旧池第九次连接被拒；复用连接完成续租与失败收尾；其他阶段保持原池行为；配置漂移／撤销拒绝；实际 preload 与应用池在加速模拟的 55 分钟节奏中，用一条 TLS 连接完成 110 次 renew 和一次 fail，并显式关闭。

使用本机回环严格 TLS、PGlite、虚构身份和数据，外部网络由 loopback-only 守卫拒绝。模拟时钟不是实际运行 55 分钟，也不证明远端断线恢复或生产同步成功。首轮 13 项是最终 14 项的子集，不累加计数。本轮没有真实项目请求、凭据内容读取、任务启动／恢复、账号／配置写入或部署。
