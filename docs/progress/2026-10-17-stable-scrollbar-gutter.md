# 2026-10-17：滚动条常显时，切换栏目页头不再左右跳（Claude）

编辑登记：Claude 本轮修改 `src/app/globals.css`（根元素加 `scrollbar-gutter: stable`）。契约、接口与媒体路由、fixtures、依赖、栏目开关、全局入口与后端代码未改。

来由：反馈 F20。用户的 Mac 设置了“始终显示滚动条”，在动态、学习、影视等之间切换时导航左右动。反馈审查对话确认：换页时短暂出现比一屏矮的加载占位或页面，滚动条消失，可用宽度从 1265 变 1280，居中的页头整体右移 7.5 像素再回来。

## 改了什么

根元素始终为滚动条留位置（`scrollbar-gutter: stable`），页面高矮变化时版面宽度不变。

## 怎么验证的

只在演示数据下验证：本机生产构建，无界面 Chrome 关掉悬浮式滚动条（`--disable-features=OverlayScrollbar…`，相当于“始终显示滚动条”），1280 宽，从动态依次点学习、影视、书籍、游戏、相册、动态，每次点击后 3 秒逐帧记下第一个导航项的位置。

- 改前：五次切换里导航在 720.5 与 728 之间跳（7.5 像素）。
- 改后：每次都固定在 720.5。
- 关于页（比一屏短）在墨水浅色、墨水深色、苹果、像素深色、千禧下，右侧留出的位置都是页面底色，没有突兀的空白条。

起初用 `::-webkit-scrollbar` 样式模拟常显滚动条，改前改后都跳，说明那种模拟不代表真实的常显滚动条，记在这里免得以后误判。

## 限制

- 悬浮式滚动条（触控板默认、手机）本来就不跳，这次不影响。
- 正式站点要发布后看；用户自己的 Mac 上最直观。
