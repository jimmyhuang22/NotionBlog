## 改了什么

- **快捷搜索按回车打开结果**：原来回车走 `router.push`，换页反馈只认点击链接，所以按回车时旧页面不变暗，慢的时候也没有进度条。`page-switch.tsx` 新增 `announceMove(href)`，用代码跳转的地方在跳转前调用，效果与点按链接相同；快捷搜索的回车（结果、“查看全部”、没有选中时去搜索页）都用它。同一路径（只换筛选或锚点）与点击时一样不算换页。
- **弹窗打开时背后的页面不再滚动**：看大图、快捷搜索、关于卡片三个原生模态对话框，以及窄屏的课程目录抽屉，打开时在根元素上加 `data-held`，`globals.css` 让根元素不滚动。滚动条占宽度的环境（Windows、macOS 设成始终显示）里，滚动条消失会让页面变宽、居中内容右移约 7 像素：只靠 `scrollbar-gutter` 在 Chrome 里留不住这块位置（与 F20 的结论一致），所以锁住时量出滚动条宽度，用同宽的右内边距补上。共用的 `holdPage()` 放在 `use-dismiss.ts`，嵌套的弹窗共用一次锁定；`useModal` 在打开时锁定，对话框关闭或组件卸载时解除。
  - 目录抽屉原来设置 `body.style.overflow = "hidden"`，但根元素是 `overflow-y: scroll`，页面实际在根元素上滚动，那行设置不起作用；现改用同一个 `holdPage()`。
- **切回“明暗跟随系统”后标签页图标立即更新**：原来手选浅色或深色后，两条图标链接都指向所选的图标；切回跟随系统时 `syncIcons` 直接返回，链接停在手选的那张，要刷新才恢复。现在跟随系统时每条链接按自己的 `media` 指回对应的图标。

## 怎么验证的

演示数据本机开发服务器，无头 Chrome（脚本在会话临时目录，不入库）：

- 快捷搜索：按 `/` 打开，输入“笔记”，结果出现后按回车，跳到第一条结果，过程中出现了换页的覆盖层；到达后覆盖层移除、根元素恢复可滚动。
- 锁定：1280 与 800 宽，注入 15 像素的经典滚动条样式（无头 Chrome 默认是覆盖式滚动条，不占宽度），分别打开快捷搜索、看大图（`/preview/blocks`）、课程目录抽屉（800 宽的长笔记）。打开前后页头站名、导航、正文第一块的左边与宽度完全相同，根元素右内边距为 15 像素；在背景上滚轮，页面位置不变；关闭后滚轮恢复正常，内边距移除。390 宽手机模式下目录抽屉同样锁定和解除。关于卡片在演示数据首页没有入口，未单独测，它和另外两个对话框走同一个 `useModal`。
- 图标：先存“深色”，加载后三条图标链接都指向深色；打开主题菜单、打开“明暗跟随系统”后，浅色那两条指回浅色、深色那条指回深色；再切到动态页，仍然正确。
- 全程页面没有脚本错误。
- Node 24.21.0：`npm run check` 3225 项全部通过（含隐私、类型、协议检查）；`npm run build` 通过，49 条服务端追踪不含私有运行文件。本机默认的 Node 26 会遇到已知的无关失败，所以用的是本机固定的 Node 24。

## 限制与下一项

- 只在演示数据和无头 Chrome 下验证。Safari、Firefox 与真机未测；iOS 上锁定根元素滚动从 iOS 16 起生效，更早的版本背景仍可能被手指拖动。
- 浏览器何时重新读取标签页图标由浏览器决定；Chrome 在链接地址改变时立即更新，Safari 未测。
- 锁定期间，固定定位的元素（回到顶部按钮）在经典滚动条环境下会右移一个滚动条宽度，被弹窗背景盖住，不易察觉。
