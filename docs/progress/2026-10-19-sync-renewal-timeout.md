# 2026-10-19：同步续期的驱动连接超时识别（Codex）

## 编辑登记与范围

## 问题与修改

锁定版本的 pg-pool 在建连超时后产生 `Connection terminated due to connection timeout`，原续期白名单遗漏了这条无 code 错误，导致现有有界恢复未执行。增加该精确错误匹配，保留旧字符串兼容、最多三次同一 RPC、原两次退避以及同一 run／fence／seconds 参数；未知、认证、TLS、政策和租约错误仍终止。不重放 stage／promote，不更改数据库资格、锁期限、协议、依赖或发布模式。

终止回执增加来自固定白名单的 reason 分类，保留既有 code、leaseRejected 和 transient；不保存原始 message、cause、SQL 或连接值，未知情况明确保留 unclassified。该字段只用于私有同步回执，不进入网站 DTO。

## 验证

通过本机回环 TCP 接受连接但不完成握手，取得实际安装 pg 驱动的错误，而非手写同名假异常。修复前该回归真实失败、原四项通过；修复后全部八项通过。另验证持续超时最多三次、重新连接后服务端拒绝租约仍立即停止、认证／TLS code 优先，以及嵌套 cause 与相似文字不会扩大重试。

完整工程检查通过类型、三协议、2258 项测试与隐私 1311 文件；随后新增精确缓存过渡，相关 48 项、最终类型与生产构建通过，44 条服务端 trace 排除私有文件。没有将本机结果写成平台通过。私有复现日志与运行包准备保存在本方忽略目录。
