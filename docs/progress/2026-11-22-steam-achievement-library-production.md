# 2026-11-22：Steam 成就多款正式上线（Codex）

用户授权在 GitHub 必需检查通过后普通合并 [#447](https://github.com/jimmyhuang22/NotionBlog/pull/447)，先在新加坡安装数据迁移并导入，再通过私有链路同步到上海。受检源码为 `36ce68f`，普通合并后的正式源码为 `d6b60ad`，两者文件树一致。本机 `npm run check` 通过 3,529 项，`npm run build` 通过。[GitHub 必需检查](https://github.com/jimmyhuang22/NotionBlog/actions/runs/45004760866)和可信隐私检查通过。

按固定允许名单核对 164 款已排除隐藏及私人作品的游戏。15 款无成就，149 款支持成就。支持成就的游戏中，48 款与已公开的站内条目确认对应，另外 101 款待确认站内对应关系。48 款包含已上线的首款，15 款存在解锁记录，33 款的 Steam 进度已明确核对为 0。逐款匹配、数据来源和校验回执留在私有目录。来源、匹配和隔离验收见[多款导入隔离验收](2026-11-22-steam-achievement-batch-verification.md)。

两站沿用已发布的页面、成就详情和图标接口。数据库使用 `004_steam_achievement_batches.sql`，保留单款试点数据和现有 PSN 套组。每批新加坡写入时核对当前隐私排除及站内作品，上海接收时核对压缩包并在事务内比对两站 Steam 全量数据指纹。迁移通过现役服务容器使用的数据库执行。

分七批新增发布 47 款，计入试点后两站各有 48 套、3,327 项 Steam 成就、486 个解锁日期及 2,694 枚已校验图标。两站的 Steam 全量指纹一致，受影响作品的正式 HTTPS 详情逐项核对通过，并从每个有可用图标的新增套组抽查一枚原图。两站的 PSN 仍各有 47 套、2,808 项。

桌面（1280 像素）和手机（390 像素）视口均在两地正式服务通过浏览器抽查。《女神异闻录5皇家版》分别显示 PS4 16/53、PS5 53/53 和 Steam 0/53。切换到 Steam 后可以展开 53 项。上海的复核关闭了媒体和字体加载，图标字节另由正式图标接口核验。

未解锁的隐藏成就保留隐去明细的占位。另有一款作品的 12 枚可见成就图标在 Steam 官方地址复核均返回 404，成就仍显示，以占位图代替缺图。

上海通过既有私有传输链路接收共 31.39 MB 的有效压缩包。一次中断的续传出现重复尾段，按分块指纹保留正确前缀并续传，整包通过 SHA-256 核验后才入库。新加坡遇到锁超时的批次经只读确认基线后继续。正式 HTTPS 验收累计读取约 7.87 MB，两站浏览器抽查累计约 2.89 MB。上线验收结束后，上海按整包指纹核实并清理了七个本轮临时传输包。

下次常规内容交付验收应同时核对本次 Steam 数据及现有 PSN 基线。上海较早的待验内容包生成于本轮导入前，保持待验状态。
