# 2026-11-25：私盘展示图资格查询合批（Codex）

编辑登记：`src/server/database/display.ts`、`src/server/database/display-media-query.ts`、`src/server/database/runtime.ts` 和媒体、采集兼容性测试。适用范围为两站现役 `published`／`scoped`／`private-disk` 展示图。沿用 `/media/v2/`、现有公开与撤回规则、原始媒体限制、浏览器私有缓存以及 Cloudflare 策略。部署仅需更新应用产物，旧采集兼容性测试继续确认新版网站入口不在冻结准入范围内。[回源对照和选择记录](2026-11-25-release-542-dual-site.md)

## 读取行为

同一进程中等待的封面最多合并 32 项。单个批次只占用一条数据库读连接，另一条可处理列表、正文等读取。批次按现有发布版本读取函数与展示图函数在同一 PostgreSQL 语句里核对现役批次和逐项资格。每次资格调用都产生新的数据库读取，读盘后的重查进入后续语句。发现发布批次、修订号或图片描述变化时，沿用原有拒绝语义。批量结果缺项按原单图函数分别处理无资格及展示文件未登记，保留 404 和 503 的差别。

所有读盘、字节完整性校验及撤回检查均使用原有路径。批处理等待窗口为 2 毫秒，队列上限 128；单张请求仍用原来的单图函数。本次复用既有 scoped 和 display 数据库函数，运行配置无需改动。

## 隔离验收

用无外部网络、无宿主机监听端口的 PostgreSQL 17.11 容器，安装现有发布、范围读取、冻结和展示图 SQL，使用合成数据与独立只读网站账号。原版与候选各用两个读连接，实际 HTTP 路径发送 30 张不同页面绑定的 WebP 请求，预热后交替测三轮。原版首字节 P95 为 66.3–74.5 毫秒，候选为 30.8–50.3 毫秒。所有图片内容与私有缓存头一致。小尺寸合成图、同机环回与容器环境下的数字用于比较本轮候选，生产并发和公网耗时另行验收。

读盘期间提交撤回后，在途图片返回空体 404，第二条仍公开的页面绑定继续读取同一份图片字节。读盘期间切换发布批次后，在途图片也返回空体 404，新请求读取新批次；当前页面仍公开但登记缺失时返回 503。只读账号直接访问展示图私表仍被拒绝。定向测试核实 30 张图在两阶段各发送一条批量语句，以及发起批次的客户端取消后，其余请求继续完成。

正式发布验收应保持双站分别检查版本、封面与栏目，并以相同 30 张图复验站内首字节。项目的现有撤回规则继续生效，真实页面的撤回演练使用隔离来源。
