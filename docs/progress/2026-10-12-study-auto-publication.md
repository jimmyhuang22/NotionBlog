# 2026-10-12：全部课程自动公开与目录排序（Codex）

编辑登记：Codex 从最新 main 开独立 `codex/study-auto-publication`，负责独立学习扩展、Notion 发现／父链／排序、网站采集和数据库目录读取。内部配置／writer 契约、Notion client 的可选数据库读取与媒体定位参数有兼容扩展；公开 StudyNode、前端 DTO、页面和组件不修改。Claude 保留视觉和交互；图片任务继续操作既有小图流程。

- 按用户新决定同步 AGENTS、需求、隐私、Notion 配置与网站能力说明，并新增独立决定和学习操作说明，取代网站“单课、逐页名单”；冻结 v1 和旧配置保留兼容。
- 课程来源 all，学习来源 course-descendants；递归实际拥有的子页面、块父级与数据库记录，未来新增自动纳入。外部引用／视图／引用同步块不授予资格，中央 deny 及祖先撤回仍有效；未知父链、权限失败、循环和超限明确失败。
- 单个详情／媒体只核对实时父链；单门目录只发现该课。完整采集发现后重用同一次正文读取，静态自动策略不再提前扫描所有学习内容；临近过期的签名图地址仅刷新该定位并核对同一源文件指纹。
- 第一层数字覆盖优先、再按日期和自然标题；子页按正文位置，数据库内部行按自然标题兜底。统一排序写入私有 ordinal，数据库目录按同一 run/revision 分页读取该课，与 Notion 树一致，前端上一篇／下一篇沿用原数组。
- 独立学习 SQL 包装原 policy/stage，要求已暂存同根课程和父节点、拒绝跨课程身份／循环；受限 writer 在 begin 前做扩展摘要握手。原 v1/v2/媒体 SQL 摘要保持，扩展准备本身不安装、不切换策略。
- 说明数字属性应加在各课程内部笔记数据库、缺失时可选；给出“只填一条会提前”的已确认规则，以及中央 deny 的即时撤回和归档／移出在数据库快照中的时效区别。真实来源和候选配置只留忽略目录。

验证：Node24 的 `npm run check` 通过，包括 1,231 项测试、类型、原冻结协议／新学习扩展摘要及 491 文件隐私检查；`npm run build` 通过，40 份服务端追踪排除私有文件。新增 6 项针对性本地验证覆盖未来课程／子页、排序、deny／归档／移出、拥有数据库／分栏与引用边界、过期定位刷新及源变更拒绝；真实 PGlite 安装、角色限制、新模式发布和旧名单发布均验证。网络／图片为合成输入，未将其称为真实课程发布验收。另仅查询两份真实 schema 和课程总表（3 请求、0 正文、0 图片），结果留私有目录。

局限与下一项：后代数量／新增媒体规模尚未知；本轮没有云 SQL 安装、策略或运行配置替换、真实完整同步、资格续期或站点部署。完整发布按用户交接包另行授权，先满足 PR 自动检查与平台预览、协调 publisher／小图互斥窗口，再执行一次实际 publish；不先跑全量 dry-run，也不扩大原 2 GiB、20,000 记录／16 MiB 等硬限。成功后才交付同一 reader 批次的每课页数／深度、正文代表样本和目录给 Claude。
