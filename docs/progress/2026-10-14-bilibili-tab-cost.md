# 2026-10-14：B 站目录渲染进程成本（Codex）

编辑登记：用户同意接续效率试验，先解决目录标签与 Chrome 进程的对应。本项只记录有限只读测量与取舍；私有观察脚本和证据留 SSD 忽略目录，不更改采集实现、运行包、SQLite、权限、频率、网站或云端内容。

方法：通过 Chrome 的窗口菜单打开任务管理器，识别本项新建目录标签的标题与 Process ID。随后只读采样该 renderer 的 PID、父进程、累计 CPU、RSS 与可执行文件名，不读进程参数或浏览器凭据。正常点击分页并核对数据确实换页，三页卡片数量四十二／四十二／二十五；没有提交目录或重新采集统计。任务管理器在分页后显示相同进程编号，避免把其他 Chrome 窗口的总量当作本项开销。

结果：一秒间隔、五十四帧，首末采样跨度 53.656 秒；累计 CPU 增量 3.63 秒，RSS 起始约 264.7 MiB、观察峰值 350.2 MiB、末值 235.5 MiB。观察从第一页加载后开始，因此不含打开页面的开销，也不代表扩展自然运行的完整单次成本。工具操作和等待使观察窗口比原自然目录采样更长；不能用本次墙钟时间判断自动任务变慢。

限制与清理：RSS 可能包含共享页；renderer 同时执行网页及已有页面注入，数值不是采集脚本自身的独占成本。没有覆盖 Chrome 主进程、GPU、网络与扩展进程，也没有测算本次浏览器流量。样本标签已关闭，任务管理器中对应行消失；本项打开的任务管理器随后关闭，有限观察器正常结束。其他标签和原调度保持。
