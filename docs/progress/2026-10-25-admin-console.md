## 页面与组件

- **总览**：同步状态（空闲／进行中／上次失败／结果未知）、上次成功时间、发布模式、定时安排、待处理数、网站内容版本；“立即同步”按钮，运行时逐步显示进度；上一轮失败或结果未知时单独一张卡片；最近操作。
- **内容**：按栏目切换、标题搜索；可展开的层级（子页面按需读取，失败只影响该分支并可重试）；每行显示状态、Notion 最后编辑时间、子页面数，操作有“同步”（单页）、“冻结”“解冻…”“下架”。
- **冻结／解冻对话框**：先计算影响范围（页面数、图片数），图片仍在 Notion 时拒绝冻结并列出页面；解冻可选“同步一次”或“永久解冻”，提示会被覆盖的控制台修改和会被下架的页面；确认后跟踪进度到结束。
- **下架**：输入地址生成计划，显示目标、子页面数、图片数和过期时间，勾选确认后执行；失败或结果未知时可从计划续办。
- **记录**：定时同步与控制台操作，最新在前。
- **登录**：设置密码后启用；未登录只显示名称。

适配层：`ConsoleBackend` 接口有两种实现，演示后端（内存中的虚构内容，操作按时间推进，可切换四种场景）和桥接后端（启动后端提供的命令，按[对接协议](../CONSOLE_BRIDGE.md)交换 JSON）。后端的能力开关决定显示哪些按钮，旧模式下冻结与单页同步不可用。

安全：只监听本机或指定地址（拒绝 `0.0.0.0`），监听本机以外必须设密码；每个请求核对 Host；HMAC 签名的 HttpOnly 会话 cookie；登录失败放慢与限次；页面禁止嵌入、不收录、不缓存；传给桥接命令的环境只有 `PATH`、`HOME`、`NODE_ENV`。

## 验证

- **只在演示数据下验证过**，没有连接任何真实后端、数据库或 Notion。
- 无头 Chrome，1280 与 390 宽、浅色与深色：总览立即同步全过程，内容页展开、冻结全过程、图片未就绪的拒绝、解冻对话框，下架计划到核验完成，记录页；390 宽无横向滚动。修复了展开时在状态更新函数里触发读取导致的 React 报错，复查无报错。
- 设密码时：页面跳转登录、接口返回 401、错误密码提示、正确密码进入、cookie 脚本不可读；启动脚本拒绝 `0.0.0.0` 和无密码的外部地址；未知 Host 返回 421。
- `tests/console-backends.test.ts` 12 项通过：演示后端的同步、冻结、解冻、续办下架、旧模式；桥接后端的请求格式、错误码透传、坏回复、环境不外传、相对路径；配置规则；会话签名与过期。
- `npm run check`：类型检查、协议检查、隐私检查通过；测试 2768 项中 31 项失败，全部在 `website-v2-runtime`、`qualified-shared-budget`、`capture-recovery-host`、`capture-recovery-admission` 四个文件，原因是发布校验要求 Node 24，本机为 Node 26，与本项无关。`npm run build`（网站）与 `npm run console -- build`（控制台）均通过。`eslint console`（不含构建产物）无问题。
