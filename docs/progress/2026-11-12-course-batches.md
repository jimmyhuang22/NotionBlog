# 2026-11-12：整门课程自动分批（Codex）

## 编辑登记与改动

本项涉及管理后端、增量 host/CLI、冻结弹窗与批处理测试。按最多 15 页、目标 40 个原图资产分批（单页最多 100 个可独立成批），后端持久保存步骤并顺序执行；每批读取当前版本与冻结代数。host 对内部 refreshPageIds 验证格式及冻结组归属，准备时未轮到的组成员保持冻结，避免父级目录把其他批次带入当前增量，保留发布层硬限制、独立 reader 与队列恢复。CLI 显式传递选择，不允许普通恢复命令夹带刷新选择。

冻结按 50 个媒体描述符分批核验后统一提交。冻结按钮由操作类型决定，预览失败不再误显示“同步一次”；提示说明分批语义。东京专用 display 适配器与部署记录保留在私有运维目录，不含公共仓库中的来源身份或凭据。

最新 develop 的按压反馈 CSS 缺少一个媒体查询闭合括号，导致生产构建失败；本项仅补齐该括号，没有重新设计样式或部署正式站。

## 接口与 provider

仅内部 ManagementPorts.refresh.pageIds 和 host.refreshPageIds 可选输入；原浏览器 JSON DTO、SQL 协议、默认 provider 与定时任务配置不变。冻结的同步一次保留组保护，逐批原子发布；前批成功后后批失败不冒充整项成功，unknown 不重放。

## 限制与下一项

预分批保留余量，但单页超过 100 个原图资产、重大父子关系变更导致准备结果超限时仍拒绝，不放宽数据库协议。总时长、字节与请求预算继续限制单项任务。正式站采用和域名切换不在本项范围。
