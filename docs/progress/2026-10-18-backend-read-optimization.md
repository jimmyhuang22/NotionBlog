# 2026-10-18：后端读取性能优化（Codex）

编辑登记：用户批准架构审查后的优化。本项从最新本地主线建立独立分支，负责受限 SQL、database repository、首页／搜索服务入口与取消和连接生命周期；不修改 Claude 的页面、视觉、组件或既有同步任务，初次交付后，用户另行批准安装迁移并准备启用；本次不改正式开关或部署。

- 新增显式 opt-in 的 scoped 读取扩展，沿用原 qualified／published 当前批次、父链、中央下架与版本门控。链接只检查实际引用，媒体 owner 查询内去重；reader 仍不能读表、写表或调用私有 helper。
- 动态在聚合前选取本页正文，修复少量分页仍被整栏正文超过 16 MiB 阻断的问题；完整导出和单次正文批量边界保持。排序每次操作只解析一次时区，重叠 metadata 在途合并不跨取消作用域、不保留已完成结果。
- 搜索一次读取有界文字片段及目标／图片资格标记，显式栈保留深度优先顺序及 32 层边界，应用逐片段脱敏、清理引用后沿用原匹配，结束时重新核版本；无持久索引或资格缓存。内部链接及图片说明继续随目标资格撤回，正文的格式、URL 和不支持块标签不进入搜索文字。
- 首页／时间线先按无正文 metadata 选择页面，再批量读取所选动态，保留排序、总数与完整预览；为此新增两个可选的服务端 repository 能力，不增加公开 DTO 字段或 HTTP 接口。
- HTTP 搜索／时间线与首页增加整轮期限及取消检查；在途 SQL 正常排空后再返回失败。内容池接入既有托管生命周期辅助库，保留 max=2 和原超时，日志只记录固定类别和安全错误码。
- 默认仍为 legacy。三份独立迁移已安装、摘要登记并通过原受限 reader 的真实数据验收；scoped 配置切换与正式发布仍按运行说明单独执行，尚不宣称正式网站已经提速；原网站同步暂停及其他任务保持。

验证：初次交付在 Node 24.21.0 下完整 `npm run check` 通过 2,195 项测试。真实验收修复后的最终完整检查再次通过全部 2,197 项测试、类型／协议和 1,200 项隐私扫描；`npm run build` 通过，43 项服务端产物追踪未包含私有运行文件。无取消作用域时不共享 metadata 的隔离要求继续保留；新增栈遍历深度顺序／边界及缺失第三项能力的失败封闭回归。三个 capture 兼容清单仅更新原有 after 精确摘要及引用链，没有扩大 before、允许路径或生产者范围，冻结运行包未安装。

初次完整检查在一项既有本机 HTTP 连接测试中触发 Node 原生断言；单独复现后，允许本机回环监听即通过，随后同代码完整检查全部通过，原失败日志保留。初次构建因复用依赖的跨目录软链接被 Turbopack 拒绝，改为相同已安装依赖的本地副本后通过；没有更改依赖或锁文件。隐私扫描 1,198 项及差异检查通过，不将本机通过写成平台或正式环境通过。

实际实现的离线对比使用 300 条虚构动态、300 条笔记及 2,400 项媒体，最大祖先链 13 层；同一 PGlite 数据、同一 Node 24 进程，预热后交替采样五次。表内为中位数，四项完整 DTO 均相同；SQL 次数不包含预热时的能力握手，字节为 driver 返回 rows 的 JSON 序列化量，不是 HTTP 或协议层流量。

| 请求 | legacy → scoped 中位数 | SQL 次数 | 返回 JSON 字节 |
| --- | --- | --- | --- |
| 单条 metadata | 81.26 → 1.58 ms | 1 → 1 | 486 → 486 |
| 动态列表十二条 | 366.80 → 20.54 ms | 2 → 2 | 350,552 → 350,568 |
| 全栏目搜索 | 1,340.86 → 98.08 ms | 15 → 2 | 7,212,990 → 543,615 |
| 首页十二条 | 275.87 → 32.41 ms | 1 → 4 | 7,096,394 → 367,492 |

首页先比较过逐条读取方案，虽减少正文传输但造成十五次 SQL，最终改为一次正文批量读取；四次包含 metadata、批次／资格版本核对与正文批量读取。额外往返与字节收益仍须在真实同区环境对比。合成文本重复且没有真实网络，以上数值不作为线上收益或 p95 承诺。

局限：列表仍读取合格 metadata 后按既有日期／标题规则排序，社交仍读取当前快照；搜索仍扫描文本，没有将三元索引合成实验冒充真实索引收益。最终目标分支新增的作品页样式与独立社交封面来源修正没有修改本项后端、契约、协议或依赖，未为无交集变化重做页面；正式发布仍对最终集成版本验证。下一项为当前发布冻结解除后的代码整合和用户选定的正式配置／发布验收；已安装云端只读扩展，未改正式开关、采集内容或部署网站。

补充安装验收：初版紧凑 AST 的真实搜索超时；专用引用扫描也未解决，改为文字片段后仍观察到逐块 SQL 的开销，最终采用显式栈。已经安装的迁移不改字节，通过独立补充迁移及三项摘要握手修正。真实正文离线比较包括五组完整搜索 DTO，以及递归／栈遍历的完整原始投影逐项相等；原失败回执保留。最终云端受限 reader 的 18 项检查全部通过，覆盖权限拒绝、当前 schema、metadata／详情／列表／年份／课程目录一致性、中英文搜索、首页两页与错误版本拒绝；未在云端制造下架或修改真实内容。撤回、模式／epoch／过期与 32／33 层边界由本地回归验证。

一次独立云端完整搜索 SQL 约 2.7 秒，本机远程读取中英文搜索约 4.3–4.8 秒；其中包括传输、解析及应用工作，不能等同于网站页面耗时或正式同区 p50／p95。当前仍扫描全部合格搜索文字，正式发布后必须复测实际页面。安全检查仅新增私有摘要表启用 RLS 且无直接访问策略的预期提示，未为消除提示向 API 角色开放表。
