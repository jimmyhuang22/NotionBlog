# 2026-10-14：游戏最近游玩日期修复（Codex）

编辑登记：本轮在独立 `codex/game-recent-played-date` 修改 Game 兼容字段、Notion v2 映射和日期读取、共用浏览日期、mock、日期显示、同步输入校验及相关测试和说明。保留其他会话的图片、增量发布、运行预算与调度工作。

## 变更

- Game 增加可选 `lastPlayedDate`；原 `playedDate` 继续表示人工体验范围。游戏年份、筛选、日期排序和页面分组优先采用平台日期，缺失时回到原日期。
- v2 支持明确映射普通日期或 `latest_date` 日期 rollup；不完整、不支持或错误聚合明确失败。网站发布校验接受新字段并兼容旧快照，冻结 SQL、协议摘要与权限不变。
- 游戏详情分别显示最近游玩、体验日期，默认排序标为最近游玩；未改变现有布局与栏目开关。mock 增加明确虚构的最近游玩样本和无日期兼容样本。
- 获准作品库增加关系日期汇总属性；独立复读确认其他 schema 属性保持。具体来源、原属性基线和真实读取证据保存在忽略目录。
