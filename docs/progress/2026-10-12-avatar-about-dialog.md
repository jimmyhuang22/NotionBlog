# 2026-10-12：点头像看“关于”，导航栏目平铺（Claude）

编辑登记：Claude 本轮前端修改与验证完成。范围：`src/app/layout.tsx`（全局入口：导航去掉“关于”，页脚加“关于”链接；用户本人提出）、`src/app/page.tsx`、新增 `src/components/about-dialog.tsx`、`src/components/browser-document.tsx`（多一个可选的空正文文案）、`src/lib/nav.ts`、`src/lib/request-cache.ts`、`src/app/globals.css`、`src/app/motion.css`、`src/app/skins.css`、`tests/nav.test.ts`、前端接手说明、需求说明与一条决策记录。没有新依赖；契约、fixtures、栏目开关、`src/app/api/` 与 `src/app/media/` 未改。

起因是反馈审查对话转来的三项要求（点头像弹出关于内容、导航去掉“关于”、影视书籍游戏相册平铺）。三处需要用户定的地方各出了三个做法的对比图，用户都选了第一个推荐项，另定了页脚留链接；决定见 [关于页从头像进入，导航栏目平铺](../decisions/2026-10-12-about-from-avatar.md)。

## 改了什么

- **导航**：去掉“关于”。栏目不超过六个时全部平铺，超过六个时爱好类才收进“更多”（`splitNav` 与 `NAV_ROW_LIMIT`）。线上现在的组合是动态、学习、影视、书籍、游戏、相册六个，全部平铺。
- **平板附近的断点**：六个栏目平铺后，像素主题在 761 到 798、千禧主题在 761 到 767 宽度下搜索和主题按钮会被挤到第二行。这两套主题在六个栏目时把“两行页头”延到 800。墨水与苹果不需要，也没有动（它们的吸顶高度按 760 分档）。
- **头像**：关于页可读时，首页头像上盖一个指向 `/about` 的链接，右下角一枚小圆标；鼠标指上去或键盘聚焦时外圈上墨、头像轻轻歪一下（像素主题是方形虚线框）。普通点击在当前页打开弹层，带修饰键的点击、新标签页和没有脚本时照常进入 `/about`。
- **弹层**：原生模态对话框，标题“关于”、正文、更新日期。第一次打开才请求 `/api/pages/about`，之后再开不重复请求。加载中是三条淡色短条；失败和暂时读不了各有说明并可重试；这一页在首页画出来之后被撤下时写“这一页现在看不了。”；空正文写“这一页还没有内容。”。Esc、关闭按钮、点遮罩都能关，焦点回到头像；正文里的站内链接先关弹层再跳转。
- **可读才给入口**：`isAboutAvailable`（`page` 开关开着并且这一页已发布；检查慢或失败都算不可读）决定头像链接和页脚链接是否出现。两处各在自己的 Suspense 里，首页的个人介绍和整页外壳都不等这次检查。头像外面多了一层固定的 `.hero__avatar`，仍是介绍区的第一个子元素，依次入场的顺序没有变。
- **页脚**：多一个“关于”链接，进入 `/about` 页面。`/about` 页面本身没有改。

## 限制

- 真实内容没有看过：真实关于页的长度、图片比例、代码或公式在弹层里的样子，要等真实数据预览。
- 弹层不改地址，手机上按返回会离开首页而不是关掉弹层；搜索面板也是这样，用户知情。
- 内容服务慢的时候，头像链接和页脚链接是稍后才流进页面的，那种情况下没有脚本就看不到这两个入口（首页时间线也是同样的机制）；`/about` 直接访问不受影响。
- 页面还没变得可交互时点头像，会像普通链接一样进入 `/about`，不是弹层。
- 六个栏目的上限按两个字的栏目名量出来；栏目改名或加了更宽的主题要重新量。
- 没有在 Safari、Firefox 和真机上看；没有用读屏软件实测。
- 与本次改动无关、顺带量到的：站名较长（线上是 18 个字符）时，手机上第一行放不下站名和两个工具按钮，按钮会独占一行，页头变成三行——像素主题在 390 及以下，苹果与千禧在 320。这在改动之前就是这样，没有在本次处理，已单独提出。
