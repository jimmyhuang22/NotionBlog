编辑登记：Claude 修改 `src/components/work-detail.tsx`、`src/lib/work-record.ts`、`tests/work-record.test.ts`、`src/app/library/[type]/[slug]/page.tsx`、`src/components/library-detail-loading.tsx`、`src/app/library.css`、`src/app/skins.css`、`docs/FRONTEND_GUIDE.md`，新增决策 [游戏详情改为“全幅主视觉”](../decisions/2026-11-19-game-detail-art.md)。契约、接口与媒体路由、取数层、fixtures、栏目开关、依赖、站点配置与后端代码未改。

## 改了什么

- 游戏详情：横版图铺满并渐隐到页面底，图上是游戏名和平台；左栏状态、评分、时长（加预计条）、时间线；右边标签、正文、上一款 / 下一款。
- `gameRecord` 去掉目录和空标题。
- 上一 / 下一的说法三类统一为“部 / 本 / 款”并都带小图，游戏用横版小图。
- 详情页里旧的通用信息区（`facts`、`Lead`）与它的样式删掉；苹果、岛屿、千禧给旧详情标题的字重转给三种新标题。
- 游戏的加载占位换成同样的形状；游戏页预加载 1600 宽的图。

## 怎么验证的

- 本机正式构建加临时预览页（未提交，已删除），用线上取下来的真实记录：《塞尔达传说 旷野之息》（有评分、预计、正文）、《杀戮尖塔2》（无评分、无预计、无正文）、《艾尔登法环》（在玩，正文有 B 站链接和勾选项）、《守望先锋2》（白金，正文是图片），以及去掉封面的《杀戮尖塔2》。
  - 墨水浅色 1280、深色 1280、390；岛屿、千禧、苹果 1280。
  - 没有横向溢出；渐隐后岛屿的条纹、千禧的网格照常露出。
- 预览页的“上一款 / 下一款”是照真实标记手写的，日期是占位字。
- `tests/work-record.test.ts` 11 条。
- Node 24.21.0：`npm run check` 与 `npm run build`，结果见合并请求。

## 限制与下一项

- 线上真实路由没看过；影视、书籍、游戏三页都要在发布后挑旧记录核对。
