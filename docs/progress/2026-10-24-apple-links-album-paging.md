## 改了什么

- **U16**：苹果与千禧的 `.rt-link` 原先 `text-decoration: none`，改为 1 像素直下划线，颜色为强调色 45%、下移 3 像素，悬停时与墨水一样加深为文字色。苹果时间线标题、千禧“展开全文”悬停等不属于正文链接的规则保持原样。
- **U18**：相册页只读第一批 50 个、不处理后续页。改为新组件 `AlbumGrid`：服务端照旧取第一页 50 个，之后用共用的 `usePagedList` 与 `ListTail` 滚动加载（失败可重试、返回时恢复、内容版本变化时从头重载），卡片标记与样式不变。相册不到 50 个时 `paged` 为假，不画列表末尾，页面与之前一致；空列表仍显示“还没有相册。”。

## 怎么验证的

见合并请求：`npm run check`、`npm run privacy:check`、`npm run build`；演示数据下苹果、千禧的正文链接截图与悬停，相册页在默认页大小下与之前一致，临时把页大小改小后滚动加载与“已显示 N 个相册”。
