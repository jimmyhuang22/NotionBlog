# 2026-10-12：网站同步原件复用（Codex）

编辑登记：本轮只修改 `scripts/website-sync/download.ts`、新增原件缓存模块、同步 CLI 的可选配置及对应测试／说明，需求补充网站同步效率一节。保留 v1 下载器、SQL、DTO、页面、缩略图生成与其他聊天的编辑范围。

- 可选缓存已接入 v2 下载器与 CLI；完整 GET 后保存强验证器，当前来源确认未变化且本机原件核对通过时复用。改变的图片照常下载，缺失／损坏缓存重新下载，不安全文件配置明确失败；拒绝、限流和不一致的 304 不返回旧内容。
- 支持只读使用既有原件镜像；每个被使用的对象独立核对 SHA／大小／格式／私有文件属性，不扫描全库或改镜像索引。仅保存摘要和验证记录，不持久保存签名地址。S3 认证参数更新不影响键，其他查询参数的原始编码／顺序和请求表示保持隔离。
- 三张小样本可行性检查通过；实际实现首次消费 16,749 字节，持久缓存重建后的第二次三张均重新验证、图片正文下载零，三个已有原件复用、额外复制零。首次约 5.23 秒、复用约 4.89 秒，不推算全库支持率或完整同步时间。特殊查询编码修正由离线用例覆盖，不重复线上整库验收。
- 开发验证缓存及现有下载器的 33 项相关测试和类型检查。首次测试夹具用了系统临时路径别名，被规范路径守卫正确拒绝；改用 realpath 后通过，生产守卫未放宽。完整检查的类型／三协议和 1,155 项测试通过；两次完整检查均在最后隐私阶段标记虚构签名 URL，第一次修正漏掉了普通 signature 参数。最后全部改为 URL API 生成虚构参数，只复验受影响的 9 项测试及 447 文件隐私检查，通过后未第三次重跑全量测试。生产构建只运行一次，39 份服务端追踪检查通过；原日志保留，未把失败命令写成整条 check 成功。
- 暂存差异复核补齐缓存／镜像目录隔离，重叠配置在写入前拒绝；该脚本守卫及测试只复验 9 项缓存测试与类型检查，均通过。网站模块、协议和依赖没有新变化，复用现有构建结果，不再次跑整套构建或线上图片样本。
