## 修改、接口与 provider

搜索页与快捷搜索共用来源行，课程优先编号、缺失用名称，父级按物理顺序显示纯文字，链接可访问名称包含区分信息，仍打开原目标。长标签自然换行，快捷搜索选中高行后保持可见，末尾入口至少 44 像素。保留换词保护、输入法及原位恢复。

`SearchHit.context` 可选可空，旧响应兼容，不改变匹配、排序、总数和其他栏目。Mock 提供三条同名的跨课／不同父级示例；Notion 复用已核对元数据，不增加读取。数据库独立扩展及默认关闭配置支持两种 publication 与四种读取组合，对返回的一页额外一次有界元数据 SQL，保留末尾版本复核；冻结 SQL、原 schema digest、运行包及业务调度保持。

[决定](../decisions/2026-10-23-search-result-context.md)和[实现说明](../SEARCH_RESULT_CONTEXT.md)列明上限、未知与失败区别、模式前提和未来安装边界。未读取真实来源、执行云端 SQL、安装扩展、启用开关、合并 PR 或部署。
