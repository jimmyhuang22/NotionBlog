`SearchHit.context` 可选可空，旧响应兼容，不改变匹配、排序、总数和其他栏目。Mock 提供三条同名的跨课／不同父级示例；Notion 复用已核对元数据，不增加读取。数据库独立扩展及默认关闭配置支持两种 publication 与四种读取组合，对返回的一页额外一次有界元数据 SQL，保留末尾版本复核；冻结 SQL、原 schema digest、运行包及业务调度保持。
