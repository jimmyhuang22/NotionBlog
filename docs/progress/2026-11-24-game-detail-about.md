## 做了什么（按 [决策](../decisions/2026-11-24-game-detail-cards.md) 和第六轮原型）

- **简介**：写在主视觉上的平台下面。两行、半透明深色底，“简介全文”就地展开，“收起”合上。是否超过两行在页面画好后量；没有简介就不出现。
- **“关于”卡片**：加上开发、发行两行（几家用“、”隔开），只写有的；开发、发行、类型都没有时整张不出现。
- **“游玩录像”卡片**：放在左栏最下面。
  - 对上已公开的作品时，用作品页的卡片（封面、播放数、最后更新）；
  - 对不上时，是一个“B 站视频”加地址的链接；
  - 有录像字段时，正文里“游玩录像”那一节（标题和下面的书签）不再重复显示。
- **手机顺序**：我的游玩、时间线、正文、关于、游玩录像、上一款 / 下一款。

## 怎么验证的

- 本机演示站点加一个未提交的预览页。用线上《女神异闻录5皇家版》《识质存在》的详情接口数据，手工加上 `about` 和 `playVideo`。看了以下几种情形：
  - 有三段简介、开发、发行、对上作品的录像；
  - 一句短简介（不出现“简介全文”）、只有开发、只有地址的录像；
  - 没有新字段（和现在线上一样，正文里的“游玩录像”照常显示）；
  - 只有开发、发行、没有简介。
- 宽度和外观：1440 与 390，岛屿浅色，墨水深色。没有横向溢出，没有报错。
- 修了一处：收起时第三行从底色的内边距里露出半截，改成把截断放在里层。
- 单元测试：`gameNotes` 去掉“游玩录像”一节。
- Node 24.21.0 下的 `npm run check` 与 `npm run build`，结果见合并请求。

## 限制与下一项

- 录像卡片用的是演示作品，真实作品要等 Codex 把新字段的映射在正式环境生效后，才能在线上看到。
- 正文里《女神异闻录5》那节“游玩录像”，等用户核对后由 Codex 从 Notion 删掉；在那之前，有录像字段时页面已经不重复显示。
