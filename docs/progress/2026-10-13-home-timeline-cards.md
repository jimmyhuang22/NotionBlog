# 2026-10-13：动态卡片贴合内容，一句话的动态也成了卡片，卡片底部不再多一行空白（Claude）

编辑登记：Claude 本轮前端修改与验证完成，范围为 `src/components/status-body.tsx`、新增 `src/lib/text-runs.ts`、`src/app/timeline.css`、`src/app/skins.css`（删去一处不再使用的选择器）、`tests/text-runs.test.ts`、前端接手说明。契约、接口路由、fixtures、依赖、栏目开关与后端代码未改。

来由：在正式站点的首页看了一遍真实内容（1280 与 390 宽各一次），时间线上有三处不整齐，报给用户后用户说都做。

- **卡片底部多一行空白**：有的动态卡片下边比别的高出一行。原因是列表里的动态文字多半以换行结尾（抽看线上 50 条：38 条以一个换行结尾，6 条以两个换行结尾，其余没有正文），卡片保留换行显示，两个换行就成了一行空白。现在显示前去掉文字首尾的空白，中间的换行原样保留。
- **卡片宽度**：动态卡片原来一律占满整栏（约 666），作品卡 560、栏目小卡片 460、单张图 420，往下滚时右边参差。给用户看了四种做法的对比图（现状、都占满整栏、贴合内容、都不超过 560），用户选了“贴合内容”：动态卡片随文字宽窄，短的就是小卡片，长的占满整栏。
- **只有标题的动态**：原来是时间线上的一行字，和有正文的卡片交替出现。给用户看了两种做法（含手机），用户选了“放进小卡片”。

具体做法：

- 动态卡片宽度贴合内容，最宽到整栏；有正文的最窄 280，免得两个字撑出一张按钮大小的卡片；只有标题的不设最窄宽度，上下留白也小一些。
- 展开全文后卡片占满整栏，收起后回到贴合内容。
- 动态页（`/status`）用的是同一个组件，一并改变。
- 作品卡、栏目小卡片与图片的宽度没有动。
