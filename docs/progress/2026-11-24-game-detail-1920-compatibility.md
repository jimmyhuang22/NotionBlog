# 2026-11-24：游戏详情背景 1920 兼容接入

Codex 编辑展示图的宽度解析、校验与离线编码入口、游戏详情背景 CSS 和响应式预加载。游戏详情在桌面为宽于 1600 的展示媒体源选用 1920 请求，小屏仍选 1600。1920 作为可选派生图，老发布缺少新图时沿用现有最大展示版。`cover`、`boxArt` 和平台时长契约沿用现有字段。

按后续讨论采用 1600／1920 分档。小屏继续使用 1600，大屏优先使用 1920。未来待办只回收无引用的派生副本。已写入需求和[决定](../decisions/2026-11-24-display-1920-migration.md)。

定向验证覆盖新旧媒体请求、缺少新图时的回退及非法宽度。离线浏览器在 390、1023、1024 和 1440 CSS 像素宽下核对实际背景和预加载，只发生一次图片请求。现有原图样本和浏览器记录留在私有目录。

私有发布侧仍需扩展展示登记规则，其现有审核摘要校验会拒绝未审扩档。现役映射按发布版本不可就地更改，1920 派生数据应随新版本通过既有源绑定、对象摘要、两站签收和回退验证。后续测完生成与交付体积再安排生产切换。此阶段验证的是应用兼容读取和本机编码，无项目云端读取或写入。
