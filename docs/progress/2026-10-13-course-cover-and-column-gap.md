# 2026-10-13：课程封面的失败状态与分栏链接间距（Claude）

编辑登记：Claude 本轮前端修改与验证完成。范围：新增 `src/components/cover-image.tsx`，改 `src/app/study/[course]/page.tsx`、`src/app/study.css`、`src/app/prose.css` 和前端接手说明。没有新依赖；契约、fixtures、栏目开关、接口与媒体路由未改。

来由：发布 186 后在正式站点复验时看到的两处小问题（见 [发布 186 前后的真实内容复验](2026-10-13-release-186-live-check.md)），用户要求修掉。

## 改了什么

- **课程封面**。原来是普通图片，加载失败时露出浏览器的破图标和替代文字。现在用 `CoverImage`：加载失败时显示和正文图片同一种浅色块，写“封面暂时无法显示”；封面还没到时原位是一块浅色，来源给了宽高就按比例先占好位置，到了之后浅色撤掉（透明底的图不会透出底色）。封面常在页面可交互之前就已经失败，那时收不到事件，所以组件挂载时会检查图片当时的状态。
- **分栏里的子页面链接**。只装子页面链接的分栏，下边距从 18 改成 10，和一条子页面链接的下边距一样。手机上两栏叠起来后再接一条子页面链接，三条之间都是 10，读起来是一组；电脑宽度下也一样。分栏里有别的内容时不变。

## 接口与 provider

没有新的取数。封面仍是站内媒体路径上的普通图片，不经过图片优化缓存；预览档位照旧是 800。

## 怎么验证的

只在演示数据下验证：演示课程没有封面，分栏的这种组合演示内容里也没有，所以用了一个不提交的临时页面，放手写的虚构封面与正文，查看后删除。本机无界面 Chrome。

| 项目 | 结果 |
| --- | --- |
| 封面正常 | 显示，1280 宽时高 280、390 宽时按比例 133 |
| 封面地址不存在 | 显示“封面暂时无法显示”的浅色块，上边距与封面相同；无替代文字时读屏名称是“课程封面” |
| 封面迟到（请求被按住） | 原位是浅色块、已占好高度；放行后正常显示，浅色撤掉 |
| 透明底的封面 | 到了之后没有底色 |
| 生产构建、脚本被按住 | 页面可交互之前封面已是破图；脚本放行后变成失败状态，控制台没有报错 |
| 链接分栏后接一条链接 | 1280 与 390 都是 10（原来 18）；叠起来的两栏之间 10 |
| 链接分栏后接文字、接另一组链接分栏 | 都是 10，与单条链接后接文字一致 |
| 有文字的分栏后接链接 | 仍是 18 |
| 链接分栏在正文最后 | 卡片底部不多留空 |
