# 2026-10-24：后端审查首批源码修复（Codex）

编辑登记：从当时最新 develop 建立独立工作树；本项修改隐私检查及其现有 Git/CI 接线、内容 provider 与路由缓存判定、游戏与社交任务清理、学习增量链接和增量队列恢复入口。根目录其他任务的未提交文件不纳入本项。

## 修改

- B01：补充带密码的 PostgreSQL URL、JWT、云访问标识、私钥正文和凭据变量赋值检测；拒绝任意命名的 `.env` 私有文件，暂存检查覆盖类型变更。历史模式逐提交检查文件树，包含最终被删除的秘密；pre-push 与现有托管工作流接入历史检查，无新依赖或第三方动作。隐私检查移至完整检查首项。错误只输出文件与类别，不输出匹配值；工作区符号链接不跟随读取。
- B04：生产环境必须显式配置内容 provider；启动配置和请求读取均拒绝缺失／非法值。本机隔离演示仍显式设置 mock；用户明确选择 mock 的部署不被禁止。
- B05：签名前和内部接口验签后共用路由规范化，只保留 Status 判定所需的 focus。重复、空值或非法 focus 仍为无效请求，不能规范成合法详情；无关参数不再扩大判定缓存键。
- B06：游戏 CLI 的父进程持锁，业务工作进程超时先终止、必要时强制停止，确认退出后才释放锁；失败通知保留并提示查看错误码，增加显式 `unlock-stale`。小红书配置／会话初始化移入 try/finally；原生宿主在处理消息前安装取消监听；增量 CLI 使用持续监听，重复取消不会消耗唯一清理机会。
- B02：两处学习链接重写共用同一个函数，撤回时清除外层标题，改名时同步外层标题；数据库 DTO 投影也遮蔽已有空 target 的旧标题。
- B07：单页准备失败不再直接结束整轮；永久图片拒绝转人工检查。利用既有尝试账本按世代计数，指数退避，五次失败后保留为待检查。未知提交和未验读取仍阻止进一步发布。历史待检查项不会覆盖本轮 retry 结果；新事件仍记录，可在列表看到新变化。显式恢复增加世代，重置该次人工恢复的重试计数，不自动解除任何 hold。

## 接口与运行方式

公共 DTO、数据库协议、来源配置、栏目开关、依赖及生产环境变量未修改。历史扫描新增 `node scripts/check-privacy.mjs --range BASE..HEAD` 和 `--history HEAD`；新分支推送扫描可达历史，已有远端提交可用时扫描提交区间。Git 钩子仍需安装；CI 独立执行，不依赖开发者安装钩子。

增量 CLI 新增本机 `list-review` 与 `resume`，均要求现有配置、运行目录和发布锁目录；后者另要求 source/page。前者每次最多列出 100 项，可用 source/page 作为上一页末项的游标。只打开已存在且匹配配置的私有队列，并取得发布者同一把锁；没有云数据库连接、来源采集或实际发布。输出含私有工作标识，只供本机操作人员使用。

恢复仍须由操作人员明确执行；源码合入不自动安装到私人运行根，也不恢复已暂停的游戏、社交、网站或维护任务。

## 验证

已加入针对凭据类型、中间提交、暂存类型变化、生产配置缺失、签名后查询规范化、撤回标题、锁截止及配置异常清理、队列退避／永久错误与实际恢复 CLI 的离线回归。使用已有本机依赖、Node 24.21.0 和离线出站保护，完整 `npm run check` 的类型、协议、隐私与 2,604 项测试通过，零失败／取消／跳过。锁收尾的两项进一步修正完成后，受影响 12 项测试与类型检查再次通过；其他代码保持受检字节。`npm run build -- --webpack` 及 48 份服务端追踪隐私检查通过，字体来自已有本机缓存，未为构建访问真实来源。记录、链接、差异和暂存隐私另行收尾。

首轮完整检查使用 shell 默认 Node 26，并受沙箱本机端口限制，存在失败；改用已有 Node 24 和获准的 localhost 虚构服务后完整通过。没有放宽运行器 Node 24 要求、冻结版本或外部出站保护。历史扫描在分支基线检查了 1,974 个提交文件版本并通过；这仅表示未命中现有规则。

旧运行包兼容性测试只更新当前读取器的精确摘要断言，并继续断言该新版不能进入旧许可；冻结兼容目录、协议与真实运行包均保持原样。

针对性验证期间发现并修正了 CLI 返回联合类型和 IPC 可选方法的类型问题。两条旧断言分别仍允许过时的外层标题、要求人工恢复不增加世代，现按修复后的语义更新；保留这些初次失败，不将其写成首次全通过。

## 局限与下一项

B03 数据库角色拆分及当前生产权限尚未实施或在线核查；源码迁移中的授权不代表已核实当前目标实际权限。GitHub 密钥扫描与推送保护已在用户单独明确批准后启用，更新响应和独立回读均为 enabled，见[决定](../decisions/2026-10-24-secret-protection.md)。规则扫描不是对任何秘密的完整证明，个人来源值仍依赖私有 blocklist；未把私人 blocklist 上传至 CI。

B06 本次覆盖已复核的超时、配置异常和信号路径。SIGKILL／断电仍可能遗留父进程锁；已有死 PID 锁可显式恢复，空锁、PID 复用及旧 manual-run.lock 的完整人工诊断机制仍需独立设计，不自动抢锁、不据此清理任何真实运行目录。原生宿主的历史已落盘暂停与浏览器重试调度不被此项自动改写。

B09、B12、B15 及交接包其他次要项目仍未在本项声明解决。增量入口仍需完成撤回恢复、长 Retry-After 与历史队列保留等上线前验收。新缓存键不清除旧缓存项；真实缓存效果需后续获批运行验证。

本项没有访问项目数据库、Storage、业务网站或媒体，仅变更已获批的两项 GitHub 仓库保护，没有业务云端配置变更、任务恢复、同步、迁移安装或正式部署。平台结果与本机结果分别记录，正式发布仍由用户决定。
