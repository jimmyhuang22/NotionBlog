# 2026-11-13：退役新加坡旧预览入口

Codex。用户确认后，在 Cloudflare 控制台移除旧预览子域名的代理 CNAME 和同名 Tunnel 路由。共用隧道及其余四条路由继续使用。旧预览服务定义和配置仍供现行内容导出读取。

回读 Cloudflare 控制台确认旧预览记录和路由均已移除，两个正式域名的记录和路由仍在。两台权威 DNS 和两家公共递归解析器对旧预览均返回 `NXDOMAIN`。两个正式首页 HTTPS 均为 200，构建 ID 与 #336 一致，共读取 269,052 字节正文。短 SSH 连接只读核对正式站、共享隧道和采集、发布、健康检查定时器均活跃。最后一次观察时采集正在运行，发布任务等待采集完成。

文档收尾更新了[生产部署与交接](../PRODUCTION_DEPLOYMENT.md)中的旧预览状态。#338 已在同一页把栏目加载等待阈值更新为约 700 毫秒。线上视觉复验的范围及待验项见 [#336 部署记录](2026-11-13-oracle-release-336.md)。
