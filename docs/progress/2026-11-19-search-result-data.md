# 2026-11-19：搜索结果资料与摘要接口（Codex）

## 改动

编辑登记包括搜索契约、共享匹配与摘要、数据库 scoped 分页投影、请求预算允许表及合成回归测试。没有额外更新页面组件。按[第十四节](../BACKEND_HANDOFF.md#十四搜索结果需要的字段2026-11-19claude)及[用户决定](../decisions/2026-11-19-search-result-data.md)补充的数据如下。

- 当前页结果有可选的 `cover` 与类型化 `details`。游戏的实际累计时长保留既有单位和真实零值。资料缺失值与现有 DTO 一致。动态首图只在 provider 的合格记录已提供时返回。学习笔记来源行沿用 `context`。
- 第一页返回 `kindCounts`，以分页前的全部命中统计，类型筛选与 `total` 的范围一致。无类型筛选时可用于完整的标签计数。续页省略该字段。
- 摘要先去独立模板标题，再定位第一个正文命中，保留原始字形，显示前后截断标记。标题命中时摘要为空，匹配及排序不变。此前生成的搜索游标在格式变更后按既有 400 和重启分页约定处理。

数据库 scoped 文字投影继续保持紧凑。需要资料的当前页结果使用一次带版本锁定的现有 metadata 读取批次，每条按已获准的栏目和 slug 精确定位。该批次即最终版本复核，数据库往返数保持原有边界。其他页面继续使用原本最终版本检查。数据源、权限、搜索响应字节上限与协议迁移沿用现有设置。

## 验证

在隔离的开发工作区用 Node 24.21.0 复验搜索相关 36 项测试，全部通过。覆盖 Unicode 命中窗口、首尾省略号、模板与标题、缺值和封面路径、第一页和续页计数、公开媒体撤回和仅取当前页资料。前端接入新字段和正式环境验收仍待接续。
