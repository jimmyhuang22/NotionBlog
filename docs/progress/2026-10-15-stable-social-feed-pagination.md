# 2026-10-15：首页分页不因社交统计刷新失效

Codex。编辑登记仅涉及社交 timeline 快照分页摘要、受影响测试和本记录／接口说明；不改 Claude 页面、DTO、SQL、采集器、真实资格、运行包或网站配置。

首页 v2 与 retained 作品列表此前把整份卡片加入版本，后台刷新统计会使相隔数秒的第二页请求报 INVALID_QUERY。现在对经过完整验证的 DTO 提取分页摘要，排除播放／点赞等统计、近似数字、采样时间、链接核验时间和封面；实际响应仍返回本次读取的最新值。保留 namespace、作品／发布身份、日期、标题、合集成员数量、活动／新增事件和链接地址，真实集合或排序变化仍使游标失效。每页继续从受限 reader 读取当前资格，不保存旧内容快照。旧 v1 社交协议保持。

验证：集中执行一次 check，类型／三协议通过、1,974 项测试通过；唯一旧本机连接测试在受限沙箱触发 Node 原生断言，允许 127.0.0.1 监听后单项通过。完整套件未重复。最终补强链接核验时间用例时先触发既有时间约束，改用合法时间后仅复验 retained 文件 10 项全过，未改数据库约束。privacy 与生产 build（43 份 server traces）通过。新增 PGlite 实际 ingest → retained reader → 混排 HTTP 用例，覆盖两页之间刷新个人／合集统计、返回新值、同一游标继续及撤回后拒绝；另覆盖 trial 全部统计变化、成员／活动／日期／标题变化和非法统计校验。

限制：上线时摘要算法变化会使部署前的游标失效一次。内容发布版本、真实成员／资格和排序变化仍可返回 INVALID_QUERY；前端保留位置的缓解由 Claude 负责。尚未部署或在正式站点复验。
