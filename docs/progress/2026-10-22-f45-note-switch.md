# 2026-10-22：换页变暗后接上、笔记统一版式（Claude，F45）

编辑登记：Claude 本轮修改 `src/components/page-switch.tsx`、`src/app/study.css`，新增决策记录。契约、接口与媒体路由、fixtures、依赖、栏目开关、全局入口与后端代码未改。

决定见[决策记录](../decisions/2026-10-22-page-switch-dim-then-swap.md)。

- `page-switch.tsx`：旧页静态副本一出现就在 80 毫秒内降到 55%；新页到达（地址已是目标、无加载态）后，副本至少等到变暗结束，然后整层一次移除，新页的主内容（同课笔记只是阅读区）与页脚从 55% 在 160 毫秒内升到 100%。不再让副本在新页上淡出。慢的时候进度条照旧；减少动态效果时直接换。
- `study.css`：1180 起所有笔记 `--reading-w: 1120px`、留出 204 的本页目录栏与 244 的让位（无目录时空着），含分栏／宽表格的笔记也不再放宽到 1440。**这是比原来窄的地方**：以前含宽表格或分栏的笔记在 1180 以上会放宽到 1440，现在与其他笔记同宽，宽表格在卡片里横向滚动。

## 怎么验证的

本机生产构建、演示数据（demo101 的三篇：有目录、无目录、有目录且有表格），无头 Chrome 逐帧取样：

- 1440 与 1280 宽，用左侧目录的链接依次切换三篇：每次都到了正确的笔记；旧页副本从未出现“部分透明盖在新页上”的帧（0 帧）；副本变暗到 0.55，新页从 0.55 升起；左侧目录 0 帧变暗、位置不变；三篇正文卡片左右边界完全相同（1440：352–1160，1280：342–1004）。
- 整页切换（影视 → 首页、浏览器后退）：同样 0 帧叠影，新页从 0.55 升起；首页第一次较慢时出现变暗与进度条约 1 秒。
- 减少动态效果：直接换页，没有升起动画。
- 控制台无错误。类型检查、完整测试、隐私与构建见合并请求。
