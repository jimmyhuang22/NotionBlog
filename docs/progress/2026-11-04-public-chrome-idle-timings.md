# 2026-11-04：公网首页空闲后的 Chrome 绘制计时（Codex）

## 范围与口径

- 接续 [PR286 源站验收](2026-11-04-aws-home-idle-latency.md)，用户要求用干净 Chrome 比较两组公网首页可见时间。线上仍是 `9572cc7`，本轮只读抽样，无应用、接口、provider 或运行配置变更。
- 同一台 Mac、同一公网网络，Chrome 156 无扩展的独立临时配置，每轮无原站点缓存及 Cookie，桌面视口 1440 × 900、DPR 2、不限速。打开正常公网 URL，从导航开始计时。首屏标题取元素绘制及可见帧，首张封面确认位于视口、已加载真实像素并可见，用 Chrome 元素计时与截图帧交叉核对。封面下载和首页 HTML 完成时间单独记录。
- 每轮先用 AWS 回环读一次首页，再等待指定间隔。在打开前读取数据库池端口的已建立连接数，并对照首页响应窗口内的新连接。探针仅记录 TCP SYN 时间，不留地址或请求内容。75 秒等待途中被真实公网首页访问续用的样本单独记录，避免误入冷连接组。

## 结果

| 从导航开始计时 | 12–45 秒且连接仍热（3 次） | 65–75 秒且确认重连（3 次） |
| --- | --- | --- |
| 首屏主标题可见 | 252 毫秒（252–552） | 528 毫秒（516–540） |
| 第一条动态可见 | 1123 毫秒（1104–1392） | 1837 毫秒（1457–1872） |
| 第一张封面可见 | 1440 毫秒（1324–2368） | 2460 毫秒（2076–2620） |
| 首字节 | 156 毫秒（152–416） | 394 毫秒（383–405） |
| 完整 HTML | 299 毫秒（298–559） | 983 毫秒（966–1046） |
| 首字节到完整 HTML | 144 毫秒（143–146） | 583 毫秒（578–652） |

- 以上为中位数与范围。短组间隔约 12.5／25.5／45.5 秒，浏览器发起首页前均仍有连接，首页窗口未观察到新建连接。冷组约 65.5／65.5／75.5 秒，发起前连接数为零，三个首页响应窗口内均观察到数据库新建连接。源站对应的首页读取耗时短组 143–144 毫秒，冷组 580–656 毫秒。样本的 Cloudflare 边缘节点相同，首字节仍有波动。标题出现时间的组间差异不能单独归因于数据库。
- 八次首页均成功，首封面是同一个 800 档缩略图，均只发一次高优先级请求并返回 200，逐组有截图确认实际像素可见。封面请求自身用时约 0.98–1.78 秒。观察到外部 Analytics 脚本连接关闭或重置，站内资源和页面脚本无失败或未捕获异常。
- 两个约 75 秒但未确认完全空闲的样本不纳入表中。一次等待期间有其他公网首页请求，标题 528 毫秒、封面 1548 毫秒。另一次打开前仍有一个数据库连接，随后观察到新连接，标题 540 毫秒、HTML 3173 毫秒、封面 4208 毫秒。源站对应首页数据阶段 2649 毫秒，封面网络本身约 1112 毫秒，这次正文为什么额外慢未进一步定位。
- Chrome 记录传输约 9.83 MB，八次 AWS 回环预热另有约 0.21 MB 压缩 HTML，日志与数据库出站为小量，未单独计费。每组仅三次，结果适用于此次桌面、网络和当前首图。未测 Safari 或手机。
