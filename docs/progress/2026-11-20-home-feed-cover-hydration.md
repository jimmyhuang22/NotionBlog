# 2026-11-20：首页按页读取封面（Codex）

## 修改

- 首页首屏与 `/api/home/feed-v2` 共用的混合时间线，在 scoped、display-only 数据库模式下先读取有资格公开的索引，按现有顺序合并作品和内容并分页，再批量查询当页内容卡片的封面尺寸。
- 封面查询沿用当前发布、媒体资格及版本检查，展示元数据缺失或发布版本变化时拒绝返回该页。动态正文和图片沿用原有选中条目读取。首页输出字段、游标格式、作品合并顺序和七秒读取预算保持原值。无需安装数据库迁移。

## 验证与后续

- 48 条虚构数据库记录的定向测试覆盖首屏与续页，分别只查询 15 和 16 个封面。被撤下资格的封面未进入映射查询。映射缺失及版本冲突返回 503。
- 本机 Node 24.21.0 的 `npm run check` 全部 3,517 项通过，`npm run build` 通过，51 份服务端构建追踪通过隐私检查。首次沙箱内执行无法监听回环端口，经允许后按项目原有离线网络限制重跑。构建仍出现既有 middleware 弃用与本地磁盘动态路径追踪提示。
- 离线构建经回环 HTTP 验证，首页包含动态就绪标记，首页聚合首屏与续页都返回 200，游标取得不同条目。本次仅本机实现和验证。正式站恢复情况需上线后在新加坡复测，首页发布顺序与已有发布请求协调。
