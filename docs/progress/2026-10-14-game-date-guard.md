# 2026-10-14：游戏的平台游玩日期还没有数据时，页面保持原样（Claude）

编辑登记：Claude 本轮前端修改与验证完成，范围为 `src/app/library/[type]/[slug]/page.tsx`、`src/app/library/[type]/page.tsx`、新增 `src/lib/game-dates.ts` 与 `tests/game-dates.test.ts`。契约、fixtures、接口路由、依赖、栏目开关与后端代码未改；后端在 282 里加的取数与排序逻辑没有动。

来由：准备发布时发现，后端的 282（游戏按平台游玩日期浏览）已在 develop 上，但它要的数据来源还没有接上。照原样发布，正式站点的每个游戏详情页都会多出一行“最近游玩：日期未记录”，原来的“游玩日期”改叫“体验日期”，游戏列表的默认排序标成“最近游玩”而实际仍按手填日期排。问了用户，用户选“先补一个前端保护再发”。

- **详情页**：没有平台日期的游戏只显示一行“游玩日期”，和发布前一样；有平台日期时才显示“最近游玩”与“体验日期”两行。
- **列表**：默认排序只有在这一页的游戏里确实有平台日期时才叫“最近游玩”，否则保持原来的名字。
- 数据接上之后不用再改前端，两处会自己换成新的样子。

没有处理的：用户在另一个前端会话里为这项功能定了四条口径（年份与排序取手填日期与平台日期里较晚的、平台日期只公开到日、首次游玩有才显示、不做分平台明细），282 现在的取数规则与其中几条不同。这属于取数与契约，由那个会话转给后端，在启用数据来源之前改。

| 一个不带平台日期的演示游戏 | 只有“游玩日期”一行 |
