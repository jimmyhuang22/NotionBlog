# 2026-11-12：上海预览与 Oracle 内容交付（Codex）

## 编辑登记与授权

本项仅管理两台预览服务器的私人运行程序及本记录，使用独立工作树；未改动主工作树中的前端改动。用户批准先对齐版本与内容，手动验收通过后再开启自动交付，正式域名与 AWS 不动。用户另行明确批准固定导出身份、限来源且六小时内到期的临时维护公钥，以及限定临时目录的两天 COS 过期规则。

## 修改、接口与 provider

- Oracle 为内容来源，使用已完成的 `published` 版本；上海复制数据库快照与本地展示图片，不新增 Notion 采集。交付使用原同步锁，源轮次未验收、队列未清空或状态过期时不取快照。
- 以 `39046d8` 及 Oracle 现有自托管配置兼容修正构建 AMD64 程序，对应 Oracle ARM64 程序。架构不同导致 BUILD_ID 不同，不能据此判定源码版本不一致。源服务目录、构建身份或配置不符时停止交付。
- 固定 SSH 身份限定来源 IP 和命令，禁止交互 shell 与转发。导出不包含数据库角色密码或文件中的 Notion／Access 凭据。上海使用独立 PostgreSQL 17、TLS 和只读网站登录，恢复到独立候选库；原预览密码保护、禁止索引及内网 API 阻断保留。
- 大包经现有私有 COS 中转，按长度和 SHA-256 验证。仅新增临时交付前缀的两天过期规则；本次已安装的临时程序包经单独批准删除。过期规则已保存，不代表尚未到期的包已删除。
- 恢复兼容修正保留应用对象原有归属，旧平台事件触发器由目标 PostgreSQL 管理员持有，不把导入账号提升为超级用户。状态分阶段记录，结果不明不重放数据库恢复。

## 限制与下一项

正式域名与 AWS 保持原状。社交统计沿用 Oracle 已有保留内容，本项不迁移其采集任务。后续同域名大陆／海外分流需要另行决定。自动交付依赖现有 Mac 在线及受限 SSH 来源 IP；搬机或出口改变时需要相应迁移运行与访问配置。自动交付只同步内容；源站代码升级时应先重新对齐程序与验收，不能把旧版内容交付当作代码升级。

本次已批准的批量传输包括约 219 MB 程序、83 MB 源快照及 383 MB 上海交付包；另有 COS 到上海的对应下载与小量健康检查，未读取或修改 AWS 数据。COS 中尚未到期的内容交付包由已保存的两天规则清理，本次安装程序包已删除；本地交付 tar 与服务器成功作业的恢复包已清理。小量公网抽查约数 MB，另有原上游故障复验约数 MB 的 Notion 元数据读取，均在本项授权范围。
