## F43：换页

- `PageTransition` 去掉按页面加 key 的进入／退出视图过渡，只保留筛选的视图过渡；挂上 `PageSwitch`。
- `PageSwitch` 在窗口上听冒泡到顶的点击（Next 的链接已经 `preventDefault`，说明是站内跳转）和 `popstate`。路径不变的跳转（筛选、排序、锚点）不处理。开始时把页面区（同一门课里换笔记时只是笔记那一栏）和页脚复制到一层固定在页头下的不透明画面里，铺上与正文同样对齐的纸底；每帧检查新页是否到达（路径对上、页面区里没有加载状态），到了就让这层 180 毫秒淡掉（`cubic-bezier(0.2, 0.7, 0.2, 1)`）。60 毫秒还没到就进入等待：复制的内容降到 0.55（140 毫秒），进度条 1.6 秒长到 85%；到达时进度条 0.15 秒补满、0.25 秒淡出。15 秒仍未到就收起，交给页面自己的失败状态。
- 导航：按下时当前栏目（`aria-current`）与墨线就移到新栏目；墨线改用 CSS 过渡滑动（0.36 秒），首次定位不滑。原来的 `data-nav-dir` 左右移动与 `nav-mark` 视图过渡删除。
- 首页加载状态加了一个隐藏的 `data-page-loading` 标记；其他加载状态本来就带 `page-loading` 类。
- 笔记页的上一篇／下一篇（墨水、苹果）按下后只把标题变成强调色，不再画方框。

## F42：首页头部

- 删除 `.hero > *` 的 `rise-in` 入场动画。加载状态和真页面里的头部长得一样，交接时原地不动；从别的页面进首页时由换页的交叉淡化带进来。名字下的笔划（`PenOnce`）在页面里，只画一次，没有改。

## 怎么验证的

- `npm run typecheck`；除 `website-v2-runtime` 与 `qualified-shared-budget` 外的全部测试 2378 项通过；`npm run privacy:check`。
- 演示数据，`next build` + `next start`，无头 Chrome 真实点击，每帧记录复制层与进度条：
  - 1280、390 宽，动态 → 学习（网络延迟 700 毫秒，第一次进）：点击后约 60 毫秒复制层就位，约 120 毫秒开始变暗、进度条出现，约 240 毫秒降到 0.55；数据约 1.47 秒到达，进度条补满淡出，复制层 180 毫秒淡掉。整个过程页面区里有加载状态时复制层一直完全不透明，没有一帧露出加载状态或底色。
  - 学习 → 动态（看过的）与浏览器后退：复制层 180 毫秒淡掉，没有变暗、没有进度条。
  - 90 毫秒间隔连点三个栏目：只淡到最后一个，结束后没有残留的复制层或进度条。
  - 减少动态效果：等待时立即变暗、进度条静止在 85%，到达时直接换。
  - 课程内换笔记（1440，延迟 1500 毫秒，从页底点“下一篇”）：只复制笔记那一栏，左边目录仍是真实的；复制的样子与点击前一致。
  - 进度条在千禧、手帐、墨水深色（1280）与苹果（390）下都清楚。
- F42：清缓存冷加载首页 1280 墨水、390 手帐各 3 次，逐帧取 `.hero h1` 不透明度：一直是 1，没有回落，只有一个 `.hero`，布局偏移 0。

## 限制与下一项

- 只在演示数据下验证；正式站要发布后由反馈审查对话录屏复测（影视 ↔ 书籍 ↔ 游戏、动态 → 详情 → 后退）。本机演示环境里影视、书籍、游戏栏目关着，换页用的是动态、学习与笔记页。
