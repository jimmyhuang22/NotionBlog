# 2026-10-23：缓存版本竞态的有限重读与请求缓存隔离

## 编辑登记与范围

执行者：Codex。用户同意接续自然换版验收中发现的渲染竞态修复。本项从最新 develop 建立独立分支，修改缓存投影读取、统一内容入口内的请求缓存身份及对应测试；不改依赖、DTO、SQL、公开规则、页面视觉、云端配置或冻结来源程序。只准备草稿 PR，不合并、部署或恢复其他业务任务；retention 清理继续停止。

## 实现

缓存加载后发现版本变化或固定日期窗口过期时，丢弃该结果，再重新取戳、计算缓存键并读取，最多三次完整尝试。仅重试本模块内部的竞态信号；同样错误码或文字的 provider 错误、配置／资格失败、取消、缓存错误和异常条目仍直接失败。每次尝试沿用调用方既有截止时间，不重置等待窗口。失败结果不进入成功缓存，持续变更耗尽次数后仍明确失败。

重读还必须隔离 React 在同次渲染中已经记住的课程元数据：缓存加载期间传递请求局部版本，内容服务的 React memo 以该版本为身份。同版本共享原请求缓存，换版本重新构造服务及课程／学习请求缓存；关闭公开缓存时保持原请求身份。未增加暖缓存的版本查询，合法大文档仍在复核后绕过缓存大小限制。
