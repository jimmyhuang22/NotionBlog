# 2026-11-25：游戏页的平板年份、空结果、想玩和无日期（Claude）

编辑登记：Claude 修改 `src/components/library-grid.tsx`（空结果、一段式列表、无日期分行）、`src/app/library/[type]/page.tsx`（把所选平台的名字和“全部平台”的地址传给列表）、`src/app/library.css`，更新 `docs/FRONTEND_GUIDE.md`。

## 来由

用户问游戏页还有什么 UI/UX 能改。Claude 在正式站点补看了苹果、千禧、墨水深色、平板 768、手机 390、在玩、想玩和空结果，提了四项，用户看本机原型后决定：

1. 平板 768 下左栏的“2026”断成“202 / 6”：900 以下年份数字缩小（约 32px）并禁止断行。
2. 空结果原来是全站的“这个分类下还没有内容。”米色条：改成年轮里的一段，写“想玩里还没有 PC 游戏。”，带“看全部平台”（不跳到顶部）。
3. 想玩只有一段，左栏只写“想玩 107 款”：用户选**甲**，去掉左栏和竖线，盒子占满宽度。
4. 在玩的“无日期”有 155 款：用户选**甲**，按盒子上印的平台分行；并要求从上到下的顺序和平台筛选从左到右一致：Switch（含 Switch 2、3DS，和筛选口径相同）、PlayStation、Steam、PC、其他。想玩同样分行。选了一个平台时不分行。

分行按盒子上印的平台，一款只进一行；筛选器的款数是“这个平台上有的游戏”，一款可以算进几个平台，所以两边数字可能差一两款（想玩 Switch 行 18、筛选器 19）。

## 怎么验证的

- 本机正式构建加未提交的预览页（线上数据）：768 下年份一行；想玩 + PC 显示新空结果，“看全部平台”可用；想玩整面墙、分行为 Switch 18、PlayStation 4、Steam 85；在玩“无日期”为 Switch 79、PlayStation 35、Steam 41；选 Switch 时不分行；1440、390 没有横向溢出，没有脚本错误。
- Node 24 下 `npm run check` 与 `npm run build`，结果见合并请求。

## 没做的

- 苹果外观下状态标签和平台滑块风格不同、手机浮动坞只有图标、大幕小盒子的时长线、年度小结：用户没选，先不做。
