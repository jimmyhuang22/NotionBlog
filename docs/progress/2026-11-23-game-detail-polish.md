## 做了什么

用户在线上游戏页挑出五处，看过注入线上页面的对比原型后选 1乙 2甲 3甲 4乙（白金按钮另看四种，选丁）5乙：

- 日期线：小字名称、大字年份、月日在下（`stripDate`）；同年写淡；跨年“2022 – 2023”；主栏窄于约 520 时竖排（容器查询）。
- 左栏几个平台的奖杯：图标加名称、条、个数三列对齐（subgrid）；白金行白金色条与“白金”；0 个变淡。单套白金时条也是白金色。顺手修了档位个数里“15 /44”多出的空隙。
- 每月细柱换成一行字（`trophySpan`）：“2023 年 1 月 24 日拿到第一个，第 12 天拿到白金”，或“X 到 Y 拿到 N 个”。
- 平台切换：单色图标；白金写“白金”加金属描边；0 个变淡；名称裁到大写字母高度对齐图标。480 以下平分一行、个数在名称下面（原来三个平台在 390 宽已超出卡片约 25 像素）。
- 上一款 / 下一款：两侧半圆把手（1100 宽以上、可悬停时），指上去展开；左右方向键按下页尾卡片。

## 怎么验证的

- 本机构建的演示站点上临时加了一个预览页（未提交）：渲染真正的 `GamePage`，数据是线上《女神异闻录5皇家版》详情接口 2026-11-22 的一次读取（PS4 16/53、PS5 53/53 白金、Steam 0/53），另有八种日期情形（同一天、月内一段、同年跨月、跨年一段、相隔二十多年、只有两个日期、游玩日期未记录、什么都没有、只想玩、四个日期带跨年一段）；封面与奖杯图标经本机代理从正式站点读取。
- 截图宽度：1440、1280、1100、1099、900、820、800、390、360、320；外观：岛屿浅深、墨水浅深、苹果浅深、千禧浅深（日期与奖杯）；白金描边看了岛屿浅深、墨水浅色、苹果深色和 390 手机。所有宽度没有页面横向溢出。900 宽四个日期时跨年年份在“–”后折行，不压到下一列。
- 键盘（脚本真实按键）：焦点在奖杯平台切换上按 → 只换平台；页面上按 → / ← 打开下一款 / 上一款；按住 ⌘ 时不响应。1099 宽把手不显示。
- 单元测试：日期各种跨度的切分、奖杯一句话的几种写法、白金判断与平台图标。Node 24.21.0 的 `npm run check`（3531 项全部通过）与 `npm run build` 通过（去掉临时预览页后的提交树）。
