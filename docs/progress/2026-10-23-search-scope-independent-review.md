## 结论与证据

在本次审查范围内未发现阻塞该方向的缺陷，可以作为后续独立候选的依据。此前部分 adaptive 并发／过期测试使用纯 Status，实际走原引用投影；其通过不能单独证明优化分支。本项在独立虚构 PGlite 中补九组检查，明确包含课程、学习笔记和 Status 的混合候选，使用原型原始 SQL，不重复性能基准。

| 独立复核 | 结果 |
| --- | --- |
| 命中条件分支的资格计数 | 混合候选 11 → 6；纯 Status 4 → 4，确认后者回退原路径 |
| 两种公开模式、五个查询、三种分页大小 | 共比较 38 页，完整 DTO、排序和游标一致 |
| 已知笔记／媒体 owner 撤回及子孙撤回、候选外目标撤回 | 下一请求重新判定，正文、链接与媒体不保留旧资格 |
| 内容读取后、最终版本读取前发生变化 | 真正含笔记的优化分支继续拒绝结果 |
| 仅媒体变化而 revision 不变 | 优化分支拒绝旧游标 |
| 资格过期与 epoch 变化 | qualified 过期拒绝，published 保留原持续展示语义；epoch 变化两者均拒绝 |
| 六类角色的函数权限 | 即使另授 schema USAGE，仍不能直接调用内部资格集合 helper；公开原型只允许 reader 及其派生角色 |

核对原型、输入和证据摘要，原二十三份固定文件、1618 份源码、15974 份锁定依赖及七个链接均保持。计数临时包裹在检查后还原；后续行为检查不使用计数包裹，临时数据库已关闭。以上页数与九组检查不追加到原二十组，也不作为新的真实性能样本。

同语句复用的论证依赖入口和资格函数仍为 STABLE、使用调用语句快照，且只接收本语句资格循环生成的集合；与 [PostgreSQL 快照说明](https://www.postgresql.org/docs/17/xfunc-volatility.html)一致。本轮只检查该声明与实现，并未用 PGlite 单连接测试代替真实 PostgreSQL 多会话并发证明。

## 正式实现仍需明确的边界

“学习笔记限定”目前是候选集合含 study-note 时启用整组复用；混合集合中的其他类型也会复用。正式实现与说明须保持这一含义，不能写成所有非笔记逐条使用原 helper。

新模式、独立能力标识及缺失／错误摘要隔离尚未实现。本轮通过旧 filtered 接口的私人替换测试原型，不证明未来 filtered-scope 入口已经接通；正式候选须覆盖新能力缺失／慢检查不阻断普通课程、首页和目录，保留三条原搜索路径及 SQL 限额、TS 完整匹配／排序／分页与末尾版本复核。

公开入口不得接受调用者伪造的已通过集合。安装时须将函数创建、撤销默认权限及选择性授权放在同一事务，固定可信 search_path，并重新核对实际 owner／角色和回退；参见 [PostgreSQL 函数权限说明](https://www.postgresql.org/docs/current/sql-createfunction.html)。本轮已在虚构库去除 schema 权限遮蔽后核实 EXECUTE，未审查尚不存在的正式安装包。
