# 2026-10-18：复用已校验的小图字节（Codex，F28 B2）

编辑登记：本会话负责F28 B2的小图读取；只修改媒体字节读取及其回归测试。不修改Claude已完成的封面预览、F21页面／代理、运行中的同步或历史批次清理。

## 改了什么

同一服务实例、同一存储对象内，v2小图复用已校验的WebP字节，并合并相同对象的同时下载。缓存以完整媒体描述为键，包含所属页面、资产标识、内容摘要、尺寸和对象路径；不同存储实例互不复用。资格和批次投影不缓存，每个请求仍先读当前资格，取得字节后再读一次，并要求投影完全一致。实时Notion模式保留原有来源检查，v1不启用字节缓存。

缓存从验证成功起可复用五分钟，命中不续期；过期项在后续读取时清除。每对象最多1 MiB，总预算16 MiB／128项，包含在途预留；超限按原路径读取。完成对象按最近访问顺序淘汰，在途对象不重复预留。错误和坏字节不保留、不自动重试，分类瞬时故障仍沿用原先重新检查资格的原图入口。向请求方返回独立副本，调用者不能改坏缓存。

成功响应增加固定名称的`Server-Timing`：`thumb_scope`、`thumb_object`、`thumb_recheck`。对象阶段注明`miss`、`hit`、`coalesced`或`bypass`；不输出来源标识、签名地址或凭据。HTTP仍是private一天／must-revalidate、两个CDN专用头no-store；撤回后的新请求继续拒绝，已获用户接受的浏览器缓存期限不变。

## 验证

真实数据只读分段：沿现有受限reader及加速地址读取三张已知800宽封面，共523,228字节、三次COS GET，没有来源读取或写入。开发设备上首个对象约1.85秒，其余约0.60–0.64秒；每次资格查询约0.18–0.27秒，字节校验小于1毫秒。该读数来自墨尔本开发机，不是Vercel或浏览器TTFB，也不能与旧版本F28表直接作前后比较。

针对性28项通过，包括重复／同时下载只取一次、失效与容量、完整描述和存储隔离、坏字节与失败后释放、缓存命中后撤回／批次／绑定／派生图变化仍拒绝，以及真实路由400／1600宽的资格与撤回守卫。

一次完整check的类型与协议检查通过；2,214项中2,208项通过，6项失败计数来自精确运行文件摘要、一个旧集成场景及其后续失败、另一个未改动连接测试的Node原生断言崩溃。集成场景现分别证明缓存中的已验证字节仍正确、冷存储实例遇到坏字节必须拒绝，并保留后续来源／SQL撤回与新批次测试。运行兼容表只登记本次两个应用文件的精确摘要，增加逐项变更摘要必须拒绝的检查；没有更改采集、DTO、来源证明或运行中的冻结程序。

上述受影响文件及缓存／路由／HTTP策略共46项复查全部通过；未改动连接测试的单独复查也在其中，原生崩溃原因未确定，原失败日志保留。最终类型检查、构建及43份服务端追踪隐私检查通过。不重复无关全套，不把局部复查写成完整check一次全通过，也不当作平台CI或线上验收。
