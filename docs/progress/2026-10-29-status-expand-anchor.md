# 2026-10-29：展开或收起长动态时文字不再跳走（F51，Claude）

编辑登记：Claude 本轮修改 `src/components/status-body.tsx`、`src/lib/size-motion.ts`，新增 `src/lib/scroll-anchor.ts` 与 `tests/scroll-anchor.test.ts`，在 `tests/size-motion.test.ts` 加一条测试，更新 `docs/FRONTEND_GUIDE.md` 的动效一条。契约、接口与媒体路由、fixtures、依赖、栏目开关、全局入口与后端代码未改。

## 问题

反馈 F51 与巡查 S14-1、S14-2：卡片顶端已滚出屏幕、读者正读到中间时点“展开全文”，按钮不动，正在读的文字一下跳走（线上首页 1280 宽 90 像素、390 宽 268 像素，动态页最多 215 像素）；长文多图的动态会被直接甩到末尾（线上 1280 宽一次 2697 像素）。收起时反向跳，10-28 定下的“平滑滚回开头”也因此不触发。

原因是浏览器的滚动锚定：内容变化时它在屏幕里挑一个参照物，并整页滚动让参照物不动。卡片顶端在屏幕外时，参照物落在“展开／收起”按钮上（#202 为保住键盘焦点让它前后是同一个元素），按钮上方的内容整块换掉，页面就跟着滚了高度差那么多。

## 改了什么

- 新增 `src/lib/scroll-anchor.ts`：从点按换内容开始，到高度过渡结束后的下一帧，在页面根元素和 `body` 上设 `overflow-anchor: none`；结束后去掉这条内联样式，恢复浏览器默认。几张卡片同时在动时，等全部结束才恢复；最迟 1 秒也会恢复。没有只在卡片或按钮上关，那样浏览器会改用下面那条动态当参照物，卡片长高时页面一路往上滚。
- `size-motion.ts` 的 `play` 返回它启动的过渡，卡片据此等过渡结束再恢复滚动锚定。
- 收起时滚回开头的代码没有改：现在浏览器不再先跳一下，开头仍在屏幕上方，平滑滚回就照 10-28 的决定和收缩同时开始。
- 图片晚到、加载更多等其他时候，滚动锚定照常工作。

## 怎么验证的

演示数据本机生产构建（`next build --webpack` + `next start`），无头 Chrome 1x，逐帧记录页面滚动位置、卡片顶端、正文段落顶端与按钮位置。脚本改自审查对话的 `expand-shift.mjs`，加了卡片顶端位置、主题与减少动态效果的参数。卡片顶端都放在屏幕上方 150 像素处再点按。

改之前先在同一构建上复现：动态页 1280 宽，《虚构记录 04》（长文、无图）展开时页面滚 89 像素、段落跟着上移 89；《虚构记录 12》（长文、六张图，对应 S14-2）一次滚 3203 像素。

改之后：

| 页面 | 宽度 | 条目 | 展开时页面滚动 | 正在读的段落偏移 | 收起 |
| --- | --- | --- | --- | --- | --- |
| 动态页 | 1280 | 04、12 | 0 | 0 | 平滑滚回，开头停在页头下方 |
| 动态页 | 1024、768、390、320 | 12 | 0 | 0 | 同上 |
| 首页 | 1280、390 | 04、12 | 0 | 0 | 同上 |

- 动态页 390 宽，墨水、苹果、岛屿、千禧各自的浅色与深色（千禧只有浅色）：展开偏移都是 0，收起都平滑滚回；苹果页头更高，开头停在它的页头下方。
- 收起：《虚构记录 12》从卡片末尾收起，约 0.7 秒内逐帧滚回，每帧最多 250 像素（浏览器的平滑滚动），没有一帧跳过去。
- 减少动态效果：展开不动，收起直接定位到开头。
- 展开、收起后焦点仍在按钮上；过渡结束后页面根元素与 `body` 的 `overflow-anchor` 回到 `auto`，没有留下内联样式。
- 卡片整张在屏幕里时，展开和收起照旧，只有高度过渡。
- `npx tsc --noEmit`、`npm run privacy:check`、相关文件 lint、`npm run build` 通过；`npm run check` 里 33 个失败都是本机 Node 26 的已知问题（后端子进程缺 `libnode.147.dylib`、发布脚本只认 Node 24），全部在后端运行时测试文件里，与本改动无关，平台检查以 GitHub 上的 Node 24 为准。

## 限制与下一项

- 只在演示数据下验证。演示数据里长动态的开头和全文是同一段落；真实数据里如果开头与全文的排法不同（例如开头是纯文字、全文有图在前），读者那一行可能仍会移动一点，这不是滚动锚定造成的，上线后复验时注意。
- 短动态“展开完整内容”（宽度也变）演示数据里没有可展开的正文，没有测；Safari 本身不做滚动锚定，未测；真机未测。
