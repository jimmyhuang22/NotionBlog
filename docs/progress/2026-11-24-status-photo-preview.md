# 2026-11-24：F63 动态照片顺序接口

执行者 Codex。受影响的共享范围是 `StatusEntry.previewBody`、动态预览读取和演示样本。现有卡片继续通过照片条展示，直到 UI/UX 接入原型三，过渡期间过滤预览中的重复图片。

动态列表 `/api/content/status` 和首页时间线 `/api/home/feed-v2` 共用 `statusPreview`。图片保留在原文位置，与 `entry.images` 使用相同的 ID 和站内地址。文字和图片有独立额度。详情和同步存储仍使用原有正文结构，数据库入库校验拒绝列表派生字段。

本机验证演示动态的短段落和照片、照片前中后位置、嵌套、截断与九张上限。隔离数据库覆盖授权图片、动态撤回及存储白名单。应用检查和构建在演示数据下运行。未部署。

UI/UX 接续时用 `previewBody` 渲染折叠内容，接上九行裁切与照片分组，按图片 ID 与 `images` 对照按钮的剩余张数，遇到缺少图片块的旧快照保留原照片条。按钮无缩略图。动态页与首页分别复看照片尺寸、逐帧位置、键盘和多主题；真实数据与两站验收随前端完成后进行。见 [决策](../decisions/2026-11-24-status-photo-order.md) 和 [接口](../STATUS_API.md)。
