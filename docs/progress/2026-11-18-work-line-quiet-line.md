## 改了什么

- `HomeWorkLine` 的信息行（新函数 `quietParts`）：平台图标后不再显示平台名（改为只给读屏）；单篇不写“视频／图文”；合集写“合集 N 个视频”；新增写成个数后的“+N”（`.work-line__added`），去掉标题旁的胶囊（删除 `.work-line__update`）；第一个部分前不加分隔点（`.work-line__part--first`）。
- 补充行（同一作品的第二个平台）同样处理。四个主题都适用。

## 怎么验证的

- 改了两个测试断言（平台名只读出、单篇不写类型、合集词组与 +1 及读屏说法）。Node 24.21.0：`npm run check` 与 `npm run build`，结果见合并请求。
- 本机正式构建，用一次取回的正式首页数据在不提交的临时页上渲染（封面经脚本从正式站点代取），墨水与岛屿浅色 1280、390，墨水 320，岛屿深色、苹果、千禧 1280；没有横向溢出。取数时 B 站合集当天又新增 1 个视频，那一组变成跨天，所以截图里每条带日期：“今天 · 合集 180 个视频 +1 · 播放 6.2万”“昨天 · 11 月 17 日 · 点赞 203”。
