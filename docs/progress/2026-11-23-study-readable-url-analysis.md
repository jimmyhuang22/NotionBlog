# 2026-11-23：学习区可读地址分析（Codex）

按用户要求核对正式站的学习首页、一个学习项目、项目内全部 13 门课程的目录，以及一部游戏的新旧地址。游戏新地址返回 200，旧 ID 地址返回 404。学习项目已经使用配置中的短名，课程和笔记仍由 Notion 记录 ID 生成地址。课程目录共读到 961 个可访问页面节点，最深四层。11 门课有规范化后重复的页标题，其中三门存在连父级标题路径都仍重复的情况。HTTPS 只读响应共约 85 KB。

建议学习项目沿用 `/study/projects/<项目编号>`，课程采用 `/study/<课程编号>`，笔记和子页采用 `/study/<课程编号>/notes/<页面短名>`。周次可作为短名的一部分，重复的子页优先用周次或相关父级区分，同一语义路径再碰撞时分配固定编号。首次发布持久化分配，标题变更沿用已分配地址。每门课可独立使用相同的页短名，公开读取按课程和页面短名共同定位，内部同步按原记录身份运行。

若后续采用此方案，应在两地交付同一份名称映射，并让课程目录、正文站内链接、面包屑、上一篇／下一篇、搜索、规范链接和站点地图读取对应新路径。验证应覆盖应用现有资格校验、跨课程重名、同级重名、深层笔记、标题改动和旧路径处理。本次是方案分析，域名、正式地址及 provider 未变更。
