# 2026-10-12：缩略图体积收益规则与离线大图试验

编辑登记：Codex 在独立 `codex/thumbnail-size-benefit` 分支处理缩略图生成批次、对应测试与媒体／需求／独立决策说明，已按最新开发约定普通合入最新 develop 的改动并保留其他代理的工作；本项向 develop 日常集成，main 由用户通过集中发布请求更新。本轮使用已有本机试验原件和先前小批原件镜像；真实图片、私有清单、对比页面与回执留忽略目录。

- 400／800 每档仅在实际输出严格小于当前展示原件时预扣上传预算、上传和登记；相等或更大继续保留获准原图。无收益路径仍重查完整来源、当前批次与撤回状态，坏字节、读取失败或权限错误仍终止，不以体积规则掩盖异常。
- 相等或更大的旧缓存候选不进入复用，重新核验原件并编码；旧不可变条目保留。若重编码产生更小对象，实际回读与当前登记仍完整执行，但不覆盖被排除的旧缓存条目。历史 SQL 映射仍验证并使用，未自动清理；编码器、配方、路由、DTO、冻结 SQL、权限和调度保持。`notSmaller` 单独计省略档位，`skipped` 继续计编码器明确跳过的原件。
- 已有 21 个非随机本机样本共 62,780,041 字节，包含大照片、4K 截图、文字、两张实际透明图及三个先前小批样本。使用当前生产 WebP 配方重新编码，19 张严格通过，2 张 JPEG 因已确认的多余标记字节警告被严格解码拒绝；两张失败记录单列，未修改原图或放宽解码边界。
- 19 张通过样本共 54,047,909 字节；每档分别计算保留原图后的显示量：400 档 251,745 字节，较原件少约 99.5%；800 档 697,654 字节，少约 98.7%。共 38 个候选档位，其中 3 档不更小而保留原图；35 个有收益档位按字节去重为 33 个对象／932,398 字节。只在本机生成，没有读取云原图或执行上传。
- 按相同缩放参考比较当前配方与 Q95，记录 RGB 误差及 Alpha 精确保持，另提供照片、细字和透明边缘的本机对比。当前配方在 Q85／无损 WebP 中择小；有损候选不能统一称为近乎无损，缩放后无损也不代表保留原尺寸细节。学习正文及灯箱继续用原图，未根据全局误差自动判定人眼接受。

验证：新增性质测试独立 13 项、批次及本机 SQL／HTTP focused 77 项通过；普通整合最新 develop 后，Node 24.21.0、umask 022 的 `npm run check` 通过 1,101 项测试、类型与三项协议检查及 418 个候选文件隐私检查；`npm run build` 及 37 个服务端构建追踪隐私检查通过。其他代理的 develop 文件逐一比较保持，独立公开差异复核、合并内容暂存隐私及差异检查通过。

本机页面已在浏览器载入；另逐张查看七个代表样本的 800 档参考／生产／Q95 原生像素裁剪，并查看五个照片、画面及文字样本的 400 档。当前配方的照片／草木纹理有可见软化，Q95 更接近缩放参考且占用更多字节；界面主要文字在所检 800 档仍可辨认，但 400 档长文截图的细字不适合正文阅读。两张透明样本的全部候选 Alpha 与缩放参考逐像素一致，另检查窗口外缘显示。此人工复核只支持预览用途，不是全部样本画质或国内加载验收，生产质量参数未调整。

本轮未执行云端 Auth／SQL／Storage 请求、改托管环境变量、部署、续期、真实同步或调度；前轮两次云执行额度保持耗尽。数字只属于明确的严格通过样本，不代表全站、随机总体、国内网络或月账单。未持久化无收益结果，后续新批次仍可能重新下载编码；被排除的旧缓存条目也可能重复生成。

下一项：完成 develop 日常集成，积累改动后向 main 提集中发布请求并由用户合并。用户可用本机对比页确认预览画质；按新的明确预算与当前资格安排有体积收益的大图云端小批试验。两张严格拒绝 JPEG 的来源规范化需独立复核，不能未经允许覆盖原件。
