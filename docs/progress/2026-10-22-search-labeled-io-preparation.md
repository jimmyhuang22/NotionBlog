# 2026-10-22：搜索分路径 I/O 入口离线验证完成

编辑登记：Codex。本项把上轮已验证的回环计量原型接入独立的本机对照核心，并准备只读准入检查；执行文件、真实配置、路由与回执保留在忽略目录。本合并请求只提交本记录，不修改应用、契约、provider、SQL、连接池、同步或生产配置。受检应用源码继续固定为 `80193c0`，便于隔离计量变化；此后 develop 的缓存、页面及共享 reader 池更新未纳入性能结论。

两个模式分别经过自己的回环观察端口，再连接原冻结全局中继。全局中继继续独立限制六次 HTML、十六个累计连接、16 MiB 接收停止阈值和一百八十秒，观察端口只计不透明字节和本机连接，不读取、解密或保存载荷，也不能选择真实外部端点。各模式只获得观察量，不把它写成精确请求流量、应用实际收到的字节或平台计费量；本机接受连接与全局计入的数据库连接分别记录。

窗口与每组采样同时保留全局累计量、两种模式的累计观察量和未归属余额。跨采样边界的在途数据可能使“本组观察增量”大于“本组全局接收增量”，因此余额变化允许为负；累计余额仍须非负并守恒，不能截零或强行分摊。超限数据块保持全额记账，尚未到达观察端口的部分继续未归属。

停止过程共用同一个清理承诺，等待子进程退出及观察端口关闭；清理失败时不得声明子进程全部停止，也不得将本轮标为成功。保留首错停止、禁止后续采样组、固定路由、相同 DTO／目录指纹验证以及不把进程计时冒充精确 HTTP／SQL 计时的规则。
