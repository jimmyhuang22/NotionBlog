## 接口、权限与默认行为

`readLibraryFirstPage` 统一首屏列表及年份编排；database v2/scoped 可显式提供 `readLibraryPage`。没有选择 compact 时沿用原接口与缓存。新入口执行栏目权限包装，不缓存完成态 DTO，不因新路径读取失败退回旧缓存。

精简选择器负责年份、排序和分页，完整最终检查负责当前资格及当前页元数据；封面异步准备完成后再次检查，之后只同步投影。空页和可选年份失败不绕过检查，SQL、资格、游标和投递错误不被降级吞掉。最终并发边界仍是最后 SQL 开始的语句快照，不承诺在该语句开始后提交的撤回中断正在完成的响应。

`DATABASE_LIBRARY_PAGE` 在 `.env.example` 与自托管 profile 均默认 `legacy`。profile 白名单接受 `legacy`/`compact`，compact 必须配合 scoped；既有 profile 测试同步验证默认值和配置约束，没有新增测试文件或性能场景。新增独立迁移及摘要只进入源码，不安装到云端，不改实际运行配置。
