# 2026-10-14：作品卡片按各平台的样子显示，只留播放和点赞（Claude）

编辑登记：Claude 本轮前端修改与验证完成，范围为新增 `src/components/social-work-card.tsx`、`src/components/work-strip.tsx`，删除 `src/components/social-card.tsx`、`src/components/collection-card.tsx`，修改 `src/components/home-timeline.tsx`、`src/components/home-works.tsx`、`src/lib/works.ts`、`src/lib/home-feed.ts`、`src/app/timeline.css`、`src/app/skins.css`，以及 `tests/works.test.ts`、`tests/home-feed-display.test.ts`。契约、接口路由、fixtures、依赖、栏目开关、全局入口与后端代码未改。

来由：用户看了首页上一张合集卡片的截图，觉得信息太多又没有封面，要求出几个原型：显示封面、去掉用不上的信息、只留播放量和点赞（小红书同理）、参考各平台自己的样子。Claude 用正式站点存下来的真实标题与数字做了三个样子的对比图（电脑 1280 与手机 390），用户选了“各平台自己的卡片样式”，并同意读取时间只在超期时显示。决定见 [决策记录](../decisions/2026-10-14-work-cover-cards.md)。

## 改了什么

- **一张新卡片取代作品卡与合集卡**（`social-work-card.tsx`）。B 站：16:9 封面，左上角类型与集数，播放和点赞在封面底部，下面标题与平台名。小红书：3:4 竖封面，标题最多两行，下面平台、类型和点赞。整块是一个链接（只在地址核验过时）。同一作品的其他平台在卡片下各占一行。
- **没有封面时**是不带画框的同一张卡：标题、平台与类型与集数、带文字标签的播放和点赞、去原帖的箭头。不画假封面。
- **只留播放和点赞**（`leadingFigures`）：首页卡片、首页清单、作品页都按这一条；两项都没有而有别的数字时用第一项顶上。
- **读取时间只在超期时写出**；平时鼠标停在数字上可见。“原平台可能要求登录”只念给读屏。合集基线的“最近一集发布于某日”去掉。
- **连着的几件作品**：其中有封面时是一排可横向滑动的小卡片（`work-strip.tsx`），各带自己的日期；全都没有封面时仍是原来的清单。鼠标另有左右两个小按钮，手机上不出现。
- **封面读不出来**时退回占位，沿用 `cover-image.tsx`。
- 对后端的封面需求写进了 [后端交接包](../BACKEND_HANDOFF.md) 第十二节。

## 怎么验证的

本机开发服务器加一个不提交的临时页面，把 2026-10-13 从正式站点读下来的 60 件作品（16 个 B 站合集、44 篇小红书图文，真实标题、数字和地址）拼成首页时间线，另加六个虚构的情形：合集有新增、合集同时发在小红书、只是发现更新的多 P 视频、数字超期的图文、没有地址的单个视频、没有任何数字的图文。**封面是本机画的示意图**（五种比例，用来看裁切），不是真实封面。临时页面与截图都没有提交。

| 看了什么 | 结果 |
| --- | --- |
| 全有封面、全无封面、一半有封面，1280 与 390 宽 | 都没有横向溢出；有封面 15 张卡（5 张单卡、10 张在两排里），无封面时两组连着的作品是清单 |
| 墨水深色、苹果、像素、千禧 | 卡片、封面上的字、占位都正常；像素主题手机宽度下无封面样子也看过 |
| 读屏拿到的链接名称（Chrome 辅助功能树） | 先念标题，再平台、变化、类型与集数、“播放 … 点赞 …”，最后“在某平台打开，原平台可能要求登录”；一排的名称是“7 件作品，可左右滚动” |
| 链接 | 15 个全部是新窗口打开、地址原样；没有地址的那张是不可点的块 |
| 一排小卡片 | 1280 宽：按“向后”移动 486，到头后“向后”消失、“向前”出现；聚焦到排尾的卡片会自动滚进可见范围。按钮不在 Tab 顺序里，也不念给读屏 |
| 可点范围 | 没有低于 36 高的链接 |
| 鼠标悬停 | 合集数字的提示是“整个合集的合计 · 数据截至 …”，其余是“数据截至 …” |

检查：`npm run typecheck`、三个 `*:protocol`、`npm run privacy:check`、`npm run build` 通过；`node --test`（除去本机跑不了的 `website-v2-runtime` 与 `qualified-shared-budget` 两个文件）1874 项全过。

## 限制

- **没有在真实封面下看过**，现在的数据里封面全是空的。合入后线上看到的是无封面的样子（信息已减少）；带封面的样子要等后端补上封面才会出现，届时需要在正式站点复验一次：裁切是否合适、小图两档是否可用、封面底部的字在浅色封面上是否看得清。
- 没有在真机上滑过那一排小卡片，只在无界面浏览器里用脚本滚过。
- 作品页仍是清单，只是数字改成播放与点赞；是否改成封面网格等真实封面到位后再定。
- 一件作品发在两个平台的情形只用虚构数据看过，正式数据里还没有。
