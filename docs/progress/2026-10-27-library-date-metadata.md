## 接口与 provider

通过 Notion 连接器读取现行 schema 和指定记录，仅更新上述页面属性，并按来源查询已保存结果。公开网页用于核对作者简介、实物目录和发行公告；接口重定向到其他软件时不把该结果当作独立产品依据。网页历史评分与需要验证才能读取的页面不冒充当前评分。

本轮共 51 次成功 Notion 调用，含 17 次属性写入；保存的连接器响应 JSON 合计约 0.63 MB，另有少量公开资料网页读取。这是返回内容的序列化大小，不是云端计费流量；没有访问项目 Supabase 或 Storage。指定平台的个人活动查询最初在进程启动前被自动审批拒绝；用户补充明确批准后执行，两款中一款成功返回约 32 KB 的公开成就记录，另一款三次均返回 429，两次退避后已结束本轮查询；没有重查已成功的一款，也不以限流响应推断没有成就。

本轮核查不保证缺失资料都能补齐。未证实的值维持空白或保留已注明争议的原值；五项资料问题由维护任务继续处理。平台没有首次活动字段时不宣称取得了精确首玩日；本轮采用的成就日期明确记为参考。所有待用户答复事项均已处理，限流查询不影响用户明确确认的日期。
