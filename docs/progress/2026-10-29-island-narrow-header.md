# 2026-10-29：岛屿主题窄屏顶栏按钮拉开（F50 补充，Claude）

编辑登记：Claude 本轮修改 `src/app/skins.css`（岛屿顶栏按钮间距一段）与 `docs/FRONTEND_GUIDE.md` 页头一条。契约、接口与媒体路由、fixtures、依赖、栏目开关、全局入口与后端代码未改。

## 原因

F50 发布 198 后 390 以上已通过，但 320–360 宽岛屿顶栏三个按钮间距仍是 2 像素，投影几乎相接。用户 10-29 看过审查对话的对比图后选定：330–360 宽用乙（间距 6、按钮 40），320–329 宽用丁（间距 6、按钮 36 见方）。

## 改了什么

- 去掉岛屿 `max-width: 360px` 时间距 2 的那条，540 以下一直是 6。
- 新增 `max-width: 329px`：顶栏三个按钮 36×36。图标、底色、描边、4 像素投影和按下下沉都没动。
- 规则旁注释写明用户选定与分档原因。千禧主题同样的 2 像素规则用户没要求，未改。

演示数据本机生产构建，无头 Chrome 1x，首页，站名在页面里换成线上的“Jimmy Huang's Blog”（18 个字符）后测量。岛屿浅色和深色结果相同：

- 各宽度站名不截断、无横向溢出，右边距 18。390 起顶栏 105.6 是站名回到大一档字号，与改前相同。
- 分界线：330 宽用 40 的按钮时站名到按钮还余 17.8，按此推算 40 的按钮在约 324 宽起才留得出 12；交接包推算的 330 成立，没有调整。
- 320 宽打开主题菜单：弹层左 28、右 260，在屏幕内（浅色与深色）。
- 墨水、苹果、千禧在 320、360 宽：按钮 40×44，间距、顶栏高与改前规则一致（改动的选择器只作用于岛屿）。
- `npm run build` 通过；隐私检查随提交通过。只改了 CSS 与文档，没有跑整套 check。
