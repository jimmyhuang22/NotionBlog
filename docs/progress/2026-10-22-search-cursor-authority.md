# 2026-10-22：搜索游标绑定当前可见结果

编辑登记：Codex。本项修改 `src/lib/content/website.ts` 的搜索游标身份及独立回归测试，从 develop `12ef0b6` 建立短期分支；原连接池有界对照任务由其既有控制器继续等待，本项不重复启动读库窗口。provider、DTO 和数据库协议保持原接口。

## 触发与修复

离线实际 SQL 复现：三条搜索结果中，第一条仅因图片说明匹配；读取第一页后撤回该图片，实时投影剩两条匹配，但存储批次和内容 revision 不变。旧游标仍接受原偏移，继续读取会跳过现在排第一的合法结果。qualified／published 两种公开模式和 on-demand／filtered／precomputed 三条搜索路径均复现。

搜索游标原身份只含存储版本、范围、查询及页大小，现在加入排序后可见结果的 SHA256。结果移除、顺序或摘要变化使旧游标返回既有 `INVALID_QUERY`，调用方从首屏重新查询；结果未变时仍可跨搜索路径连续翻页。沿用 `w1` 游标格式，不额外查询数据库，不保存搜索结果或权限缓存。

同时验证仅撤回图片说明、正文仍匹配的情况：命中 ID 集合未变，摘要已改变，也须使旧游标失效。只对 ID 列表取摘要不能覆盖此情况。

## 方案与本机开销

比较 ID 列表摘要、完整排序结果摘要和逐条流式序列化摘要。使用虚构结果、交替策略顺序，每组预热三次后取九次 CPU 样本；完整与流式方案摘要字节一致，ID 方案无法识别只有摘要变化的撤回。

| 两万条虚构结果，序列化约 6.39 MB | 本机中位耗时 | 摘要变化可识别 |
| --- | ---: | --- |
| ID 列表 | 0.905 ms | 否 |
| 完整排序结果 | 7.225 ms | 是 |
| 逐条流式序列化 | 9.132 ms | 是 |

采用完整排序结果摘要；一千条样本中位约 0.343 ms。计算随可见结果线性增长，完整序列化另需临时字符串内存，流式方案减少这部分整串分配但在此样本中逐条调用更慢。这些是本机微测试，不能称为真实 SQL、HTTP、托管延迟或 p95；后续实际页面验收仍独立进行。

## 验证与下一项

冻结离线网络守卫下，PGlite 使用仓库真实迁移和受限 reader，先复现原版六种组合，再验证修复版六种组合。新增十五项定向测试通过，覆盖六组合中的结果移除、仅摘要变化，以及三十七条同名结果在三条路径、两种公开模式、三种页大小下的全部分页、无重复和跨模式游标一致性。没有新增真实网站、数据库、来源或图片请求。

固定离线完整检查通过全部 2,467 项测试，零失败／取消／跳过，类型、三类协议及 1,573 文件隐私检查通过。离线 webpack 构建及 48 项服务追踪隐私检查通过；复用此前已核验的五份真实本机字体响应，输出字节摘要一致，冻结外网守卫保留。此构建证据验证本机编译和字体发射，不证明远端字体服务或平台部署。两套相同锁文件的既有安装在本机复用，构建前转为独立 APFS 副本；未访问 registry，受检应用输入在检查与构建之间未变。

搜索优化与独立预计算仍关闭；本项进入 develop 后，正式发布及真实有界对照按各自流程执行。后续页面验收重点是撤回后旧游标返回重启分页，以及新首屏保留全部当前可见结果。
