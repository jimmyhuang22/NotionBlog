# 2026-11-21：手机上只有一张“上一款／下一款”时占满整行（Claude）

编辑登记：Claude 修改 `src/app/library.css`（一条 640px 以下的规则）。契约、fixtures、接口与媒体路由、依赖、栏目开关未改。

## 做了什么

- 看线上游戏页时发现：作品只有一个邻居（最新或最早的一部，只有“下一款”或只有“上一款”）时，那张卡片按 W-08 只占半宽；在手机上半宽只有 170px 左右，扣掉封面后标题被挤成一个字一行（线上《识质存在》390 宽就是这样）。
- 640px 以下这张卡片改成占满整行，和有两个邻居时手机上上下排开的宽度一致。电脑上不变，仍是半宽靠在自己那一侧。样式是影视、书籍、游戏详情共用的，三处一起修好。

## 怎么验证的

- 在线上《识质存在》（只有“下一款”）390 宽注入同一条规则后截图：卡片占满整行，标题两行。线上页面没有改动。
- Node 24.21.0：`npm run check`（3516 条通过）与 `npm run build` 通过。
- 没有在本机演示数据下看：离线演示模式关着资料库栏目。
