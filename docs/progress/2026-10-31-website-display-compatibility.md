| 路径 | 本次行为与原实现的对应关系 |
| --- | --- |

| Storage／COS、本机媒体和 reader token | 相同 provider 选择与惰性创建，没有新增鉴权、对象读取或写入。 |
| self-hosted 展示 | 原 v1 静态 WebP 路径保留；新增确切 v2 配方及有界动画检查只在相应展示产物被使用时生效。 |

## 构建、部署与流量边界

按仓库代码，内容页在 `connection()` 或 `searchParams` 后读取，动态详情没有 `generateStaticParams`，媒体／API 在请求时执行；根布局与构建配置只读配置。构建不获取媒体 URL，reader pool、token 和 Storage 不在模块导入时发请求。因此构建与部署初始化的预期项目数据库连接、SQL、Storage 请求和数据出口均为 0，约 **0 B**；这不是线上计量结果。依赖下载与部署产物传输属于构建平台流量，不属于项目数据库／Storage 出口。用户或平台实际发起运行时请求后按原读取路径计量。

本机完整构建使用离线演示配置，不能把它当作生产凭据或线上效果的验证。`develop` 不自动部署；发布请求交用户合并到 `main` 后触发既有正式部署。此次不执行线上抽查、不改 Vercel 配置，不触碰私人现役运行包、退役根、Dagu、真实业务锁或计数。
