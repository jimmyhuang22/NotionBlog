# 2026-10-21：公开缓存与本机下架后端实现

执行者：Codex。编辑登记：后端统一读取缓存、API／媒体响应、内部签名刷新和资格接口、本机命令、独立 SQL、根布局与缓存配置、开发环境隔离。页面与组件仍归 Claude，未改其视觉、相对日期、分页交互或 F21 搜索候选。用户三个选择已确认，见[决策](../decisions/2026-10-21-public-content-cache.md)。

默认关闭的 tagged-v1 后端已经接入 content／social／home 最终 DTO 和相关 HTTP。完整参数、环境／连接身份摘要、日窗口和公开版本进入缓存键；冷读结束重核版本，错误不存储。一天主要在可清除的服务端／托管 CDN，浏览器使用前重验证。独立 SQL 将成功完整发布、社会投影与小图映射的待刷新事件和原提交放在同一事务；消费者幂等清理 Next／CDN，失败保留 pending，不重采／上传。

本机命令按站点／连接和固定计划执行；原六锁及数据库 staging 核对避免中断他人同步。中央 deny、版本和待清事件原子提交，课程连带后代，四档媒体关系一并处理，不删除共享对象；真正共用同一 owner URL 时先报告、拒绝执行，等独立绑定。结果不明只读已提交意图，核验前不报告 COMPLETE。

本机 Next16.4 原型发现中间层直接使用 Data Cache 没有复用，因此改成固定、签名的普通 Node 资格接口，保留 middleware 兼容名称，不加地区配置。修正后九次 loopback 请求验证了重复读取、查询隔离、硬标签删除和版本下架。初始原型缺协议清单导致的类型失败与中间层未命中均保留，未冒充通过。真实受限 PGlite、控制协议和恢复测试覆盖十三项。

一次完整检查完成类型和原协议核验，测试 2,371／2,393 通过。22 个失败含沙箱 loopback 监听拒绝、Node 直接模块加载／不支持的 TS 参数属性，以及新网页代码不再等于历史冻结摘要；逐项保留并修复。没有修改冻结兼容清单，新增的当前网页摘要仍被旧过渡明确拒绝。只重跑这十份失败／受影响文件，57 项全部通过，未跳过断言或重新跑整套；最终 webpack 构建、类型检查及 48 份服务端 trace 隐私检查通过，隐私、记录格式、链接和差异核对另行收尾。未把原全检退出码改写为成功，也不把分段复验说成另一轮完整 CI。

接口、标签、前端声明、版本监听及安装边界见[说明](../PUBLIC_CONTENT_CACHE.md)。SQL 由固定本机 CLI 生成，未应用；生产变量、账号、业务调度、网站部署、源／对象数据均未改。下一项是交 Claude 接页面和单一可见标签页的版本失效；集成后准备一次实际安装／正式发布方案。托管 CDN 命中、原浏览器副本过渡和一分钟目标尚待线上有界验收，不重复全站图片／同步测试。
