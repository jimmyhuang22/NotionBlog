# 2026-11-20：定位内容发布的重复超时（Codex）

编辑登记仅涉及此次诊断和本地发布交接。接口、provider、队列、数据库定义及部署均未变更。

新加坡日志确认，四轮游戏增量提交在冻结验证期间超过语句时限。第一轮中断于冻结页构造，另三轮中断于整版媒体就绪校验中的展示图查找。队列对缺少提交回执的操作保留待核验状态，发布器因此在打包前停止。超时位置反映整条语句耗尽预算时正在做什么，不能单凭日志把全部耗时归给最后一次查图。

用短只读事务和现役通用计划，对三份含单图的冻结页比较完整校验结果。直接用本版缩略图和展示图构造最终校验对象，结果均同时等于旧算法和冻结快照，单页从 108–149 ms 降到 4.1–4.4 ms。另取三张非冻结图比较查找路径，原查询逐张取出 261 条历史映射再排序，独立用本版主键先取一条，再核对归属、哈希和来源指纹，结果相同。只是给原查询增加版本谓词，优化器仍可选历史索引。这些测量仅覆盖样本，不代表整轮提速比。

本次经 SSH 读取脱敏调用栈、函数定义、汇总计数和样本执行计划，回传估计低于 0.1 MB。下一步在本地加入候选 SQL、等价性和拒绝路径测试，并在有足够媒体历史的数据库测整笔增量提交。恢复以原定时器完成采集、新加坡发包及上海采用同一清单为准。
