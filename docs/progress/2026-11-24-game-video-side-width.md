## 发现并修好的问题

电脑宽度下，《女神异闻录5皇家版》左栏三张卡片都是 345px 宽，比 280px 的左栏多出 65px，压住了右边：时间线卡片左边被盖住，“游玩感受”被挡掉一个字。原因是左栏内部的一列网格宽度是 `auto`，录像卡片的标题设了不换行，把这一列撑到了标题全长。《识质存在》没有录像，所以正常。我本机预览时录像没对上合集，用的是链接样式，所以没撞到。

- 左栏和右栏的网格列改成 `minmax(0, 1fr)`，卡片不会再比栏宽。
- 游戏页里录像卡片的标题改成最多两行，左栏窄，不再只剩一行加省略号。

## 怎么验证的

- 把这两条规则注入正式页面，宽度 1440、1024、900、700、390、320：左栏卡片在双栏时都是 280px，标题两行（390 一行）不被截，没有横向溢出。
- Node 24 下 `npm run check` 与 `npm run build`，结果见合并请求。
