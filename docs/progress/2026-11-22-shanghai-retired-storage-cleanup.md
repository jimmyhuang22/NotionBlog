# 2026-11-22：上海旧数据库卷和轮转归档清理（Codex）

根据本次授权，在上海按[容量核查](2026-11-22-production-database-capacity-audit.md)列出的范围清理六个旧 PostgreSQL 卷和两份轮转归档。数据库卷来自十月的演练和手工准备。核对容器、挂载、发布及待交付引用后，移除了五个已退出的演练数据库容器及六个旧卷，按磁盘块计约 489 MiB。

两份轮转包对应已退役的历史批次。其中一份的批次号只出现在后续历史批的退役记录里。现役上一版在 Mac mini 有实际还原通过的数据库、媒体和应用归档，读者权限也已验过。Mac 当前保管的归档完整摘要与历史验收记录里的包体摘要有差异，核对了两者登记的回退批次、数据库和媒体摘要以及应用构建与配置身份，均对应同一回退版本。清理时在原有上海交付锁内再次核对归档完整摘要、现役指针和待交付状态，删除两份旧包共约 1.32 GiB，历史签收与退役记录照常保留。

总计释放约 1.80 GiB，操作后根盘约余 28.8 GiB。现役数据库容器、网站发布指针和暂存待交付批次的状态经读回一致。按上海 HTTPS 入口复核首页、《女神异闻录5皇家版》的 PS4 与 PS5 奖杯明细和《吸血鬼爬行者》的 Steam 成就。现役库读回 47 套、2,808 项 PSN 奖杯及 149 套、10,255 项 Steam 成就。只读核对返回的容量、引用与网页响应合计低于 1 MB。
