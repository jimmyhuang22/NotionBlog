# 2026-11-13：访客分析第一阶段接入（Codex）

## 编辑登记与授权

本项从最新 develop 创建独立分支。用户批准按已讨论的集中 Umami、分节点统计、私人后台及个人工作台入口方案开始开发。修改仅涉及可选统计组件、同源采集 API、自托管配置、独立网关、对应测试及本项文档；没有修改内容契约、依赖或栏目配置。

## 修改与接口

- 根布局按私人运行配置启用无界面的页面统计组件；初次访问与客户端路径导航各采集一次，查询参数、预取和同路径重复 effect 不增加浏览量。DNT、GPC 与本机禁用选项均生效。
- 新增 `POST /api/visitor-analytics`，校验 Origin、路径和请求大小，采用受信入口地址及服务端固定的网站、主机和节点。共享密钥、Cookie、搜索词及页面正文不进入客户端统计数据。
- 新增独立原生网关：鉴权转发 `/collect`，封闭原始 `/api/send`，保留 Umami 正常登录界面。网站转发限时、限速、限制并发且不重试；统计失败不阻断网页。
- `SITE_ANALYTICS_JSON` 只允许公开自托管配置；演示、CI、构建与受保护预览关闭。内容 provider、reader、数据库协议和同步行为没有改变。
- [使用说明](../VISITOR_ANALYTICS.md)及[决策](../decisions/2026-11-13-visitor-analytics.md)记录接口和边界；真实地址、账号、数据库与安装证据保留在忽略目录。

## 限制与下一项

当前代码尚未正式发布。统计服务仅回环运行，外网入口、工作台链接、双站启用、实际客户端 IP、浏览器导航和自动内容交付后的配置保留仍待部署验收。统计数据库与内容库独立；未新增保留清理或备份定时任务，不能宣称自动保留期、2FA 登记或完整恢复已验收。

正式发布仍遵守 main 的逐次授权规则。部署应保留既有自托管发布适配，并检查区域接收器的固定代码指纹与配置再生成逻辑；不得直接把统计密钥加入来源快照或覆盖另一任务的接收器。全站同域名地域分流是独立工作，不随此次接入改变。
