# 2026-10-14：B 站账号自动发现与接入（Codex）

编辑登记：用户要求指定 B 站账号的新合集和独立视频自动同步。本项独立处理投稿目录发现、B 站私有增量配置、受限账号接入与验证；不接管前端、共享 DTO、依赖、其他平台或内容／图片同步。

实现：复用原扩展的 key／origin 和固定本机启动器，增加空间域的真实 DOM 目录分页。首屏记录实际页大小，逐页核对总数、末页和唯一身份；B 站增量配置与旧小红书共享范围分离。未知发布经匿名 HTTPS 页面验证作者、公开／付费状态和完整合集归属后进入原 SQLite／outbox。普通六小时详情请求同时保存类型分类，多 P／单稿后来进入合集时复用记录，不再另采；目录卡片另选既有成员作为封面时，以本机完整成员清单判定已知，避免重采。

云端候选：CLI 生成一份迁移，在原社交 schema 增加默认关闭的账号授权表及自动登记记录表、两项账号／链接专用函数，并替换一个原受限投影视图以折叠合集中的多 P 子卡。worker 仅获得这两函数的执行，不获得配置／审批表增改权；reader 权限不增加，新表 RLS 明确拒绝普通角色。登记、采样、投影同事务，匹配回执和幂等保留；撤回、关闭绑定不能被再次发现复批。新合集入口在浏览器实际打开并核对成员后才记录证明，链接未知不伪装验证；补链接不更新统计采样时间。

资源：目录六小时、十五分钟本地检查；发现每事件最多三目标／九十秒，窗口二十详情请求／一百二十八 MiB／十六分钟。原 B 站周期预算、单连接与逐项 ACK 保持；发现／链接处理与原 B 周期、共享来源锁协调。捕获完成后先落 SSD，锁竞争不必再次请求平台。浏览器只使用自己的短暂标签，结束／异常关闭，并恢复上次失联留下的本轮标签；不访问评论、收藏或导出 Cookie，不新增常驻服务。

实际路线预检：旧目录与当前签名目录各一次未登录请求均返回 HTTP 412，公开导航正常但不能把签名存在当作目录可用；不重试或伪造指纹。已登录 Chrome 三页实际为 42／42／25，共 109 个唯一身份；与规范化的既有单稿和 SQLite 合集成员均匹配，未知目标零。一处合集入口和代表成员实际可见。页码先变化而列表暂未变化的现象已纳入等待／去重，不能只看页码。未重采视频统计、上传或修改云端；详细身份／时间／证据仅保留 SSD 私有目录。
