## 封面缓存、权限与撤回

对三个栏目各一个已公开 400 像素封面做有限顺序抽样。普通响应为 WebP，分别 66,996 / 9,654 / 18,972 字节；重复响应内容一致。条件请求均返回 304、正文 0 字节。

第一轮采集将重复的 `Server-Timing` 响应头压成字典，丢失了应用层计时，因此该轮只能用于 HTTP 耗时与体积。修正观测脚本后保留所有同名响应头：6 次普通图片请求均明确标记 `thumb_object ... desc="hit"`，物体读取阶段为 0.03–0.05 ms；每次仍有 `thumb_scope` 和 `thumb_recheck`。3 次 304 也有初始和最终检查，未进入对象字节读取阶段。它们是预热后的选定图片样本，不能将 6/6 外推为自然访问命中率或 SSR 数据缓存命中率。

这批热样本中通常初始检查与重查各约 144–147 ms，一次初始检查为 582 ms；304 完整公网耗时 431.8–450.7 ms。缓存省掉对象存储读取，却保留权限成本和 HTTP/网络开销；响应头中的两个权限阶段不是完整 SQL 语句计数。

随后等待既有 5 分钟 TTL 自然到期，在未清理缓存的情况下再次取相同三个封面。三个首次读取都由应用头确认 MISS，三个紧接的重复读取均确认 HIT；三个条件请求均为 304。这里的冷/热只指缩略图字节缓存，不是数据库连接、SSR Data Cache 或整机冷启动。

| 封面样本 | MISS 完整耗时 ms | HIT 完整耗时 ms | 304 完整耗时 ms | MISS / HIT 对象阶段 ms | 200 / 304 正文字节 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 影视 | 1724.8 | 903.6 | 433.5 | 371.50 / 0.05 | 66,996 / 0 |
| 书籍 | 587.6 | 435.2 | 435.8 | 136.07 / 0.03 | 9,654 / 0 |
| 游戏 | 672.8 | 555.1 | 443.9 | 105.98 / 0.05 | 18,972 / 0 |

命中率在这组人为排序样本中是首次 0/3、重复 3/3，不代表自然流量。由现有实现与 MISS/HIT 标记可判定每次 MISS 进入一次对象读取路径，HIT/304 不进入对象存储读取路径；底层传输是否重试没有远端日志，不把路径次数写成精确云端请求数。三个条件请求合计省去 95,622 字节响应正文。热 200 仍传完整图片，并不会节省浏览器传输量。影视 MISS 的初始权限阶段约 580 ms，而热请求约 146 ms，不能把全部端到端差异都归因于对象缓存。

这组 9 次响应也全部保留初始与最终资格检查；最终阶段约 145–146 ms。由此可以确认线上已有媒体字节缓存没有跳过该阶段，但无法得出新 SSR 入口的 SQL 次数或映射成本。
