# 2026-10-13：课程代码只出现一次（Claude）

编辑登记：Claude 本轮前端修改与验证完成。范围：`src/lib/format.ts`（新增 `courseName`）、`src/app/study/page.tsx`、`src/app/study/[course]/page.tsx`、`src/app/study/[course]/layout.tsx`、新增 `tests/course-name.test.ts`、前端接手说明与一条决策记录。没有新依赖；契约、fixtures、栏目开关、接口与媒体路由未改。

起因：核对后端的只读内容快照时确认，真实课程名以课程代码开头，而学习首页的卡片、课程页的标题、课程目录的抬头都另有一行写着代码，代码因此出现两次。出了两个做法的对比图，用户选了“小字保留代码、标题去掉代码”。决定见 [课程代码在卡片和标题里只出现一次](../decisions/2026-10-13-course-code-once.md)。

## 改了什么

- 新增 `courseName`：课程名以自己的代码开头（不分大小写，代码后面跟着空格、冒号、连接号这类分隔）时去掉代码，返回剩下的课程名；代码前面的方括号标记保留；其余情况原样返回。
- 三处标题改用它：学习首页的课程卡片、课程页的标题、课程目录的抬头。小字那一行（代码，或代码加学期）不变。
- 浏览器标签页的标题、面包屑、搜索结果没有动。

## 怎么验证的

只在演示数据下验证；本机无界面 Chrome。

| 项目 | 结果 |
| --- | --- |
| 单元测试 | 代码加空格、冒号、连接号的写法都去掉；大小写不同也认；代码在名字末尾、名字只有代码、代码只是另一个更长代码的开头、没有代码，这些都原样返回；方括号标记保留 |
| 学习首页（1280、390） | 两张演示卡片：小字是代码，标题是“[演示] 课程名”，没有横向滚动 |
| 课程页与笔记页（1280、390） | 标题和目录抬头只写课程名；上面的小字仍是“代码 · 学期”；标签页标题仍是完整的名字；面包屑不变 |
| 另外三套主题 | 课程页在苹果、像素、千禧下各看过一张 |
| 自动检查 | 见合并请求正文 |

出对比图时另用过一份按真实课程表形状造的 13 门虚构课程（代码在最前、没有方括号标记），只在本机用，没有提交。
