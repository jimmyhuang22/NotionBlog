## 做了什么

- 用户从四种主栏做法里选乙（[决策](../decisions/2026-11-21-game-dates-strip.md)）。
- 页面：游戏详情。组件：`GameDates` 取代左栏的 `GameTimeline`，放在主栏标签下、正文上；左栏去掉日期一组。
- `dateStripNotes`：每个日期旁要写的两样，一段日期的天数（两头都算）和到下一个日期隔了多久；`spanLabel` 把天数写成天、月或年。按站点时区的日历日算。
- 样式：电脑上横排、间隔站在连线上（底色挡住线）；640 以下竖排、间隔写在日期下面带向下箭头，主栏上面一道细线和左栏分开。原来 `.game-timeline` 与 640 以下 `.work-game__dates` 的规则删除。

## 怎么验证的

- 演示页 `/preview/game-trophies` 渲染真正的 `GamePage`。本机临时让它接受线上三款游戏的真实日期（只在工作区里改，截图后还原，没有提交）：《识质存在》（发售 → 9 天后 → 体验共 46 天 → 3 个月后 → 最近游玩）、《女神异闻录３ Reload》（同一天、16 个月后）、《宝可梦 Pokopia》（四个日期、15 天后 / 同一天 / 5 天后，加两个平台的奖杯与正文），另有只想玩（只有发售）和没有日期（“日期未记录”）两种。
- 宽度 1280 与 390，墨水浅色；1280 另看了墨水深色、苹果、千禧浅深、岛屿。没有横向溢出，没有控制台错误。
- 新增两条测试（间隔与天数、天月年的分界）。Node 24.21.0：`npm run check`（3518 条通过）与 `npm run build` 通过。
