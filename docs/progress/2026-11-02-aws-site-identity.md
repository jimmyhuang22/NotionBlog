# 2026-11-02：恢复 AWS 网站站点配置（Codex）

编辑登记：本项只修改 `docs/SELF_HOSTED.md` 并新增本进度记录。应用、页面、组件、契约、依赖、SQL 和构建输入未改；实际修复在仓库之外的受保护网站运行配置中完成，个人值与配置备份不提交。

## 原因与修复

AWS 迁移使用了历史部署目录中的旧站点 JSON，站名、简介和头像未沿用正式值，学习项目与已有页脚入口也遗漏。旧配置能通过结构校验，因此服务正常启动，但学习入口显示通用课程分组。原平台的站点变量为不可回读的 Secret，返回空值不能证明正式配置为空。

从此前已实际发布、验证过的私有备份找回正式站点配置。用户明确批准恢复站名、简介、头像、学习项目及原页脚链接，并重启网站。仅替换 `SITE_CONFIG_JSON` 中这五项，其余网站环境字段、时区、社交链接、来源、公开资格、栏目开关和收录设置保持。写入前核对当前站点对象与预期一致，建立同权限回退副本，再原子替换；配置仍由服务用户所有，权限0600。

本轮没有新建 main 发布或替换程序。服务器实际 `SOURCE_COMMIT` 为 `b9f39fb9375313770ad3a450ad0bd32a23b3e1f2`，与核对时最新正式 main 一致；develop 当时多出的应用变化为未发布的 M08 读取期限修复，没有更新的页面或组件。

## 验证与范围

- 本机既有 profile loader 与站点 parser 接受候选，学习项目有效；其余环境字段不变。服务器以实际服务用户验证受保护配置通过，重启后服务 active、running，自动重启次数0，本机健康204。
- 公网浏览器核对正式首页的新站名和简介，头像实际加载且自然尺寸非零，原页脚入口恢复；学习页显示原项目名称、编号及目标路径。修复后的首页和学习页截图仅私有保存。
- 限定 HTTP 抽查：www 首页200、学习项目目标200、健康204，均为 Cloudflare DYNAMIC；三次响应正文合计167,318字节。连同浏览器图片与网站读取，云端只读流量估计数MB以内，数据库及对象存储出口未独立计量，未批量抓取。
- 第一次服务用户验证因命令停留在管理员家目录而被 Node 目录权限拒绝，尚未执行重启；切到实际 release 目录后验证及重启成功。没有重做已成功的配置写入。

本项仓库变化为纯说明，完成记录格式、相关链接、差异和隐私检查；未重复整套 check／build，也不将本次运行配置验收称作新版程序发布或全站性能验收。数据库、媒体存储、凭据、其他服务与后台调度未改。
