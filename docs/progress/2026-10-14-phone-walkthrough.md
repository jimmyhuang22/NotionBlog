## 手机走查（正式站点，真实内容）

无界面 Chrome，390 宽、触摸模式，14 个页面各一次文档请求：首页、动态、学习首页、课程页、一篇笔记、影视列表、一部影视详情、游戏列表、相册列表、一个相册、作品页、搜索结果、关于页、一个不存在的地址。每页在同一次打开里换成墨水深色、苹果、像素、千禧再量一遍。超过 400 KB 的图片不下载。

| 项目 | 结果 |
| --- | --- |
| 横向溢出 | 14 页 × 5 种主题配色都没有 |
| 小于 12 像素的文字 | 没有 |
| 读不出来的图片 | 没有（被我拦下没下载的封面显示的是各自的占位，不算） |
| 脚本错误、页面自己重载 | 没有 |
| 页头高度 | 墨水与千禧 106，苹果 91，像素 138 |

找到并修了三处：

- **像素主题的页头在手机上多占一行**。点阵字体的站名加上两个工具按钮放不下一行，按钮被挤到第二行，页头 138 高。站名在 420 及以下小一号后，390 与 360 宽都是 95。320 宽仍然放不下，没有再缩。
- **课程目录的展开箭头太窄**。箭头只有 24 宽，手指不好点。可点范围向左扩到 40 宽，样子不变。
- **两处英文占位漏给了访客**。课程页里没有公开的子页面显示成 “Unavailable page”，不支持的内容块后面带着 “（Unsupported Notion block）”。这两个词是后端用来遮住真实标题和块类型的固定占位，不是内容。现在未公开的页面写“未开放的页面”，泛泛的“不支持”不再加括号说明；后端给出具体名称时照旧显示。

看到但没有改的：

- 关于页的正文还是两行占位文字，这是内容，不归前端。
- 首页与作品页上有一件作品的数字标着“未按期更新”（读取时间比当时早八个多小时），这是按规则如实标出来的，说明那一路的定时刷新当时没有跑成。
- 页脚的“关于”和面包屑的第一个链接宽只有两个字（28），高度够；没有动。

## 看大图的手势（本机，模拟触摸）

在演示数据的正文页和相册页上，用模拟的触摸事件走了一遍：

| 手势 | 结果 |
| --- | --- |
| 点图片 | 打开，焦点在关闭按钮上 |
| 两指张开、合拢 | 放大到 2.6 倍，再回到 1 倍 |
| 放大后单指拖动 | 图片跟着移动 |
| 双击两次 | 放大到 2.5 倍，再回到 1 倍 |
| 相册里左右滑动 | “1 / 2”到“2 / 2”再回来 |
| 整个过程 | 后面的页面没有滚动，浏览器没有被缩放 |
| 点关闭（44×44） | 关上，焦点回到那张图片上 |

没有发现问题。这是模拟出来的触摸，惯性、误触和两指旋转这些手感上的事只有真机能看。

## 键盘与读屏结构

| 项目 | 结果 |
| --- | --- |
| 手机宽度下用 Tab 走页头（本机） | 跳到正文、站名、各栏目、“更多”，顺序与看到的一致；回车打开菜单，再按 Tab 依次是影视、书籍、游戏、相册，走出去后菜单自己关上；在菜单里按 Esc，菜单关上、焦点回到“更多” |
| 1280 宽（本机） | 没有“更多”，九个栏目按原来的顺序都能走到 |
| 关于弹层（本机） | 头像上的入口读作“关于我”，标明会弹出对话框；回车打开，焦点进到弹层里，弹层有标题；Tab 走不到后面的页面；Esc 关上，焦点回到头像 |
| 作品页给读屏的结构（正式站点，读无障碍树） | 一个一级标题、每个年份一个二级标题和一个有名字的区域、清单是列表；20 行都是有完整名称的链接：日期、标题、平台、类型、数量、数字、在哪个平台打开、可能要求登录，数字超期的还带读取时间 |

改了一处：作品清单里分隔用的小圆点会被读进链接的名称里，现在在支持的浏览器上不读出来（不支持的浏览器照旧）。

没有用真正的读屏软件听过，以上是结构和名称层面的检查。
