- 从 develop `fd94970` 建立 `codex/render-rate-limit-20261107`。用户批准在 Nginx 访客地址修复验收通过后继续实现；[代理修复 PR](https://github.com/jimmyhuang22/NotionBlog/pull/296)单独交付。
- `POST /api/render/snippets` 接收原 `Snippet[]` JSON 数组，成功返回以片段 id 为键的 HTML 字符串对象。不支持的片段仍省略并显示原文。保留每批 24 项、累计 60,000 个 UTF-16 字符，以及既有单项代码、行长和公式规则。
- 删除旧 Server Action 文件，原解析／渲染核心改为普通服务端模块。浏览器合并队列只替换发送函数，改用同源 fetch；失败会拒绝本批请求，允许后续需要时再请求。传输最多等待八秒，拒绝响应和不合法成功响应均按失败处理，不自动重试。
- 跨源请求返回 403；非法 JSON／片段或输入预算返回 400；限流沿用 503、`RATE_LIMITED` 和 `Retry-After`。响应不缓存。输入传输上限 400 KiB，兼容原字符上限全部采用 JSON 转义的情况；读取请求体最多三秒，完成／失败／取消均释放并发。
