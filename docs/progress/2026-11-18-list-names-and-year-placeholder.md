# 2026-11-18：列表名字用正文字体，年份占位改成短条（Claude）

编辑登记：Claude 修改 `src/app/skins.css`（墨水主题那一节新增几条规则）。契约、接口与媒体路由、取数层、fixtures、栏目开关、依赖与后端代码未改。

## 改了什么

两项都只在墨水主题（浅色与深色）生效，苹果、岛屿、千禧不变。

- 列表里的名字改用正文黑体、略加粗：影视、书籍、游戏卡片的名字，作品页卡片名，首页时间线里的作品、游戏、视频名与动态卡片标题。手写体留给页标题、栏目标题、月份、页头和名字。用户 11-16 看过前后对比原型，当时没选，11-18 决定做。
- 影视、书籍、游戏页加载时，年份筛选的占位从一整块灰色胶囊改成一排短条，位置大致对着年份文字；旁边的“最近”占位没有灰底（随 #357 的规则）。动态页的占位不变。

## 怎么验证的

- Node 24.21.0：`npm run check` 与 `npm run build`，结果见合并请求。
- 正式站点只读验证：把这次的规则临时注入真实页面截图（不改服务器、不写数据）。看了游戏页桌面浅色与深色、游戏页手机 390、首页时间线、作品页。加载占位是把占位的同一段结构临时插到真实筛选上面截的，没有在真实的慢加载中看过。
