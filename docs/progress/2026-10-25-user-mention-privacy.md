## 修改、接口与 provider

正文原来直接采用用户提及的 `plain_text`，并可能沿用附带的 href。复核同时发现标题、摘要等元数据的 `plainText` 也会保留该显示名。两条路径现在共用中性标签 `User`，正文不附链接，原有文字样式保留。完整用户对象与只有 ID 的部分对象采用同一规则，不为解析提及新增 API 请求。

同一转换器覆盖段落、标题及目录、嵌套块、代码／表格、图片说明与替代文本。v1／v2 provider 的详情、Status 列表和 v2 采集／搜索投影均在输出前执行该规则。页面与数据库提及的既有资格判断不变，日期提及和作者手工输入的普通文本保持原义。

公共 DTO、配置、依赖、SQL 与冻结恢复兼容清单均未改变。历史外部视频恢复测试新增当前隐私转换器的精确摘要，并继续断言旧恢复协议必须拒绝它；没有给旧采集快照增加兼容放行。
