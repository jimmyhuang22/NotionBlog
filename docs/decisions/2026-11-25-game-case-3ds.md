# 2026-11-25：3DS 卡盒照日版实体盒

状态：已选定，前端已接入。补充 [2026-11-24-game-case-printed-faces](2026-11-24-game-case-printed-faces.md)：那条写 3DS 仍用原来的顶条，本条起改为照实物。

## 为什么

用户问 Switch 和 Switch 2 卡带盒比例是否不同时，发现 3DS 也按 0.62 的竖盒画，和实物不符。查证后日版 3DS 盒是横的。用户看过原型，要求竖条上的“3DS”字样和实体盒的样式、位置、大小完全一致，之后定下按原型正式改。

## 决定

数值按 5 张日版实体盒商品渲染图（姆吉拉的假面 3D、萨姆斯归来、火焰之纹章 if、众神的三角力量 2、究极之日）量出，换算成卡盒宽度的比例：

- **比例**：宽 1.091 : 高 1（第三方替换盒标 137 × 125 毫米，约 1.096）。
- **外壳**：透明浅灰，上边约占高度 2.75%，下边约 2.9%，书脊一侧没有，右边约占宽度 3.15%。
- **封面**：正方形，在左边，占宽度 86.5%。
- **竖条**：白色，从宽度 86.5% 到 96.85%。
- **字标**：“NINTENDO 3DS”，用维基共享资源的公有领域矢量图 `Nintendo 3DS logo.svg`，图形原样使用。“3”红色，其余黑色，屏幕图标灰色。从下往上竖排，字头朝封面，占盒高 24.4%–73.6%、盒宽 89.3%–94.65%。
- **通关／白金**：在封面右上角，和 Switch 一样。
- **最近在玩**：大幕和小缩略图按宽度排，3DS 盒加宽（大幕 200，缩略图 92，手机 74），让它和 PS 盒差不多高。游戏墙按高度排，不用改。

## 没做的

- 火焰之纹章 if 两版的竖条是黑色，宝可梦究极日月的外壳染成红或蓝，都没做。所有 3DS 盒都是白条、浅灰外壳，因为数据里没有这些区分。
- 竖条顶上的 amiibo、Nintendo Network 徽标没画。
- 共用的 `gameCaseAspectRatio` 仍写 3DS 为 0.62。它也用来判断竖图够不够高，归后端管，见[后端交接第二十三节](../BACKEND_HANDOFF.md#二十三3ds-卡盒是横的2026-11-25claude)。前端的 `gameCaseFace` 已经单独改成 1.091。

## 代价

游戏墙每排一样高，3DS 盒在墙上比 Switch 盒宽不少。实物的 3DS 盒比 Switch 盒矮，约为它的四分之三，墙上没有按实物缩小。线上 6 款 3DS 都还没有竖图，暂时是横图放在正方形封面里，上下虚化填满。
