# 2026-10-13：课程代码在卡片和标题里只出现一次

用户确认，Claude 落实。

## 定了什么

课程名在来源里通常写成“代码 课程名”，而学习首页的课程卡片、课程页的标题、课程目录的抬头都另有一行小字写着代码，于是代码出现两次。用户看过对比图后选定：**小字保留代码，标题去掉开头的代码，只写课程名**。另一个做法是去掉小字那一行、标题保持完整。

## 范围与边界

- 只在课程名确实以自己的代码开头时去掉；不是这种写法的课程原样显示，只有代码没有名字的也原样显示。
- 只改这三处的显示。浏览器标签页的标题、笔记页的面包屑、搜索结果和接口返回的数据仍是完整的名字，来源里的内容不动。
- 演示数据的“[演示]”标记在代码之前，标记保留。
