# 2026-10-17：明暗一键切换，主题单独一个按钮

用户觉得页头的主题菜单把“主题”和“明暗”放在一起，功能重叠：想换深色得先打开菜单，设计好的切换动效也藏在第二步后面。他们希望点深浅色就直接切换，主题换个地方。Claude 做了三个可点的原型：A 页头两个按钮、B 主题挪到页脚、C 分体按钮。用户选了 A，两件小事按 Claude 推荐的做。

定下来的：

- 页头工具按钮从两个变成三个：搜索、主题（调色盘）、明暗（月亮／太阳）。
- 明暗按钮点一下就在浅色与深色之间切换，不开菜单，当前主题的切换动效从这个按钮出发。
- 主题按钮打开的菜单只有四套主题，底下一个“明暗跟随系统”开关；原来“跟随系统／浅色／深色”三选一的那一行去掉。
- 跟随系统：第一次来跟随系统，点过一次明暗按钮就记住选择；想回到跟随系统，在主题菜单里打开开关。没有选“明暗按钮三态循环”。
- 只有一种明暗的主题（千禧）：明暗按钮留在原位，点一下在下面冒出“千禧只有浅色”，不切换。没有选“换回墨水深色”和“把按钮藏起来”。
- 手机上为了让站名和三个按钮仍在一行：540 以下按钮收窄到 40、间距收紧，380 以下站名小一档（像素在 340 以下）。

这一条改的是页头的全局入口，取代存档里“已确认二十”中“页头按钮改为主题菜单”的做法；四套主题本身和各自的切换动效不变。
