# 2026-10-17：图片允许私有浏览器缓存一天

用户在反馈F17明确选择图片缓存一天，并接受撤回前已访问的副本仍可从该访客浏览器中显示至新鲜期结束；页面五分钟缓存由前端另行实现。此决策修改旧“每次显示都要到服务器重查媒体资格”的要求。

成功的v2／社交站内图片字节响应采用private,max-age=86400,must-revalidate；CDN及Vercel-CDN专用头no-store，不使用immutable或stale-if-error。源内容摘要虽进入地址，派生配方与发布资格未必使同一预览URL永久不变。动态签名302、未授权、404和错误仍no-store，冻结v1保持原策略。

服务端立即拒绝撤回后的新请求并保留下载后检查；已在私有缓存中的副本在新鲜期内不会触发新请求，不能实时召回。过期须重新验证；浏览器也可提前清理或根据刷新指令发起请求。不向共享缓存长期放行，不改变HTTP内容API、公开范围、数据库资格、网站同步状态或原图交付方式。

依据：[RFC9111](https://www.rfc-editor.org/rfc/rfc9111.html)、[Vercel缓存头优先级](https://vercel.com/docs/caching/cache-control-headers)。原有文档中的媒体no-store说明，在本决策覆盖的成功字节响应范围内由本条替代。
