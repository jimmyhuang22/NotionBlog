# 2026-11-24：游戏墙悬停时名字放进盒里，其余不变（丙）

**状态**：已采纳，用户从六个可交互原型里选了丙，并要求去掉“也在 X”；Claude 实现。取代 [游戏墙决策](2026-11-24-games-wall-layout.md) 里“名字”一条的悬停做法，卡盒和排版不变。

## 背景

游戏墙上线后，鼠标指到一只盒子时，其余盒子透明度降到一半。用户觉得“很丑”：米色底透上来，其余盒子像被洗淡、发白；深色名字签还压在下一排盒子上。

Claude 用线上游戏墙的原样标记、样式、封面和字体做了一个能直接用鼠标试的原型，对比现状和五种做法：甲 抬起、乙 光圈、丙 名字在盒里、丁 倾斜反光、戊 其余退后但不发白。原型在 `.local/previews/games-wall-hover-20261124/hover.html`。

## 决定

- 能用鼠标的设备上，指到或用键盘移到一只盒子时，它抬起 6px；**其余盒子不变**。
- 名字不再浮在盒子下面，而是从这只盒子封面窗口的下半截浮出，底下渐暗；名字最多两行，用手写体。时长胶囊这时让位。
- 名字下面只写评分（有评分时）。**“也在 X”不再写**（用户 2026-11-24），盒子平台条上的平台不变。
- 触屏设备不变：名字写在盒子下面一行，不写评分。

## 影响

- 不再有东西盖住下一排盒子。
- 别的平台在游戏墙上不再出现，只在详情页里有。
