# 2026-11-12：长笔记底部目录的第二版（第五轮设计审查 M-17、X-15、X-16、X-17）

用户看过第五轮对比原型后说“全部按推荐的来”，经 Codex 整理交接，Claude 实施。补充 [2026-11-11 阅读体验调整](2026-11-11-reading-design-refinement.md) 里“长笔记的本页目录可就地打开”一条。

## 定了什么

- **整块滑入**：手机上的底部目录从第一帧起就是不透明的纸，整块从屏幕底边滑上来（约 0.3 秒），遮罩单独淡入；关闭原路返回。不再有半透明时目录文字和正文叠在一起的帧。
- **只有编号的标题并进下一条**：作者把“1.”和标题写成两个标题时，目录里显示成一条“1. Datalink Layer…”，点它跳到编号那个标题。底部目录、窄屏顶部的折叠目录和桌面右侧的本页目录一起改，折叠条上的条数按合并后的算；读到被并进去的那个标题时，跟随高亮仍落在这一条。编号后面没有标题、或紧跟着另一个编号时不并。
- **“本页｜课程”两个页签**：没有常驻课程目录的宽度（1100 以下），底部目录顶上有两个页签，默认“本页”；“课程”就是课程目录的内容，和抽屉里的是同一份，不另外读取。页顶原有的“课程目录”按钮和抽屉保留。
- **700 以上是贴着按钮的浮层**：宽约 360，从“本页目录”按钮上方长出来，不加遮罩，点外面或 Esc 关闭；按钮在右侧时浮层也在右侧。700 以下仍是底部整宽。
