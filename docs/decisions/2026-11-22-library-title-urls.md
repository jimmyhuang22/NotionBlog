# 2026-11-22：作品库使用作品名地址

网站的游戏、书籍和影视详情分别采用 `/library/games/作品名`、`/library/books/作品名` 和 `/library/movies/作品名`。三类作品同时切换。旧页面 ID 地址直接返回 HTTP 404。

- 首次公开时按栏目分配固定名称。可在第一次迁移中指定已有的简短原名。其他条目优先采用已有原名，缺失时采用标题，经大小写、分隔符和 Unicode 归一处理。标题修订继续使用分配时的名字。同名优先用相应的发行年份或作者区分，仍有冲突时分配稳定后缀。曾使用的名称继续归原作品，以免旧书签指向新作品。
- 站内正文、详情导航、列表、搜索、首页活动、规范链接和站点地图使用新地址。正文中指向本文站的旧作品地址在输出时换成对应名称地址。访问、链接及撤回均按现有公开资格判断。
- 名称库由正式发布数据生成和维护。两站采用同一份分配记录。Notion ID 标识内部记录、同步与奖杯关联。
