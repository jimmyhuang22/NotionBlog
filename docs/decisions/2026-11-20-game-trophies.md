# 2026-11-20：游戏详情加奖杯（乙），分两步上

状态：已采纳，待后端数据（[交接包十六](../BACKEND_HANDOFF.md#十六游戏详情的奖杯2026-11-20claude)）。

用户看过线上《艾尔登法环》页面上注入的三个方向（甲 · 只在左栏加统计；乙 · 最稀有三个加最近拿到；丙 · 奖杯墙加时间线），选乙。补充 [游戏详情改为“全幅主视觉”](2026-11-19-game-detail-art.md)。

## 决定

- 左栏时长下面加一组：已获得 / 总数、完成度条、白金金银铜各几个。
- 正文下面、上一款 / 下一款上面加一节“奖杯”：最难拿的三个是带边框的卡片（图标、名称、说明、等级和全球获得率）；下面“最近拿到”按时间列六个（图标、名称、说明，右边日期和获得率）；其余收进“全部 N 个”“未拿到 N 个”两个按钮。
- 分两步：先上左栏统计，逐个奖杯有了数据再上那一节。
- 同一款游戏在几个平台都有奖杯时，每套分开显示、各标平台，不相加、不挑一套。
- 没有奖杯数据时整节和左栏那组都不显示，不写“暂无”：任天堂没有奖杯系统，不经 Steam 的 PC 游戏拿不到成就。一个都没拿到（0 / N）照常显示。
- 有奖杯时不再显示“还没有写下记录”；正文和奖杯都没有时才显示。
- 获得日只到日；未获得的隐藏奖杯不显示名称和说明。

## 范围

- 只改游戏详情页；列表卡片和首页不加奖杯。
- Notion 里手写的正文照旧显示，去留等用户筛查后另行决定。
- 不改 [平台日期只公开到日](2026-10-14-game-played-date-policy.md) 和平台时长的公开规则；这里只是奖杯按平台分套。
