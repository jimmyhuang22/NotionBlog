# 2026-10-25：自托管只交付展示图片

用户确认先完成整轮离线后端实现，并准备Claude前端交接。此决定补充[独立自托管入口](2026-10-25-self-hosted-runtime.md)及既有缩略图规则：只在专用自托管入口显式开启display-only时采用新规则，普通开发、Vercel及原COS/Notion路径继续沿用原配置。

Mac保留原图，独立新配方生成必备最大展示版（宽度上限1600，小图不放大）及有收益的400/800档。转正、sRGB、透明度与元数据清理保留，Q85与无损择小；动画、多页、高位深和坏图阻止整批完成，不取首帧或回原图。没有单独档位时选择已有展示副本；已声明文件损坏或缺失明确失败。原图不进入产物目录。

不可变清单按数据库runId保存，绑定assetId、owner、原件SHA与来源指纹；文件和清单先准备并验证，后提升数据库批次，不新增独立的全局媒体指针。复用现有受限媒体资格投影，读取前后核对；不新增SQL、角色或权限。网站进程只有文件读取接口，目录不在public下，部署时须只读挂载。

`ImageAsset`新增可选delivery字段，描述最大展示版实际尺寸；读取层按同次合格投影补充，冻结同步输入仍拒绝该字段。Codex完成后端及交接，Claude负责ContentImage/Lightbox接线和文案，未接线前不能宣称灯箱验收通过。初期保留严格TLS、reader隔离enforce、no-store/noindex，社交媒体不纳入本轮。

本轮只使用虚构图片与隔离数据库，不读取真实图片/凭据，不访问业务云服务，不部署上海，不恢复同步，不改域名，不推送、合并或发布。真实安装、完整媒体覆盖及同步发布接线须另行准备和授权。实现与限制见[后端说明](../SELF_HOSTED_MEDIA.md)。
