# 2026-10-23：一次搜索目录元数据只读核查

用户在审阅明确限额后确认继续，允许针对既有网站数据库的一次目录元数据读取：一条 SELECT、一个受计量的客户端连接、64 KiB 结果／256 KiB 接收、十秒语句／六十秒全程、零重试。此项不授权安装、应用启用、合并、部署、十八次搜索对照或业务任务操作。

目标与现有受限读身份先核对。完整草稿包含扩展登记表，但冻结权限不允许该身份直接读取；实际查询缩小为可见目录、权限布尔和明确未读标记，不读取登记行、不提权、不改授权。接收字节按客户端到既有数据库入口的 TCP 传输计量，不能据此推断连接池内部后端数或服务商账单。

本次唯一查询返回后未通过会话事务只读状态验证，连接与转发器已关闭；不留存未验收目录结果，不将其作为安装前置通过。一次许可已消费，没有重试或剩余额度。

后续显式只读事务是新方案：最多五条客户端 SQL 提交，其中只有一条目录 SELECT，其余为 BEGIN READ ONLY、两条 SET LOCAL 和 ROLLBACK。它不是本次许可的自动续用；实际窗口、计量与明确授权另定。安装者、登记摘要与保护前像仍未验收。见[准备说明](../SEARCH_INSTALLATION_PREFLIGHT.md)与[执行记录](../progress/2026-10-23-search-catalog-preflight-read.md)。
