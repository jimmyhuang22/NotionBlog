# 2026-10-23：搜索应用回退采用保留旧部署方案

用户在审阅条件化方案后选择“采用此方案继续准备”。后续应用回退保留旧生产部署及其原环境，以切回旧部署替代逐项重建不可回读的配置值；未知仍保留未知，不要求回读或重设 Secret。

本决定调整[安装守卫说明](../SEARCH_INSTALLATION_GUARDS.md#配置与实例回退前像)中必须以确切配置值重建应用实例的单一路径。它不免除旧部署的存在、源码与生产域名经历、保留、套餐回退限制、操作者资格及外部数据库兼容核对；也不把历史观察或本地模拟转换为当前运行证明。任一条件不满足即停，不为证明资格而先制造发布。

原项目环境设置保持；新验收实例需要明确、独立、受审的配置与同一源码，不能把未知的生产 Secret 复制给 Preview。若另行决定改项目设置或重建应用，仍须取得相应前像并恢复确切前值，未设置恢复未设置。

回退顺序为先让旧应用承接，再确认候选实例、连接池及在途请求排空。未使用的可选 v5 可以先保留；如需卸载，另行核对精确三函数／摘要／owner／依赖，只以 RESTRICT 删除指定对象及匹配 v5 登记，不删旧登记或业务数据。

此次仅批准方案方向与后续准备，不授权数据库安装或登记、配置写入、新云端实例、S13 实测、任务恢复、合并、发布或实际回退。数据库前像、fresh 占用与 owner 人工审阅等原安装要求继续适用。

平台机制参见 [Instant Rollback](https://vercel.com/docs/instant-rollback) 和[部署保留说明](https://vercel.com/docs/deployment-retention)。真实部署身份、配置、保留值、时限偏差及回执仅保存在忽略的私人材料中。
