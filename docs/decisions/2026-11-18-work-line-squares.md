# 2026-11-18：首页轻记录的作品小图统一成方图

状态：已采纳。用户看了 #362 上线后的首页，觉得时间线上的作品“有点丑”；看过四组对比（现状、甲 统一方图、乙 小图放右边、丙 作品不放小图）后选甲。取代 [2026-11-11 阅读体验与首页主次](2026-11-11-reading-design-refinement.md) 里“小图按平台比例（横封面约 92×52，竖封面 39×52）”一句。

## 决定

- 首页轻记录（`HomeWorkLine`，单件作品与连着的两三件）的小图一律是 48×48 方图，和游戏那一行的方图一样。横封面裁中间，竖封面从顶部裁。
- 原因：小红书竖图 36 宽、B 站横图 85 宽、游戏方图 48 宽，相邻几条的标题从三个位置起头；统一后标题对成一列。竖的长截图缩到 36 宽也看不清。
- 代价：B 站横封面在首页只剩中间一块；完整封面在作品页和横滑卡片里照旧。
- 不变：横滑卡片（四件及以上）、作品页、平台数字与链接规则、没有封面时的占位。四个主题都适用。
