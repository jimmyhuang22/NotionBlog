# 2026-10-14：作品封面存图片，不存平台链接

用户确认，后端落实，前端配合。

## 定了什么

发在其他平台的作品要显示封面（见 [作品卡片](2026-10-14-work-cover-cards.md) 与 [作品页](2026-10-14-works-page-covers.md)）。用户问封面是把图片存下来，还是只存平台的图片链接让前端加载。Claude 建议存图片，用户同意：

- **封面存图片本身，放在自己的存储里，经站内地址给前端。** 不把平台的图片地址交给访客的浏览器。

理由：平台地址会失效（有的带签名和时效，有的有防盗链）；访客的浏览器会因此直连平台；平台只给原图，没有适合列表的小图；站内图片一律走站内地址是既有规则。

## 范围和边界

- 这是对做法的确认，不是对真实执行的授权。从平台下载、迁移安装、对象上传、存储开销和调度改动，由后端带着盘点和方案另行请用户点头。
- 契约不变：仍是 `SocialWork.cover`，拿不到就是空值，不用别的图顶替。
- 取哪张图、存在哪条路径、怎样判断封面变了，由后端定；前端的要求写在 [后端交接包](../BACKEND_HANDOFF.md) 第十二节。
- 前端已经做完：封面到位后首页和作品页自动换成带封面的样子，可以按平台分批到位。
