# 2026-10-18：排序是一个切换按钮，焦点框只给键盘

用户通过 F34 交接（2026-10-18）选择：

- 影视、书籍、游戏的列表只按“最近”（默认）和“最早”排序，去掉“名称”；控件是一个按钮，写当前排序和方向（“最近 ↓”“最早 ↑”），点一下换成另一个。没有“排序”二字，游戏也写“最近”，不再因有平台日期改写为“最近游玩”。旧地址带 `order=title-asc` 按默认打开，不报错；接口里的这项不变，页面不再使用。
- 按钮固定在年份条同一行的最右边，年份多时年份条自己横向滑动；没有年份条的页面按钮在同一位置。手机上同样是这个按钮，不再收进菜单。
- 作品页同样一个按钮，在“最新”和“播放最多”（B 站）／“点赞最多”（小红书）之间切换，用切换图标而不是上下箭头。
- 焦点框只在键盘操作（Tab、方向键）时出现；鼠标、触屏点过的元素和切回标签页时浏览器恢复的焦点都不画框。不全站删除焦点框。

此记录取代[作品页按平台分开](2026-10-18-works-by-platform.md)与此前作品库列表里排序控件的样子（文字选项与手机菜单），排序本身的含义与接口不变。
