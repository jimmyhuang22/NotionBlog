# 2026-11-24：游戏页改成“游戏墙”（丙）

**状态**：用户从四种排版原型里选了丙，又看过第二版后确认做成正式版；Claude 实现。取代 [2026-11-23 的转盘](2026-11-23-game-cases.md)和“游戏库”小标题的位置，卡盒本身的样子不变。

## 背景

游戏页上线卡盒后，用户觉得页面“还是怪怪的”：3D 转盘和站上其他页面不是一个风格，占了约一屏，状态切换被挤到转盘下面。Claude 用线上 317 款游戏做了四种原型（甲 主角、乙 侧栏、丙 游戏墙、丁 主机首页），用户选了丙，并让 Claude 再优化一轮。

## 决定

- **页面顺序**：标题和在玩／通关／想玩并排在最上面，和影视、书籍一致；下面是“最近在玩”，再下面是年份与排序、游戏墙。游戏页用宽版（`wrap--wide`，最宽 1240），其他书架不变。
- **最近在玩**：一排平放的卡盒，可以横着滑；第一只略大（电脑 320 高、其余 270，手机 230／200），每只下面写名字和最近一次游玩的日期，第一只前面写“最近”。排不下时边缘渐隐；能用鼠标的设备在右上角有左右箭头，手机上直接滑。它不跟随下面的状态和年份筛选。
- **游戏墙**：卡盒从 200 高（手机 136）开始，每排按盒子原比例一起放大到两边对齐，最多放大 30%，最后一排不拉伸。
- **年份书挡**：每年开头一块浅色立牌，竖写年份，下面写这一年的总款数。款数来自服务端的年份统计（和年份切换上的数一样），不按已经加载的数量算。书挡和这一年的第一只盒子是一个整体，不会单独落在一排末尾。手机上书挡变成一整行“2026　5 款”。想玩（没有日期）和选了某一年时不放书挡；没有日期的一组写“无日期”。
- **名字**：能用鼠标的设备上，盒子下面平时不写名字；指到或用键盘移到某只盒子时，它抬起、其余变淡，下面浮出名字和评分、“也在 X”。触屏设备上名字一直写在盒子下面，一行。
- **加载时**：分区加载的样子同样换成宽版，留出“最近在玩”的高度，墙的位置画 12 个空盒子的轮廓。

## 代价

- 电脑上不指到盒子就看不到名字，要靠封面认游戏。
- 没有竖图的游戏用横图裁进盒子，个别裁得不好看，竖图补齐后消失。
