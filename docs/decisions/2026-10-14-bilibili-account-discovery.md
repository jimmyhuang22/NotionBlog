# 2026-10-14：B 站账号的新公开投稿自动接入

用户明确要求去掉新合集、独立视频逐项启用的限制，希望发布视频后自动同步。规则改为一次启用指定 B 站账号，自动发现该账号的当前及未来公开投稿；新合集和多 P 生成稳定合集卡片，合集成员折叠，独立视频生成作品卡片。新增账号或其他平台不继承这一授权。

发现目录与刷新详情分开：已登录 Chrome 按真实投稿页分页读取必要身份，完整目录交给原 HTTP 采集器核对作者、公开状态及合集／分 P 归属。只对未知目标采集详情；当前目录失败、登录失效、验证或分页不完整时保留上一结果，不推断删除，也不停用既有目标的刷新。目录检查沿用六小时周期，十五分钟空闲检查不读取平台。

本地配置与云端资格都改为账号级授权；受限采集角色只能经固定函数接入该账号的有效快照，不取得通用审批表或账号设置写入权。明确撤回的目标不能被再次发现后自动复批。小红书、Notion 来源、页面和部署保持各自范围。

这项规则取代 [合集成员跟随](2026-10-14-bilibili-follow-collections.md) 中新合集和独立投稿必须单独启用的要求。代码、云端规则和浏览器目录权限分别验收；完成前仍如实标记未安装。
