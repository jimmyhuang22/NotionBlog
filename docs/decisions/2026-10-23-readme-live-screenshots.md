# 2026-10-23：README 加入作者公开网站的截图

用户认为只看演示数据，别人不知道项目实际能做到什么，要求在 README 里展示自己公开网站的影视、书籍、作品等页面。用户看过四张截图预览后确认采用，并保留页头的网站名。

## 定了什么

- README 可以使用作者公开网站上已经公开的页面截图，作为“真实效果”的示例。本次收录作品、影视、书籍、游戏四页。
- 这些截图必须标明来自作者的网站，不能当成演示数据，也不能把演示截图说成真实记录。
- 截图里的个人记录不在 MIT 授权范围内；影视、书籍、游戏与视频封面归各自的版权方所有。README 与截图说明都写明了这一点。
- 能看出所在地、住处或其他私人生活细节的页面不收录。相册页因此没有截图。
- 首页大图、主题对比、学习笔记与正文预览仍用离线演示截图。
