# 2026-10-23：独立、默认关闭的搜索资格复用候选

用户在审阅语句内资格复用的离线方案后要求继续下一步，确认新增独立能力与默认关闭的 `filtered-scope` 源码候选、本机检查／构建和草稿 PR。此次不安装 SQL、启用配置、合并或部署；不继承其他任务的生产发布授权。

新模式使用独立迁移、版本五能力摘要和只读入口，默认仍为 `on-demand`；原 `filtered` 与 `precomputed` 保持。只在本条 SQL 的候选中包含学习笔记时复用已通过物理父链资格的记录 ID；其他候选仍调用原引用投影。未知链接继续查资格，媒体仍须存在，所有请求重新筛选。

原必要条件预筛、两万条／三十二 MiB SQL 上限、TS 匹配与完整排序／分页、动态撤回及末尾版本复核保持。不缓存跨请求正资格，不从公开接口接收成功集合；内部 helper 使用调用者权限且不向 reader、writer 或普通角色授权。

可选能力仅在新搜索读取时检查，普通课程、首页、目录不依赖其存在。旧迁移、权限与冻结采集协议不改，新 reader 字节继续被旧转换拒绝。后续安装须另外核对受检文件摘要、角色、结构保护、当前运行输入与回退；实际托管性能和有限真实读取另定范围。

接入、验证与回退见[说明](../FILTERED_SEARCH_SCOPE.md)。此前离线局部收益不能直接推断线上改善。
