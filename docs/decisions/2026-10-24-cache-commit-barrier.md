# 2026-10-24：自动缓存刷新使用默认关闭的提交屏障扩展

用户明确同意按[B10 方案](../BACKEND_CACHE_COMMIT_PLAN.md)实施源码与隔离测试，包括准备仅本机使用的临时 PostgreSQL 引擎，不增加项目依赖或注册系统服务。此次确认不包含真实数据库安装、凭据、项目请求、任务恢复或部署。

采用同事务私有意图与延迟约束触发器，把自动事件取得全局缓存锁的阶段后移。保留原全局 generation、v1 事件／reader／签名／ACK，数据与事件原子提交；显式 enqueue 及立即撤回保持同步。独立扩展默认关闭，不修改冻结旧迁移；激活必须由后续受审 owner 窗口执行，普通读写角色不获得配置或意图写权。

不采用 statement trigger 作为完整修复，也不以 sequence 当前值或 MAX 分配序号代替提交版本。新方案仍有提交阶段的串行屏障，强制 SET CONSTRAINTS 可使其提前，不作完全无锁或固定耗时承诺。具体代码、原生验收、目录校验、安装／回退边界以方案为准。
