# 2026-11-21：正式发布验收后清理退役产物
状态：上海旧应用的保留策略已由[上海应用重建与保留](2026-11-21-shanghai-application-retention.md)更新。

用户确认将退役清理作为每次正式发布验收通过后的收尾步骤，补充此前的发布验收范围约定。每站保留实际现役版、指定回退版及还原所需依赖。更早的构建、镜像和交付包只有在确认无引用、本机归档并成功试还原后才可移除。

交接按站和挂载点记录净释放量、剩余可用量、下一次内容交付的容量判断和依据。操作步骤和回执模板见[生产部署手册](../PRODUCTION_DEPLOYMENT.md#验收后的退役清理)。
