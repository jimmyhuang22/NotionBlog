# 2026-10-16：更新失败保留网站最后成功内容

用户明确确认，正常更新失败时可继续展示上一次成功内容，优先保持网站可读。网站v2不应仅因为批次时间到期就让页面与API返回503。

只允许读取仍为current、已完整published、当前公开策略epoch一致的批次；新同步在staging准备，完整验证成功后原子切换。失败不能切换到未完成记录，也不能任意选择更早历史批次。保留中央deny、祖先和owner资格、已知撤回/删除及当前来源范围检查。未成功联系源端时不能保证发现最新删除；普通媒体仍受当前Notion临时地址刷新和上游可用性约束，不将“不因批次到期503”说成全链路永不失败。

内容读取的新鲜度截止与写入资格分别处理：不延长旧valid_until、不放松staging lease或过期写入限制、不更改冻结v1。新批次仍需重新验证来源，媒体登记与正文须接续同一实际批次。

此决定取代网站v2此前“到期一律拒读”的可用性要求；历史执行回执不改。实现与正式启用分开记录，本文不代表线上已启用。
