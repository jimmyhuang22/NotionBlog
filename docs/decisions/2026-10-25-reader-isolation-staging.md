# 2026-10-25：网站隔离检查按阶段采用

用户明确批准 [R01 具体方案](../BACKEND_READER_ISOLATION_MODE_PLAN.md)的源码与离线测试及常规 develop 交付：服务器 `DATABASE_READER_ISOLATION` 缺省 off，延后网站入口的额外隔离拒绝；显式 enforce 保留现有严格检查，非法配置拒绝，延后模式记录固定服务器诊断。

本决定补充[原 B03 决定](2026-10-24-incremental-reader-isolation.md)：off 阶段可按独立发布规则采用其他网站修复，但仍须记录旧权限未隔离，不能宣称最小权限已完成。真实隔离和读取验收后，发布声明必须选择 enforce；附带本机阶段一致性检查，避免误开／遗忘，不把声明当作实际目标证明。

库函数默认严格，独立同步、writer／证据身份与 B20 中央 deny 能力不受此开关放宽。公共健康／私有 readiness 协议、SQL、授权、DTO、来源范围、依赖和任务状态保持。

本次不包含真实账号／迁移、凭据、云变量读取或修改、线上验收、任务恢复、main 合并或部署。原始交接记录的 B 方向不代替某次具体发布授权，真实安装及激活仍另行验收。
