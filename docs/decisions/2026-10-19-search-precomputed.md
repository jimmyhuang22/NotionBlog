# 2026-10-19：独立、默认关闭的搜索文字派生（Codex）

用户确认共享方案后，允许完成正式实现与本机迁移验证；没有授权云端安装、填充、启用或部署。F21 既有证据已将搜索主要等待指向重复正文提取，而非连接建立。采用独立私有派生表、固定算法与正文摘要绑定、新版本只读 API；旧路径缺省继续，显式新模式核对独立 capability，表项失配在同一 SQL 内走原提取语义。

资格、父链、中央撤回、链接与媒体有效性及最后 revision 不随文字缓存。派生数据只是可重建结果，不授予公开权限。旧协议、迁移、公共 DTO、冻结 producer、来源和存储对象保持。

生成采用所有者显式批次入口，默认无目标、无有效期；只处理已有数据库正文，绑定确切 run／fence／revision，保留租约检查和整批事务回滚。暂不使用写入触发器或修改现有采集运行包，避免在恢复期间引入隐式额外写入。每批条数、字节、文档／片段、深度和检查期限都有上限；原记录删除级联清理，原维护负责人仍负责原保留与归档范围。自然同步生成接线仍须原负责人审核，不在网站账户上增加写权限。

本地实测支持继续准备该方向，不能替代托管数据库和网页验收；发布默认关闭代码不会自动产生性能收益。后续云执行需要固定版本、身份、预算、请求账本与部署回退方案，详见[操作与限制](../SEARCH_PRECOMPUTED.md)。继续排除旧详情地域候选，社交连接修复由原负责人完成。
