# 2026-10-27：控制台冻结与受限同步

用户在了解第二阶段用途后确认继续，采用[第二阶段方案](../CONSOLE_BACKEND_PHASE_TWO.md)的工程与公开语义：

- 冻结当时已发布的目标及实际后代，保留内容和独立媒体版本；后来的来源子页面不自动加入。
- 来源修改、移动、删除或失去读取权限不自动改写冻结版本。中央下架、祖先下架、栏目关闭及来源公开授权撤销继续优先。
- 永久解冻把原成员交回正常同步；同步一次保持旧版有效，到新内容原子提交成功后更新冻结版本。失败保留旧版，结果不明先核对原操作。
- 冻结采用独立扩展，不改变来源摘要或默认模式。实际安装须已有持久发布、增量运行和独立媒体，不在旧 qualified 运行根打开按钮。
- 控制台复用已有 worker 锁、队列、独立 reader 及预算，提供有界整轮／单页触发。备份包含冻结与配套本机状态，恢复默认停用并重建当前授权基线。

本决定补充现有内容公开和持久发布规则，只适用于明确选择冻结的已公开内容，不扩大其他来源的公开范围。不引入来源编辑、任意 SQL 或独立并发 writer。
