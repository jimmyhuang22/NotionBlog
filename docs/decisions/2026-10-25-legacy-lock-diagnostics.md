# 2026-10-25：遗留锁只读诊断与完整基线取消

用户明确选择“同意源码与离线验证”，批准 [B06 完整方案](../BACKEND_LEGACY_LOCK_DIAGNOSTICS_PLAN.md)，包含正常 PR／push 自动 CI 和常规 develop 合入。

完整基线 CLI 使用持续监听，直到原异步清理完成后移除；不因外层取消重发而耗尽监听。共享 worker 锁和报告的损坏 JSON 返回既有固定错误，不暴露原文或删除文件，合法旧 PID 锁继续兼容。

新增独立、显式的只读诊断入口：只检查指定目录内两种固定锁，不扫描其他路径、不读环境或真实服务、不创建目录／回执、不写 health 或恢复调度。使用私有权限、规范目录、非符号链接、有界读取及前后身份检查；格式、PID 存在和一次文件快照均不构成业务 owner 或安全解锁证明。任何存在或未知状态均保留并要求人工审阅。

manual-run.lock 不新增删除工具；PID 复用、未知提交、子进程及原授权账本由原运行拥有方另审。源码可诊断不等于真实遗留锁已处理，SIGKILL／断电也仍可能留下锁。整组稳定后一次完整 check／build，必要定向验证不代替真实采用。

授权不包含实际运行目录检查／处置、凭据或云配置、项目请求、安装运行包、业务暂停／恢复、main 合并或部署，不复用其他工作线已关闭的授权窗口。
