# 2026-11-13：新加坡 Oracle 作为默认生产目标

用户确认今后以新加坡 Oracle 为默认生产目标，AWS 不再更新，先保留而不删除。main 仍为正式源码分支，主机安装与域名切换按每次用户授权执行；不因 Git 合并自动部署到任何保留主机。

此选择取代 [2026-11-02 AWS 公开自托管](2026-11-02-public-self-hosted-runtime.md) 的生产目标和现役存储拓扑。沿用构建隔离、受保护配置、只读身份及私人业务运行根独立管理。新加坡已采用本地展示媒体和独立同步运行根，不能把 AWS 配置或部署产物直接覆盖过去。

统一入口为 [生产部署与交接](../PRODUCTION_DEPLOYMENT.md)。AWS 恢复流量、停机或删除资源属于后续独立决定；本决定不授权这些动作。既有 Vercel Git 投递配置未改变，不能把其状态作为新加坡主站上线证据。
