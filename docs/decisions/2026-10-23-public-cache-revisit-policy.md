# 2026-10-23：保留公开缓存模式的回访校验策略

用户在 S13-6 的明确选项中选择保留当前回访校验，Codex 记录。这是需求取舍的确认，当前配置已经采用该策略，本项没有修改应用、缓存开关或生产环境。

## 决定与适用范围

- 启用公开缓存的环境保留现有回访校验与版本监听，不恢复“五分钟内回到看过的页面不发请求、立即显示”的要求。服务器／CDN 可以依现有公开缓存规则复用结果，不表示每次回访都重读完整来源或数据库资格。
- 当前实现为启用该模式时 `staleTimes.dynamic` 与 `static` 均为 0，页面可见时按现有版本监听更新。此处记录现状，没有重新设置这些值或改变监听频率。
- 本决定不改变浏览器前进／后退缓存、共享布局复用或离线副本；`staleTimes` 不控制所有这些行为。不能把“保留回访校验”解释为每次历史恢复都新增强制联网，或已下载内容能被远程擦除。
- 未启用公开缓存的环境保留旧模式。本决定仅在公开缓存模式下取代[五分钟页面复用决定](2026-10-17-remember-pages-five-minutes.md)中的免请求即时回访条件；[公开缓存与下架决定](2026-10-21-public-content-cache.md)及权限、中央 deny、祖先撤回、媒体与版本失效规则保持。

## 验收含义

S13-6 的产品选择已明确：不再因一次回访发出请求或有短暂等待，单独认定违反“五分钟即时复用”。历史约半秒的样本只是观测，不是新的速度承诺或允许持续退化的阈值。F21 的详情进入速度、持续性证据及其他偶发失败继续独立处理，不能据本决定关闭性能问题。

本项只同步需求与决策，不授权发布、部署、开关变化或运行安装。既有关于缓存前进／后退的限制参照当前安装版本自带的 Next.js `staleTimes` 指南；浏览器新行为如需改变，另按具体方案处理。
