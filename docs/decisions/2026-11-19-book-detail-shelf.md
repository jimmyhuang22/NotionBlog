# 2026-11-19：书籍详情改为“书架与阅读历程”

状态：已采纳。接着 [影视详情改为“海报幕布”](2026-11-19-film-detail-backdrop.md)，书籍看过三个方向（甲 · 书封幕布，与影视同构；乙 · 书架与阅读历程，参考 Goodreads、StoryGraph；丙 · 划线笔记，参考微信读书），用户选乙。原型先读了线上前 50 本书：没有一本打过“我的评分”，每本都有豆瓣评分；摘录是书籍页的主体，读后感短得多。

## 决定

- 不用幕布。白底书封虚化后偏灰，这是甲没选的主要原因。左栏是带书脊阴影的封面和资料：状态、页数、豆瓣评分、我的评分、豆瓣条目。电脑上左栏随页面停留。
- 我的评分只占一行“未评分”，不做成显眼的评分区；以后有了评分，墨点照常画出。
- 阅读历程画成一条线：读完写起止日期和天数（两头都算）；在读的终点是空心圆，线画到读到的地方；其余情况写一句话，不补日期。
- 摘录一条一张卡片，全部显示，和影视观后感“全文显示”一致。原型里“每组先放 3 条”的收起这次没采用；如果长页面成了问题，再加。
- 模板拆法：“摘录”单独显示，部分标题后写条数，空条目丢掉；“感受 / 感想 / 书评”统一叫“读后感”；其他标题保留原名，放在摘录后面；目录和空标题不显示。
- 页底“上一本 / 下一本”带小封面，规则同影视。

## 不变

- 游戏详情还是原来的样子，等用户选方向。
