# 2026-11-19：首页在玩的游戏改成和作品行一样

状态：已采纳。首页作品行改成“小图带数字”（[决策](2026-11-19-home-work-frames.md)）后，用户觉得在玩的游戏那一行也该跟着改。看过三种做法后选丙，又要求标签写成“在 Switch 上玩”，并选了灰色字的丙一（没选标签里保留平台颜色的丙二）。2026-11-22 补充：标签里的平台名前加单色图标，见 [F60 决策](2026-11-22-game-tag-platform-icons.md)。

## 决定

- 游戏也用 144×81 的横图，图左下是时钟加已玩时长，标题单独一行，和作品行的结构一样。
- 日期后面的标签从“游戏”改成一句话：“在 Switch 上玩”“在 PC 上玩”“在 PlayStation 上玩”；记了两个平台写“在 PC、PlayStation 上玩”；没有平台记录写“在玩”。图上不再放平台标签，免得重复。
- 通关、白金的游戏在首页本来就写“在玩”（F47 的落点规则），所以同样写“在某平台上玩”。
- 取代 2026-11-11 “游戏去掉卡片底，方图 48”和 2026-11-13 “游戏保留平台和时长在一行”的样子；动态页和作品库不变。
