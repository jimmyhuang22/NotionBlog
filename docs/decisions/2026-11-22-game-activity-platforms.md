# 2026-11-22：时间线游戏活动显示观察到的平台

用户确认 F59 源码与共享契约。当前在玩或重玩事件若使用 `lastPlayedDate`，标签显示该站点自然日核实出的来源平台。同日有多个来源就一起显示。人工体验日期较晚或最近平台未知时使用作品的 `platforms`。两者同日时沿用既有最近平台日优先规则。通关、白金、作品库与详情延用作品平台列表。

`Game.lastPlayedPlatforms` 可选，已配置但无可核实值时为 `null`。平台日期继续只公开到日。公开数据只带平台标签，账户记录、来源 ID 和具体时刻留在私有数据源。见[平台日期规则](2026-10-14-game-played-date-policy.md)和[游戏同步说明](../GAME_ACCOUNT_SYNC.md)。
