# 2026-11-11：作品首屏共同读取与最终权限检查

状态：采用可选接入，默认关闭；集成和发布状态见进度记录。

电影、书籍和游戏 SSR 首屏可通过独立的实时入口共同读取列表与年份。栏目包装显式转发此能力；关闭的栏目返回空结果且不查数据库。既有列表、年份 API 和其他 provider 保留原接口。数据库 v2/scoped 通过 `DATABASE_LIBRARY_PAGE=compact` 显式选择新路径；不兼容配置拒绝启动，读取失败不自动切回旧路径。

共同读取先取有界精简字段，复用现有 JS 排序、年份和游标逻辑；随后以完整候选集合指纹、run/revision、配置和资格检查读取当前页完整元数据。需要本地或云端封面准备时，准备完成后再次执行完整检查，之后仅同步投影新 DTO、附加白名单投递尺寸。空页同样检查。选择器上限为 20,000 条和 16 MiB；超限明确失败，不返回截断结果。

仅本地可选年份计算失败可降级为隐藏年份切换，同时保留请求年份。成功计算但年份不存在时去掉年份筛选。SQL、资格、游标、取消、封面准备失败均不得作为年份降级吞掉。共同读取结果不进入通用完成态 DTO 缓存；原路径的缓存仍按原规则运行。

最终检查的有效边界是最后一条 SQL 的语句快照，不承诺阻止该语句开始后才提交的撤回。后续媒体请求继续执行自身的实时权限检查。原实现和 4 MiB 分块保留离线对照；Supabase 实例复用仍不在本项范围内。

此选择不授权安装云端迁移、修改运行配置或发布。上线条件及成本限制见本项进度与评审报告。
