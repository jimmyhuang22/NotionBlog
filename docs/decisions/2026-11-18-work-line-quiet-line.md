# 2026-11-18：首页轻记录的信息行去重

状态：已采纳。用户看了 #364 上线后的首页，觉得作品那一行“信息重复”（小红书的图标本身就是“小红书”三个字，后面又写“小红书”；B 站图标后又写“B 站”）。看过对比（现状、只留图标、图标放到小图角上、只留文字、再精简）后选“只留图标，再省两个词”（甲＋）；又觉得标题旁“新增 1 个视频”的小胶囊突兀，问能否改成“+1”。

## 决定

- 信息行以平台图标开头，后面不再写平台名；平台名只给读屏读出。
- 单篇作品不写“视频／图文”；合集把类型和个数写成一个词组，如“合集 179 个视频”。一行若除了图标什么都没有，保留类型。
- 合集新增的视频从标题旁的胶囊改成个数后面的“+N”（强调色、略粗；个数未知时写“新”），完整说法（如“新增 1 个视频”“发现新增…，发布时间未知”）只给读屏，和横滑卡片封面角上的“+N”一致（F37）。
- 同一件作品在第二个平台的补充行按同样写法。跨天时的日期仍在图标后第一个位置。

## 范围

首页轻记录（`HomeWorkLine`），四个主题。横滑卡片、作品页、没有封面时的作品列表不变。补充 [2026-11-11](2026-11-11-reading-design-refinement.md) 与 2026-11-13 关于“新增”小标放在标题旁的写法。
