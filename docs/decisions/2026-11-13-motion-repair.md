# 2026-11-13：切换与轻记录的修正

用户看过第五轮设计审查的实现后指出四处：栏目之间切换有“长方形的视觉暂留”，年份切换不流畅，首页的“在玩”不如之前，首页的 B 站作品行还要优化；并要求 Claude 直接修，不再出交接包。

## 定了什么

- **栏目的灰色轮廓晚一点出来**：点下栏目后仍然立刻进入（标题、平台或状态切换这些不依赖数据的工具马上就位），但灰色轮廓等约 0.32 秒才淡入。多数页面在这之前就到了，于是看到的是“标题 → 内容”，中间没有灰块闪一下；慢的时候轮廓照常出现。点击时的过渡画面与栏目自己的加载画面共用一个计时，接手时轮廓不重来。
- **内容在标题下显影**：过渡画面让位后，标题以下的部分 0.22 秒淡入；标题和工具不动、不淡。减少动态效果时没有延迟也没有淡入。
- **年份与状态的选中块按下就滑**：选中块是一块单独的底，按下时滑到被按的那一项，两个名字同时换成选中与未选的样子，列表随后到。此前是列表到了之后才用视图过渡把“选中的那个链接”整个搬过去，名字跟着底一起飞，被按的名字会消失几帧。动态页换年份后，前六条的内容从变暗处升起（竖线与圆点不动），与作品库、搜索一致。
- **首页游戏每款一行**：撤回“相邻的同月游戏并成一句”。每款游戏恢复自己的一行：方图、“在玩 名字”、平台、时长，各自的日期。用户原话：“时间线里的在玩游戏我感觉没之前的好”。
- **首页单件作品行**：缩略图与游戏方图同高（48 像素）；“新增 N 个视频”从小字行末尾提到标题旁，做成一枚强调色小标，位置相当于游戏行的平台与时长；小字行只留平台、类型、数量与播放。
