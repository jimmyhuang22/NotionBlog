# 2026-11-24：卡盒封面支持实体窗口和方图（Codex）

用户确认可接入一个游戏封面展示字段。优先按游戏平台和发行版查正封，Steam 按 App ID，主机按制造商、发行商或地区零售商的同版商品。保留原始附件。网站在显示时取盒内矩形，同一张卡盒保留一次平台标志。对于已选的近方形数字商品图，按完整图面显示。

在游戏数据源中可选择映射一个富文本字段「封面展示」。支持 `{"mode":"contain"}`（近方形完整图面）及 `{"mode":"retail","window":[left,top,width,height]}`（原图像素）。带印刷 Switch 左上角标的第一代 Switch 正封可以添加 `"printedSwitchMark":true`。PlayStation 型号由现有的 `Box Art Platform` 推导，字段本身不能覆盖型号或平台。只有实际采用的封面带 `Game.boxArtLayout`，旧快照可省略。原详情背景和其他媒体入口沿用既有逻辑。

网站与采集程序都支持该字段后启用真实来源映射，再通过目标记录同步。空字段不改变目录发现指纹。
