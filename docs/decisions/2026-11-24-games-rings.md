# 2026-11-24：游戏页改成“年轮”

**状态**：已采纳。用户从三套整页方案（甲 侧栏、乙 年轮、丙 陈列架）里选了乙，又看了四版原型逐步调整；Claude 实现。取代 [年份栏决策](2026-11-24-games-year-rail.md) 的整页排法；卡盒、[悬停](2026-11-24-games-wall-hover.md) 和[最近在玩的日期、读取失败](2026-11-24-recent-games-followups.md)不变。原型在 `.local/previews/games-concepts-20261124/`。

## 背景

用户想去掉右上角的排序按钮、加上平台筛选，并要求按获奖网站的品质标准，从排版、留白、视觉层级、色彩、动效、微交互、响应式和原创性自检，做一个有特色、好用的游戏页。

## 决定

- **大幕**：最近在玩做成页首的大幕，一款大盒子加名字和几个小胶囊，底下 8 只小盒子可以换（← → 也行）。换的时候大盒子从小盒子的位置飞上来，背景用这款封面虚化并取它的颜色。不写操作说明。
- **状态切换**：挪到大幕下面，和下面的游戏对齐；写成手写体大字的标签（丙 主次分明），选中那个下面一道短线，和书架的年份行同一套。默认“通关”。滚出屏幕后，同样的切换在屏幕底部的浮动坞里。
- **排序按钮**：去掉。
- **平台筛选**：全部、Switch、PlayStation、Steam、PC，带款数，样式是浮起的分段（丙），放在状态标签右边。需要后端按平台类别筛选、年份统计跟着平台走，见[后端交接包](../BACKEND_HANDOFF.md)第二十二节；交付前不显示。
- **年轮**：左边描边的大年份，往下读时停在左上，读到哪一年那一年就从下往上填实，竖线跟着填到读到的位置。每年写款数，全部加载后再加总时长和各平台几款。只有一两款的年份把盒子和信息摊开。
- **动效**只跟着操作和阅读位置走，不做滚动浮现；系统开了“减少动态效果”时全部关掉。
