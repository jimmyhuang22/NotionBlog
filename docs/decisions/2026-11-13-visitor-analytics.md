# 2026-11-13：访客分析采用独立 Umami 与区域标签

用户同意采用集中部署 Umami 的第一阶段方案：上海、新加坡采集入口汇入新加坡独立统计服务，保留同一网站下的节点区分；完整分析使用私人登录后台，Mac mini Dashboard 首先只增加应用入口，摘要卡片留到后续按需接入。
