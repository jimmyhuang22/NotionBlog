# 2026-11-23：卡盒上的通关／白金写在顶部平台条右端

用户看过三种放法的本地原型后选甲。部分取代 [2026-11-23-game-cases](2026-11-23-game-cases.md) 里“右上角写通关／白金”这一条，其余不变。

## 为什么改

试装 Steam 竖图后发现，很多竖版封面把游戏标题印在顶端。右上角的状态会压住《守望先锋2》的“2”和《识质存在》PRAGMATA 的末尾字母；放到右下角又会压住印在底部的标志，例如《女神异闻录5皇家版》的 ROYAL。只要状态还压在封面上，换一款游戏就可能再压到。

## 决定

- **通关／白金写在顶部平台条右端**：左边是平台图标和名字，右边是状态，例如“Steam ··· 白金”。封面上方不再压任何东西。
- **时长留在封面左下角**，样子不变。
- **状态的样子跟着平台条**：字号按卡盒宽度缩放，并设最小字号；白金仍是银色，通关在深色平台条上用浅色半透明底，在 PlayStation 的白色平台条上用深色底。
- **小卡盒照样放得下**：平台条设最低高度，封面从平台条下面开始。手机上的窄盒子（例如 Switch 2 加白金）收紧间距，平台名和状态都完整显示，不截断成省略号。
- **转盘下方的说明行不变**，仍写名字、平台、已玩时长、最近一次游玩和通关／白金。
- 另外两种没选：乙是盒子上只留封面、状态和时长都挪到盒子下面；丙是状态挪到右下角，和时长同一行。
