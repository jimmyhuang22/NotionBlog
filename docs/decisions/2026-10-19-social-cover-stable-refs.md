# 2026-10-19：社交封面页面使用稳定引用

已确认的问题：来源地址换签会更新严格来源摘要和不可变媒体 ID。即使新旧图片字节一致，打开页面保留的旧 ID 也会在新绑定登记后返回 404；原换签连续展示扩展仅覆盖登记前的空窗，没有覆盖页面延迟加载旧引用。

页面封面保留现有 DTO 字段和登记资产 ID，`src` 改用 `s2.<owner kind>.<owner key>` 的当前封面引用。服务端按当前显示模式，通过原受 RLS 限制的绑定表解析到唯一已验证媒体；不读取平台图片、不重编码、不建立历史 URL 映射或永久公开链接。原 `s1` 路径继续按不可变资产身份读取，旧代仍会失效。

稳定引用返回 `private, no-store`，不沿用不可变字节地址的一天浏览器缓存例外；已有 `s1` 缓存策略保持。每次读取仍检查公开资格，私有对象读取后再次检查；撤回、禁用、缺图和合集严格来源规则不变。读中换成不同字节时失败关闭，不返回过时字节或跳过第二次校验。

这是网站后端修复，不要求云迁移、权限、采集或固定运行包变更。代码准备不等于已部署；网站正式发布需要按原项目规则执行。上线前已打开页面仍持有旧代引用，首次取得新版页面后才使用稳定路径。
