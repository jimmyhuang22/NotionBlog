# 2026-11-23：游戏详情内容排布六处

状态：已采纳。补充同日的 [游戏详情五处细调](2026-11-23-game-detail-polish.md)，以及 [2026-11-20 游戏奖杯](2026-11-20-game-trophies.md) 里“三张最难拿到的卡片”和“标题旁写个数”两条。用户拿线上《识质存在》（只有 Steam 一套、三个日期都在 2026 年、没有正文）问游戏页的内容排布。我把六处问题的原型注入正式页面截图（真实数据，对照《女神异闻录5皇家版》），用户选：1 统一叫“奖杯”，2–6 都是甲。

## 决定

1. **叫法**：Steam 成就也统一叫“奖杯”，不分平台改名（原型里的甲“按平台叫”、乙“一律叫成就”都没选）。
2. **只有一套时写出平台**：标题“奖杯”旁写平台图标加名字；左栏个数上方加一行平台。多套时照旧是切换按钮。
3. **同样的话只说一遍**：
   - 只有一套逐个奖杯的数据，且有日期的奖杯全都落在用户的体验日期（或游玩日期）里时，日期线这个日期下面写“共 N 天 · 拿到 M 个奖杯”，奖杯一节不再写那句“X 到 Y 拿到 M 个”。不全落在里面，或者有几套时，照旧在奖杯一节写那句话。
   - 标题旁不再写“27 / 35”：左栏有个数，几套时切换按钮上也有。
   - “最近拿到”跳过已经做成卡片的奖杯，点“全部”时仍然都在。
4. **最难拿到的**：卡片上面加小标题“最难拿到的”；只有获得率不超过 20%（“稀有”及以上）的才做卡片，最多三张。只有一张时横着排成一条，有图标、名字、说明和档位；一张都没有就不出现这一块，比如《女神异闻录5皇家版》的 PS4 那套，最难的也有 60%。
5. **日期都在同一年时**：两个及以上的日期都在同一年，年份在线的上方写一次，每个日期改用月日大字；跨了年仍是每个日期一个年份大字（2026-11-22 的乙）。
6. **左栏跟着滚动**：电脑上（900 宽以上，且窗口高 700 以上）左栏滚到页头下面后停住；手机不变。

## 没有采用

- 2 乙（右边一枚像按钮、但不能点的平台签）；3 乙（只让列表不重复卡片）；4 乙（只加标题，照旧三张）；5 乙（所有游戏都用月日大字，等于收回年份大字）。
