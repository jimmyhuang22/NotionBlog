# 2026-10-17：课程顶部封面增加可选 1600 档

用户认可前后端分工与实施顺序，并批准对已盘点的课程封面复用本机原件生成、上传 1600 档；数据库登记等待以后恢复同步后的新成功批次。此次不恢复同步，不批准正式部署或放宽旧批次登记期限。

采用 `/media/v2/<assetId>?thumbnail=1600`，保留比例、不放大；仅当前课程的封面资产具备新档资格，400／800 和正文规则保持。后端负责参数工具、资格检查、编码缓存、数据库增量迁移和登记接续；前端负责课程页响应式选图。先支持与登记，后启用页面参数。

原小图 SQL 保持冻结，独立扩展保留 last-success 读取和到期拒写、中央下架、父 SHA／fingerprint、只读与写入角色边界。源图不足 1600、变体无体积收益或缺少新映射时沿用合格原图。800w／1600w 的选择按真实显示宽度与像素密度决定；原图回退须清除 srcSet。

本决策只补充课程顶部封面，未批准正文数千张同步扩档、其他媒体读取模式切换或原件上传。
