# 2026-11-03：静态资源缓存与图片五分钟回访

用户要求按前后端联合审查先修静态资源缓存和图片回访慢，正式发布前再确认。本项采用以下范围：

- `tagged-v1` 下，已经通过原有资格检查并获准缓存字节的 v2／s1／s3 版本图片，浏览器缓存改为 `private, max-age=300, must-revalidate`。200 和 304 一致；过期后沿用 ETag 和提前 304，不读整张图片来确认。真实换图使用新版本地址；同一 v2 地址重新生成小图时，已有副本最多保留五分钟。
- 实时 Notion 核验的响应（含回退原图）、可变 s2 地址、API、错误、跳转及未启用此模式的旧规则保持。图片不向 Cloudflare 开共享缓存，不改数据资格、公开范围、连接池、契约或定时任务。
- 已经下载的图片不能远程擦除；五分钟新鲜期内浏览器可以不联网，因此撤回后旧访客仍可能看到这份副本直至过期。到达源站的新请求仍执行原有撤回检查。强制刷新、缓存淘汰等仍可能重新请求。
- Cloudflare 只缓存 `/_next/static/` 中由 Next 返回可缓存头的构建资源，遵守源站缓存头；不以全站 Cache Everything 或强制 TTL 缓存 HTML、RSC、API 或媒体。回源入口维持 HTTPS 严格验证和 Cloudflare 网段限制。

部分取代 [2026-10-21 公开缓存决定](2026-10-21-public-content-cache.md)中的“版本图片每次使用前重验证”；页面与服务端固定日窗口、标签清理及 [2026-10-28 页面回访](2026-10-28-public-cache-revisit-five-minutes.md)保持。此次实现与云端启用的状态见[进度记录](../progress/2026-11-03-static-media-cache.md)。
