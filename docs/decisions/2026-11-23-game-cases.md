# 2026-11-23：游戏库改成竖版卡盒（甲，真实比例）

状态：已选定，等数据。用户看过三轮原型后选甲。前端在竖版封面和分平台时长到位前不改正式页面；原型在前端忽略目录 `.local/previews/games-20261122/index-case2.html`。

## 决定

- **游戏库（`/library/games`）**：每款是一只竖放的游戏盒。
  - 盒子仿真实结构：平台色的塑料壳，四周一圈细边，左边一道铰链，外面一层透明封套的反光；
  - 顶上一条色带印在封面上，写平台图标和名字：Switch 红带白字，PlayStation（照 PS5）白带黑字，Steam / PC 深蓝带；
  - 带子下面是竖版封面，左下角写时长，右上角写通关／白金；
  - 只用我们自己的平台图标加名字，不用各家的官方标志。
- **真实比例**：每个平台用自己盒子的比例。Switch 约 0.62，PlayStation 约 0.79，Steam / PC 用 DVD 盒约 0.71。同一排的盒子高度相同、宽度不同，像真的一排盒子（另一个统一比例 0.68 的乙没选）。
- **只写一个平台**：一个平台的照常写。多个平台时写玩得最久的那一个，其余的放在说明里（“也在 PlayStation”）。
- **最近在玩**：游戏库上面一排转盘，取最近玩过的 8 款，用同一种卡盒，放在页面底色上（不另开深色背景，免得上下割裂）。中间一盒最大，两边往后斜，下面有倒影；下方写名字、平台、已玩时长、最近一次游玩和通关／白金。可以点箭头、点旁边的盒子、用方向键或滑动切换，系统开了“减少动态效果”时不播动画。
- **详情页不变**：顶上仍是横版大图（2026-11-19 的“全幅主视觉”）。
- **没有竖版封面时**：在竖框中间完整放横图，背后是它自己的虚化，下面写游戏名；不把横图裁成竖的（会裁掉标题和人物）。

## 需要的数据

- 竖版封面：现在 317 款都只有横图。原型用 Steam 的 600×900 竖图试了 50 款中的 26 款。
- 分平台的游玩时长：现在只有总时长，挑不出“玩得最久的平台”。没有这项时先用最近一次游玩的平台（`lastPlayedPlatforms`），再没有就用平台列表的第一个。
