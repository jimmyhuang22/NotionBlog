# 2026-10-23：设计自检第四轮的八项选择

Fable 第四轮设计自检里唯一的高优先级 M-11（点头像打开“关于”时误触发换页）是缺陷，直接修了（合并请求 #41）。其余第 2～5 组，看过正式站上拍的前后对照与按真实时长复原的动效后，用户“全部按推荐的来”，八项如下。

- 手机上的正文标题（T-09，甲）：540 以下正文里的标题各缩一档（一级 24、二级 21、三级 19），页标题不变，让页标题始终最大。乙“页标题不缩”、丙“两边各动一点”未选。
- 窄屏的“本页目录”（X-11，甲）：折叠时写成“本页目录 · N 条”，右端一个小箭头，展开时转向上。乙“不折叠，先列 6 条”未选，手机上会把正文往下推约 260px。
- 1024 宽的“课程目录”按钮（W-10，乙）：保留完整面包屑，与按钮居中对齐，标题与这一行之间留出约 30px。甲“用手机那套，只留‘上一级’”未选。Fable 推荐甲，用户采纳了我推荐的乙：这个宽度放得下完整路径。
- 换排序（M-12，甲）：旧列表淡到 45% 后一直等到新列表；新列表同一帧换上，新行从 45% 依次亮到 100%，不从 0 开始，任何一刻都有一整张列表。这和换页“旧页变暗、新页从 55% 亮起”是同一条规矩。第三轮 M-10 定过作品页排序与年份、状态筛选走同一条规矩，所以影视／书籍／游戏的年份与状态筛选、动态的年份、搜索的栏目也一起改；学习总览的筛选是旧行淡出叠在新行上，保持原样。乙“只把间隔收紧”未选，空白一拍仍在。
- 等封面（M-13，甲）：影视、书籍、游戏列表里封面还没到时，格子是其他加载态那种淡色呼吸底，不画墨线；片名等过 1 秒才以灰字浮出。竖排片名加左侧墨线的书脊只留给真正没有封面的作品。乙“虚线书脊、整格 60%”未选。
- 详情页正文（H-09，甲）：墨水与苹果下，影视、书籍、游戏详情页的“我的记录”不再套卡片，直接写在纸上；Notion 里的目录块变成上下两道细线之间的一行小字链接（“本文 …”）。岛屿与千禧保留卡片和原来的目录块。乙“保留卡片，只去目录底色”未选。
- 在 Notion 里标成红、橙、黄的标题（H-10，甲）：墨水与苹果下，字回到正文墨色，标题下加一笔该颜色的淡墨，和名字下面那一笔同款，笔划长度随标题文字、最长 12 个字宽。岛屿与千禧仍用颜色。乙“统一映射成强调色”未选，会和链接颜色混。
- 代码配色（C-06，甲）：不再用 GitHub 的配色。关键字与字符串用强调色，注释用次要灰，其余（数字、运算符、标点）都是墨色。配色只写“角色”，由各主题自己的墨色、强调色、灰色取值，所以四套主题、浅深色都各得一套同样安静的配色；乙“换一个低饱和的现成主题”未选。

只记方向、本轮不做：T-11 岛屿的中文圆体（要新增字体子集，需用户另行同意）、M-14 浅色下换页变暗的 55%（用户自己选的值，用户不重开就不动），以及 T-10、X-12、R-08、R-09、C-07 五条低优先级，之后一起出稿。
