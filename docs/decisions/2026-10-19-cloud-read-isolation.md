# 2026-10-19：开发默认离线，社交事务池独立启用

用户批准开始连接修复与开发隔离。普通本地开发明确采用演示 provider 和本地素材，在 Next 加载 dotenv 后清理真实输入，并限制 Node 服务端外部网络；真实云端联调保留独立私有 reader 配置、显式许可和有限会话期限。生产 provider 失败不能回退演示；不改变运行包、采集频率或公开范围。

社交 shared-session pool 连接数达到上限会使封面与社交列表失败。增加显式事务池候选，只改变既有同主机端口并收紧实例池，不增加角色权限／限额、不缓存公开资格；真正启用与发布要经过实际受限 reader 验证和对应上线流程。事务池与出站流量分开治理，不能把换池或换账号表述为额度已解决。

本轮不执行账号迁移、不安装常驻本地数据库、不重复复制全站／全图。先完成开发隔离和受限连接候选，再按正常用量准备一次迁移。
