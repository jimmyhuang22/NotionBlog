# 2026-11-03：先进入栏目，再渐进加载内容

用户明确要求首次进入和切换栏目时，像之前一样点下先进入，内容与图片随后慢慢加载，不要停在旧栏目等待。Codex按本次明确要求处理这一加载交互。

- 已知栏目根路径先显示目标标题和现有加载占位，页头与导航保持可操作；Next 的目标路径及加载边界一旦提交，就交给路由继续流式加载，不等完整列表或图片。
- 看过且可立即显示的页面避免短暂闪出占位；连续点击以最后目标为准，可以点回当前栏目取消；前进、后退、键盘操作和真实错误页仍须正常工作。
- 该决定只取代 [F43](2026-10-21-page-switch-cross-fade.md)／[F45](2026-10-22-page-switch-dim-then-swap.md) 中栏目根路径保留变暗旧页直到内容齐备的部分。筛选排序、详情及同课程笔记的阅读栏过渡保持既有规则；首页介绍仍只用于首页。
- 加载标题仅为公开的栏目标签，不代表目标内容获准公开。内容资格、权限、撤回、真实 provider 错误、图片缓存与原图访问规则继续由现有服务端流程处理。

该选择改善操作反馈，不承诺服务器读取或网络下载立即完成，不用额外下载图片或绕过检查换取速度。
