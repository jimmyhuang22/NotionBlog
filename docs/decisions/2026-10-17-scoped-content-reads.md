# 2026-10-17：按实际读取范围计算内容与引用资格

用户批准后端性能审查后的处理与优化。保留现有 provider、DTO、采集和发布协议；优先减少访客请求反复处理整站正文与引用的工作。

- 新增独立 `nb_read_api` 受限读取扩展，不覆盖冻结 v1/v2、持久发布、租约或下架函数。qualified 与 published 分别调用原模式的当前批次门控；显式下架、祖先资格、政策与资格版本检查继续执行。
- 只为所选记录实际引用的链接、图片计算当前资格；媒体先按 owner 去重。同一查询内共享计算，查询完成后不保留内容或资格缓存。
- 动态列表在聚合前按本页 slug 选取正文，固定 run/revision；既有完整快照 16 MiB 边界保留，单次正文批量读取同样有界。列表排序的时区每次操作只解析一次，重叠的列表与年份读取仅在同一取消作用域内合并在途 metadata。
- 搜索先采用不建持久索引的文字片段：普通文字为字符串，带内部目标或图片依赖的片段附资格标记，避免重建文本 AST。显式栈按原深度优先顺序遍历，弹出时清理栈槽，保留 32 层边界；减少递归函数与逐块 SQL 调用。应用逐片段脱敏、清理引用后沿用原归一化、排序与分页，保留搜索文字 16 MiB／两万条上限及结束版本核对。暂不改变子串匹配规则，也不安装外部搜索服务。
- 首页与时间线先读 metadata 索引并选择页面，只为选中的动态批量读取正文；完整动态预览仍由同一 `statusPreview` 生成。混排顺序、计数及来源失败行为保持。两个可选的服务端 repository 能力不增加 HTTP 端点，不要求其他 provider 实现。
- 搜索／时间线和首页 GET 传递取消与整轮期限，在 SQL 前后检查；不遗弃在途查询，保留 pg 超时和连接归还。内容池接入与社交池相同的托管生命周期辅助函数，不扩大池容量。

服务端开关 `DATABASE_READ_PROJECTION` 默认 `legacy`。启用 `scoped` 前需安装并核对独立扩展及摘要；缺失或不匹配明确失败，不自动换 provider 或绕过资格。迁移安装、云配置切换与正式发布单独验收，代码合入不自动启动这些动作或恢复暂停的同步。

用户随后批准安装并准备启用。真实验收发现初版紧凑 AST 和按块调用 SQL 仍会超时；比较通用引用扫描、专用引用扫描、文字片段与显式栈后，选择后两项。两份补充迁移保留已安装迁移的原字节，三项摘要共同握手；没有持久搜索索引或资格缓存。
