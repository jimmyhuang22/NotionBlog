# 2026-10-23：独立单次触发器范围元数据核查

用户明确批准第三版固定 SELECT，仅将触发器类别上限从 32 提高至 128；此前两次结构读取的许可均已消费关闭，不能用于改写或重试。固定文件、散列及授权回执保存在私人交接，详细范围见[核查方案](../SEARCH_INSTALLATION_GUARDS.md)。

原 Supabase 连接器仅调用一次、代理零重试、结果 JSON 最多 128 KiB。四个 schema、七张表、十三个固定函数名最多 32 个重载、三个指定角色的直接相邻成员边、版本 1–5 最多五条登记及其他类别上限保持。超限返回不完整诊断，不接受截断对象，不追加查询。连接器不能强制物理连接数、TCP 接收字节、客户端截止、服务器只读或语句限时，内部服务重试未知；这些限制已随本次具体问题披露并获接受。

授权只包括固定元数据与登记读取，不包括业务行、应用函数调用、实际运行配置读取或写入、安装、advisors、启用、任务恢复、共享合并或部署。完整元数据仍须人工审阅，候选同名对象或版本五出现时立即停止辨认归属，历史快照不保证未来空缺。
