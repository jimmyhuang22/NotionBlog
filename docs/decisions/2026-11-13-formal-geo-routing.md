# 2026-11-13：正式博客按地域接入双站

用户确认正式根域和 www 的国内线路接入上海，默认海外线路保留新加坡 Oracle。使用支持地域线路的 DNS 权威服务；海外入口通过已有 Cloudflare SaaS 和隧道继续访问新加坡。统计后台固定在新加坡，沿用私人账号访问及两个服务节点标签；旧笔记入口保留原固定 301 跳转。

本决定补充[新加坡默认生产目标](2026-11-13-oracle-production-target.md)：正式流量由双站承担，两站继续使用同一 main 源码、各自架构产物及独立配置。网站发布不覆盖私人采集、内容交付或统计凭据；域名分流不扩大内容公开范围。

地域 DNS 依据解析链路选择线路，不能保证使用海外公共 DNS、代理或 VPN 的国内设备一定进入上海。国内故障时优先停用国内线路、回到默认新加坡，生效遵循 DNS 缓存；不是即时自动故障切换。旧的已退役网站不作为回退目标。

实施与缓存过渡的实测限制见[进度记录](../progress/2026-11-13-formal-geo-routing.md)，后续发布与配置变更仍按具体任务授权执行。
