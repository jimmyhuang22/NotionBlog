# 2026-11-23：游戏卡盒线上复看后的调整

用户在 #466 上线后看了游戏页，认为问题很多，让 Claude 改进后给本地预览；看过后让合并。部分取代 [2026-11-23-game-cases](2026-11-23-game-cases.md) 里“没有竖版封面时”一条，并补充页面上下顺序；状态位置仍按 [2026-11-23-game-case-status-badge](2026-11-23-game-case-status-badge.md)。

## 决定

- **没有竖版封面时，横图填满封面框**，从中间裁，盒子里不再写游戏名（名字在盒子下面）；只有连横图都没有时，盒子里写名字。原来“竖框里完整放横图、背后虚化、下面写名字”在线上整页都是顶替图时像一排加载占位块，名字还写了两遍。竖版封面导入后自动换成竖图。
- **页面上下顺序**：标题“游戏”，“最近在玩”，“游戏库”小标题和右边的在玩／通关／想玩，年份与排序，卡盒。筛选控件都挨着列表，不再被转盘隔开。影视、书籍不变。
- **“最近在玩”在所有状态和年份下都显示**，不随筛选出现或消失，免得按下状态时按钮跳位。
- **“最近在玩”标题只写这四个字**，不写“8 款 · 按最近一次游玩”；下面一行今年的日期不写年份。
- **Switch 与 Switch 2 算一个系列**：盒子上写了其中一个（按共用规则挑，多为 Switch 2），另一个不再写成“也在 Switch”。其他平台照常写“也在”。
