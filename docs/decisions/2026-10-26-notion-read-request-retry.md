# 2026-10-26：来源只重试失败的只读请求

用户要求离线修复来源接口偶发502导致整轮停止的问题。明确启用时，单个Notion只读请求最多尝试3次，重试前分别等待2秒和5秒；SDK重试关闭，外层分页方法不重跑。只允许已知读取端点，包括语义只读的数据源POST查询，成功的前序分页保留。

仅短暂网络错误及HTTP500／502／503／504可重试。权限、缺失、限流、异常数据、响应过大、预算拒绝及整轮取消仍停止。每次实际请求及失败响应字节继续计量，等待和后续尝试受原取消信号、来源预算和整轮截止约束，不延长租约或重置预算。

本决定规定显式启用该策略时的程序行为，不重新启动整轮、再次分配来源次数或重试写入。日常网站读取仍使用原策略；运行程序的安装、任务调整和真实执行按 [AGENTS.md](../../AGENTS.md) 的现行任务授权规则处理，不增加逐窗口重新申请的前提。
