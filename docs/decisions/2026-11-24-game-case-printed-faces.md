# 2026-11-24：游戏卡盒照实物印顶条和标志

状态：已选定，前端已接入。补充 [2026-11-23-game-cases](2026-11-23-game-cases.md) 和 [2026-11-23-game-case-status-badge](2026-11-23-game-case-status-badge.md)：卡盒比例、时长位置、取景位置不变；顶条的样子和 Switch 的状态位置按本条。

## 为什么

用户发了 PS5、PS4、Switch 2、Switch 的实物卡盒照片，要卡盒“看上去就是和官方卡带一模一样”，只把封面换成我们的。看过两轮原型后选定照实物还原；Switch 用左上角红色方块（上一轮原型的乙）。

## 决定

按照片逐像素量出边框、顶条和标志的位置与大小，换算成卡盒宽度的比例，所以大卡和手机小卡比例一致：

- **书脊一侧（左边）没有边框**，四种都是封面纸直接到边；上、右、下的边框按照片，圆角收紧。
- **PS5**：白色顶条，PS 图标加“PS5”字标。**PS4**：蓝色顶条（#0273BC），图标加“PS4”字标，下面一道白线。字标用 Simple Icons 的 PS5／PS4 图形（CC0）。
- **型号不猜**：平台写作“PlayStation 5／PS5”或“PlayStation 4／PS4”才印型号；只写“PlayStation”时是白条加 PS 图标。型号写进 Notion 现有的平台名，不加新字段，见[后端交接第二十一节](../BACKEND_HANDOFF.md#二十一playstation-游戏写明-ps4-还是-ps52026-11-24claude)。
- **Switch 2**：加高的红色顶条（约占盒宽 20%），标志居中。
- **Switch**：没有顶条，封面铺到顶，左上角是红色方块；外壳按照片是透明浅灰。
- **通关／白金在右上角**：有顶条的在顶条右端，Switch 在封面右上角。
- Steam、PC、3DS 不变，仍是原来的顶条。

卡盒上把平台图标和型号字标、NINTENDO SWITCH 字样拼在一起，是照实物这样印；首页等处的平台标签（game-tag.tsx）仍只用单个图标。

## 代价

PlayStation 左边没有边框后画面区更宽，2:3 的竖图居中时上下各裁掉约 13%，靠上／靠下取景照样起作用。Switch 左上角的方块会盖住封面那一角。
