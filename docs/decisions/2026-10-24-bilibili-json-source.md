# 2026-10-24：B 站增加独立 JSON 来源，先离线验证

用户同意新增如实标注的 JSON 接口来源并先做离线开发和测试，保留旧 SSR 兼容。当前接口可用性尚未验证，此决定不批准真实接口访问、云端迁移、运行安装、任务恢复或部署。

- 单视频新增 `public-video-api-json`，合集新增 `bilibili-collection-api-json`；不把 JSON 包装成 HTML 或冒充 SSR。原始响应摘要绑定实际 JSON 字节，缺少指标和日期保持未知。
- 新旧表示共用字段、身份、公开／付费边界及完整成员验证。合集计数、分 P、发布日期和播放关联须有同等级证据；不能把代表视频统计当作合集统计，证据不足保留待办。
- 新来源默认关闭，并以独立能力握手在来源采集前拒绝不兼容服务端。复用原受限账号、精确 ACK 和当前公开绑定，不扩大权限、公开范围或前端 DTO。
- 新 SQLite 与旧程序的状态库隔离；分类、周期、发现和待审记录也避免写入旧解码器会读取的位置。保留既有人工暂停和旧待审候选，未准备状态不自动起跑，不把新来源改名复制回旧库。
- HTTP 仅接受固定目标、固定主机、严格 TLS 和有界响应；无登录 Cookie、重定向、验证码处理、接口链式回退或来源自动重试。实际接口如要求授权或校验，保持失败并另行决定路线。
- 代码和迁移文件的合入不代表安装。真实验证仍须在完整调用图、回退、来源／数据库／缓存预算和停止条件准备完成后单独取得具体许可。

接入与回退边界见 [B 站 JSON 来源](../SOCIAL_BILIBILI_API.md)。原 [账号自动接入](2026-10-14-bilibili-account-discovery.md) 和 [合集跟随](2026-10-14-bilibili-follow-collections.md) 的范围与公开规则继续适用；本项不凭新来源授权新的账号或作品。
