# 2026-11-23：学习区使用课程编号和页面短名

学习项目入口使用原有 `/study/projects/<项目编号>`。课程用 `/study/<课程编号>`，缺少课程编号时从课程标题分配。笔记和子页用 `/study/<课程编号>/notes/<页面短名>`，目录和面包屑继续按实际课程树展示。

首次公开时登记名称。周次采用 `week-01` 这样的短名，子页可带周次和父级名称。不同课程可使用相同页短名，同课冲突时使用固定编号。改标题继续使用已登记地址，保留撤回页面已占用的名字。同一课程内调整目录层级仍使用原来的地址。页面转到另一门课程时按新的课程归属分配；原课程地址继续受归属检查。

公开资格依据课程和子页的实际父链及现有撤回规则。Notion ID 继续用于内容存储、同步和内部查找。两站使用同一份名称登记。正式切换后旧课程与笔记的 ID 网站地址直接返回 HTTP 404，站内目录、正文链接、导航、搜索、规范链接和站点地图使用新地址。
