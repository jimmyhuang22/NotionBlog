# 2026-10-21：笔记阅读页改为左目录三栏

用户看了线上笔记页（样本课程 A 样本预习笔记）后觉得浏览路径别扭、屏幕拉宽后底部不对齐、模块感太强，并提出课程目录应在左边。看过三个原型（甲：左边常驻目录、正文不套卡片；乙：左边常驻目录、保留一张纸；丙：保持专注阅读、目录从左边滑出）后选甲。本决定取代 `2026-10-19-study-focused-reading.md` 里“所有屏幕默认只显示正文、目录按需打开”的部分，其余（行宽、本页目录、祖先路径、手机上一级返回）不变。

- 1100 宽起，课程目录是正文左边的一栏（264 像素），粘在页头下、自己滚动，打开到当前这篇；右边仍是本页目录（1180 宽起）。阅读区整体随正文宽度加目录宽度居中。
- 1100 宽以下没有常驻目录：“课程目录”按钮挪到左上，面包屑或返回接在后面；目录从左边滑出，打开时页面其余部分不可操作，Esc、点遮罩或选中一篇都会关上。
- 墨水与苹果主题的正文不再装进卡片，直接写在纸上；上一篇／下一篇改为细线下的两行字，宽度停在正文右边，不再伸到本页目录下面。手帐的胶带纸与千禧的窗口是这两套主题本身的样子，保留卡片，只把上一篇／下一篇对齐到卡片宽度。
- 正文里的链接块改成一行细框：小圆标（视频是 ▶）、名称、去掉协议的地址。来源没有标题时只存了域名，这时视频网站写“YouTube 视频”“B 站视频”，其他写去掉 www 的域名；作者写了说明文字的照原样显示。全站正文共用这个样子。
- 折叠块去掉底色，标题是一行灰字，展开后内容挂在左边一条细线上。全站正文共用。
- 乙（保留一张纸）、丙（专注阅读加左侧抽屉）未选。
