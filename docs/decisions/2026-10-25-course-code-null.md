# 2026-10-25：缺失课程编号保持 null

用户看过 [B18 课程编号方案](../BACKEND_COURSE_CODE_NULL_PLAN.md)，明确同意实施源码与离线测试。Codex 负责工程与必要兼容改动。

- `Course.code` 是必需字段，值为真实属性字符串或 null。缺失、空白编号不从课程标题或页面 ID 推断；原课程标题、身份和 URL 保留。
- 两套 Notion provider、数据库 payload 校验、格式化、项目归类和必要组件兼容同时落实。无编号课程只进入已有默认收纳分组，不匹配显式编号名单、不新建分组；公开资格不变。
- [编号显示一次的决定](2026-10-13-course-code-once.md)继续适用于有实际编号的课程；无编号课程完整显示来源标题。[搜索上下文决定](2026-10-23-search-result-context.md)保持编号缺失时以课程名显示。
- 旧字符串快照继续读取，不猜测或批量清洗旧数据。未来真实安装须先更新所有读取与验收端，再启用产生 null 的同步端；网站发布不自动替换独立业务运行包。
