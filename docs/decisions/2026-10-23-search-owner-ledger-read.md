# 2026-10-23：搜索原连接器身份与登记的单次核查

用户明确批准原 Supabase 连接器的一次固定只读 SELECT，补齐[受限目录事务](2026-10-23-search-catalog-readonly-transaction.md)未读取的安装渠道身份与登记信息。此次是新的独立许可，原失败尝试和成功目录窗口均保持关闭，不追溯扩大其结果。

## 已确认范围

- 只读取会话身份、两项指定 schema owner 和迁移登记版本 1–5；最多五条登记、8 KiB 结果 JSON。
- 一个连接器调用、一条固定 SELECT、代理零重试；无 DDL、DML、角色切换、配置语句、业务行或应用函数调用。
- 连接器没有原客户端的物理连接数、TCP 字节、截止、事务只读及语句限时控制参数。用户在这些差异已披露的前提下批准本次调用；不能把连接器调用数写成物理连接数，也不能承诺内部重试行为。
- 仅接受完整、有界且身份／owner 符合预期的结果；基础摘要离线比对。版本五即使摘要匹配，也必须先辨认当前对象，不据此自动安装；异常或失败结束后不续发。
