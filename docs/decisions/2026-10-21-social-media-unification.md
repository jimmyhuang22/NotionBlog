# 2026-10-21：统一社交封面的存储和缓存（Codex）

用户明确要求完成 B 站、小红书封面的图片迁移，并修复和统一整个流程。图片原件和已有小图沿用现有私有 COS，对象迁移不改变内容数据库、页面公开范围和媒体绑定语义。读取端及后续定时上传必须一起接续；保留旧对象作为回退，不借迁移重新采集或生成已有图片。

社交封面新增绑定所有者与文件内容版本的地址：源地址换签且文件未变时，浏览器地址保持；原件或任一小图真正改变时使用新地址。此类地址采用既有的一天私有浏览器缓存政策，不启用共享 CDN 缓存或更长缓存。访问服务器的每个请求仍检查当前资格和文件版本；已下载的浏览器副本遵循既有一天缓存／撤回窗口，不能将其描述为即时收回。旧可变所有者地址继续条件验证，保留原客户端兼容。

首页与作品页只在新取得的首屏内容、游标及统计完全一致时复用已加载分页；其他列表的历史恢复行为保持。取消切换后自动读取另一平台和十张封面的重复预取。实际生产切换须在对象完整、周期入口与回退就绪、当前其他运行窗口已核对后执行，不能只改一个 provider 变量。
