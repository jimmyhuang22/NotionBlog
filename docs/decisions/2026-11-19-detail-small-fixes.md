# 2026-11-19：详情页的四个小改动

状态：已采纳。三类详情页上线核对后记下的几个小问题，用户看过线上页面上的对比后选定：

- 游戏头图：丙，头图加高（电脑 340–620，随宽度；手机 340），取景从偏上 20% 改为偏上 8%。原来像《守望先锋2》这样的图，顶部标识会被切掉一半。
- 书籍摘录：乙，超过 12 条时整块限高约一屏，下沿渐隐，下面一个“展开全部摘录（N 条）”；内容其实放得下时自动不收。没选“每部分先放 3 条”。
- 剧集的分集摘录：甲，“摘录”下全是“Episode N - 集名”或“第 N 集”的标题各配一段引用或段落时，画成一集一行的列表（第 N 集、集名、简介），标题写“分集摘录 N 集”；夹了别的内容就照原样。
- 想玩的游戏：时间线不写“游玩日期 日期未记录”；已经玩过的游戏照旧保留（补充 [2026-10-16](2026-10-16-hide-empty-experience-date.md)）。
