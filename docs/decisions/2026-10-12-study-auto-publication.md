# 2026-10-12：全部课程与拥有的后代自动公开

用户明确选择全部现有课程及每门课程的全部页面／子页面直接公开、未来新增自动公开；第一层日期为主，可用数字覆盖，子页面按父正文先后。不重复询问这些范围与排序选择。

本决定取代早期“仅一门试读课程、学习逐页允许列表、未来节点不自动继承”的当前网站规则（包括存档中 2026-10-11 已确认九及后续同义记录）。冻结 v1 和已有 allowlist 配置继续兼容。网站 v2 使用明确的 course all 与 course-descendants 来源及独立 SQL 扩展；实际云启用仍需一次另行获准的发布，不借此修改正在执行的任务。

授权沿物理所有权：直属课程、拥有的多层子页面与笔记数据库直属记录；逐层验证活动父链并保留中央 deny 的整子树撤回。不跟随链接、提及、关系、外部数据库视图或引用同步块，不改变 About 和其他普通页。数字覆盖采用“有数字优先”，缺属性／空值按未填写处理；自然标题比较数字，正文顺序用于子页。公开 DTO 不增字段，数据库使用私有 ordinal 与冻结 reader 接口。

Notion 已有视图 API，但官方文档未给出手工拖动行序的可靠契约；采用已选日期／数字规则，不把此判断说成 API 永远不支持。操作、撤回、界限与上线交付见 [学习公开说明](../STUDY_PUBLICATION.md)；个人来源与实际属性只写本机候选和记忆。
