# 2026-10-12：使用已验收部署临时提供线上真实数据

用户明确要求优先让现有线上网址读取真实内容，随后处理持续运行。平台每日部署次数耗尽、无法建立最新版 Production 构建时，用户选择让现有域名临时指向此前已验收的真实数据部署，并接受较早前端及原批次资格截止时间。

这是对此前“只在受保护 Preview 验收、暂不操作正式域名”的本阶段限制的明确补充。仅改变获准域名路由并准备既有 Production 只读配置；不把原 Preview 环境改称 Production，不开放其他部署网址、不改 DNS／收录／仓库可见性，不扩大来源范围。

旧批次仍遵守从采集开始计时的四小时资格；到期无新鲜成功批次须拒绝读取。授权不包含第三轮完整同步、自动调度或延长旧资格。普通原图与既有转换图继续沿用已验收媒体规则。

部署额度恢复后，使用最新版线上分支建立新 Production 构建，先验收再替换临时路由。持续运行、评分来源标签、托管恢复和目标地区网络验收分别保留后续边界。
