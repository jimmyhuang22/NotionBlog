# 2026-10-21：用“岛屿”主题替换手帐

用户想引入开源组件库 animal-island-ui（动物森友会风格，MIT）做主题。评估后定下：**不引入组件库代码**（它是一套 React 组件和全站样式，引入会改掉四套主题共用的组件与已定方案，还会给所有访客加载中文网字），只借用它公开的设计语言，在现有主题机制里做一套新主题“岛屿”，替换 2026-10-19 加入的手帐。墨水、苹果、千禧与所有页面结构、交互不变。

用户看了四个首页原型后选定：白天用 **B“岛民手机”**——沙色斜条纹、薄荷色应用栏、当前栏目是黄色胶囊、动态卡片像对话气泡、按钮带实心“台阶”阴影按下会下沉；夜间用 **①**——夜蓝斜条纹、深青色应用栏，其余与白天同形。

落实时的取舍：
- 白天应用栏上的白字在亮薄荷上对比度只有约 2.3，改为深棕字（约 6.5）；夜间深青栏保留白字（约 7）。正文链接用加深的薄荷（`#08706A`），亮薄荷只用在栏与装饰上。
- 字体：西文用 Nunito（`next/font`，不预加载，只有岛屿主题下才下载，约一个文件），中文沿用系统字体。
- 不使用游戏的名称、图片或素材；主题名叫“岛屿”。
- 之前选了手帐的访客自动来到岛屿，原来记住的浅色／深色不变。
- 切换到岛屿的动效：新样子从按钮处圆形弹开，略过头再回落。
