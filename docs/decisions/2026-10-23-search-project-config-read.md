# 2026-10-23：固定项目设置只读窗口

用户另行明确批准一次固定项目的只读窗口，补充[结构／权限元数据读取](2026-10-23-search-trigger-inventory-read.md)，不复用其已关闭许可。

原 Vercel 连接器最多八次工具调用：一次显式请求不解密的项目变量名单，只有名单完整、有界、无歧义且符合类型与目标要求后，才按 ID 读取七个指定非凭据键，最多七次。名单不能按这七个键或 production 服务端过滤，可能收到其他变量的元数据、密文或普通值；客户端筛选不等于服务端只返回白名单，已废弃的解密参数也不是绝对明文保护。上述限制已在具体确认问题中披露。

代理零重试；Secret、歧义、漂移、超限、工具错误或未知结果立即关闭整个窗口。名单最多 64 KiB／256 行，单项最多 8 KiB，累计可验收 JSON 最多 128 KiB，过滤保存最多 16 KiB。批准入账后十分钟内启动，启动六十秒后不再提交新调用；连接器不能强制在途取消、物理连接／TCP 接收或内部服务重试。JSON 上限不是网络传输上限。

所有结果只私存，原始名单、无关字段及未知值不展示或落盘，字段只接受受检源码中的非凭据枚举；名单缺项继续未知，不推断未设置或排除继承来源。结果只代表项目接口设置快照，不证明当前运行实例、四项构造参数或回退完成。该范围不包括实际配置写入、SQL、安装、任务恢复、启用、共享合并、公开实测元数据或部署。

具体目标、工具参数、授权／消费回执与过滤器散列留在忽略的私人材料。实际执行与闭窗结果见[本轮记录](../progress/2026-10-23-search-runtime-beforeimage-plan.md)。
