# 2026-10-20：迁移前补齐开发出站保护

用户明确批准四项保护：普通开发／测试／构建使用本机数据和 SSD 素材，Preview 默认隔离，真实云端联调采用固定样本与有限预算，离线验证通过后才考虑迁移。补充 2026-10-19 仅开发服务器默认隔离的决定。

开发、测试和本机构建以 mock／fixtures 与隔离 PGlite 为默认，不自动复制或刷新完整个人生产数据库。Node 子进程在 dotenv 前清理继承环境并阻断外部连接；Next 在 dotenv 后及新实例启动时复核。浏览器通过 CSP 限制本站图片、媒体和接口。正式 Vercel Production 明确识别，保持现有业务语义；Preview 和自定义环境不继承生产读取行为。

真实联调保留独立受限 reader、TLS／RLS 和错误语义，新增必须提供的固定计划。本机网关限制样本路径与请求次数，父进程统一计量所有 Node 工作进程的远端传输字节及连接，触限或到期停止本会话，不自动重试。该限制不是全账号的精确账单硬上限，不管理其他客户端、旧部署或正常业务任务。

本项授权开发与验证，不自动迁移、更换账户、发布 main、部署 Preview、提取云端秘密或重开生产同步。具体说明见 [开发隔离](../DEVELOPMENT_ISOLATION.md)。
