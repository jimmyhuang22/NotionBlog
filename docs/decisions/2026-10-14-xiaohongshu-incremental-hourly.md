# 2026-10-14：小红书账号增量发现与小时统计

用户要求新笔记自动发现，并明确选择“新笔记发现和已有统计都每小时”。此决定取代本账号启用后的二十四小时统计周期；原共享配置和未启用账号模式仍保持旧默认，B 站六小时周期不变。

- 新笔记发现读取本人公开投稿目录的新一段，按稳定 ID 去重；整页末尾至少五个已知 ID 才能作为边界，不能见到一个置顶旧作品就停止。不把缺项解释为删除。
- 统计独立按真实 `observedAt + 1h` 到期，每十五分钟本地检查。没有平台统计变更通知时，目录未新增不能证明旧作品的数字未变；不声称减少了全部详情请求。
- 已有可读分享地址继续走一次有界 HTTP 会话；新作品首次确认和匿名读取不完整的少数作品采用现有 Chrome 的实际渲染投影。浏览器来源与 HTTP 来源分别记录，不读 Cookie、签名接口或评论正文。
- 账号授权默认关闭；限定同一账号的公开投稿、稳定作品键和类型，受限云端函数仅能处理该范围。旧绑定禁用、作品撤回或人工关联不会被重发现重新批准。
- 跳转地址是待验证候选，必须实际读取并确认笔记及作者后才登记真实核对时间，不把格式转换或目录检查当作访问成功。沿用已有网站接受的链接格式，无须为此修改页面或部署。
- 本机冻结运行包与开发检出分开。实际云端安装、运行切换和有界样本验收另行执行；不复采全量做测试，不重复启动 CI。
