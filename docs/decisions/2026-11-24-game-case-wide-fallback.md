# 2026-11-24：没有竖版封面时整张横图居中、上下虚化

状态：已选定，作为补齐竖图前的过渡。取代 [2026-11-23-game-cases-live-polish](2026-11-23-game-cases-live-polish.md) 里“没有竖版封面时，横图填满封面框，从中间裁”一条。

## 为什么

#486 上线后，用户看游戏页发现很多封面“要么左边缺要么右边缺”。原因是没有竖版封面的游戏只能把 16:9 的横版宣传图塞进竖着的卡盒，从中间裁满，Switch 盒切掉宽度的约 65%，PlayStation 约 45%。线上 317 款里有 133 款没有竖图（Switch 59、PlayStation 40、Switch 2 7、3DS 6、PC 5、Steam 16），“通关”页 30 款里有 18 款。

用户在四种放法的本地原型里选了丙。其余三种：现在的裁满；整张贴在顶条下、下面虚化；放大到左右各切约 20%。

## 决定

- 没有竖版封面（或竖图读取失败）时，整张横图按封面框的宽度放在中间，封面框其余部分用同一张图放大、虚化、压暗铺满。两张用的是同一个地址，只下载一次。
- 盒子里不写游戏名，名字在盒子下面；只有连横图都没有时才在盒子里写名字。和 11-23 第一次试这种放法时不同，那时盒子里还写名字，用户认为像一排占位图。
- 有竖图的游戏不变。顶条、Switch 方块、通关／白金和时长的位置不变。
- 这是过渡做法。用户会让 Codex 继续找竖图，补上一款，那一款就自动换成竖图。
