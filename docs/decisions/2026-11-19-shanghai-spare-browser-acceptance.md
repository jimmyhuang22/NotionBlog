# 2026-11-19：上海站优先从备用机做浏览器验收
状态：日常验收分工已由[2026-11-22 决定](2026-11-22-shanghai-single-database-and-mac-recovery.md)取代。备用机演练需要浏览器时，单次授权和独立清理要求继续适用。

用户确认将 #390 跑通的流程作为后续约定。上海站需要浏览器验收时，优先在上海备用机本机通过腾讯云自动化助手运行浏览器和验收程序。用正常公网 DNS、有效 TLS、实际建连对端和当次 BUILD_ID 确认命中上海正式站。

需要临时 AppArmor 规则时，每次验收都单独取得用户的明确授权。规则只匹配经校验且由 root 持有的本次 Chrome 可执行文件，浏览器使用普通用户并保留沙箱。作业结束或中断后，清理本次规则、浏览器进程与临时目录，再启动独立只读作业复核清理结果。交接同时记录浏览器验收与清理作业的结果。

此决定补充[按改动范围验收的约定](2026-11-14-deployment-validation-scope.md)。适用范围及操作顺序见[上海站浏览器验收](../PRODUCTION_DEPLOYMENT.md#上海站浏览器验收)。
