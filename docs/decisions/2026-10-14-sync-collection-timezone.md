# 2026-10-14：完整与增量同步绑定站点采集时区

用户转交独立验收发现的跨日、跨年截断问题，要求修复完整和增量采集的时区传递后再启用新映射。本项补充[游戏日期规则](2026-10-14-game-played-date-policy.md)，不改变该规则或公开范围。

来源配置新增可选 `timeZone`，接受有效 IANA 时区并纳入来源文件哈希与规范化配置摘要。实际候选从受保护站点配置复制时区；模板不硬编码个人地点。完整 worker、固定完整 host、增量 host 与单页转换器使用同一绑定值，有平台日期映射却未明确配置时区时，在分配资源前报配置错误。无平台映射的旧配置不补隐式字段，原摘要保持兼容。

平台时刻按此时区截为日后存储，人工日期范围及本来纯日期的值不偏移。时区变化使增量预期摘要失配，须重建对应的完整基线与运行绑定，不能混用旧政策／工件或手工修正旧截断值。新映射启用前重新冻结源码、来源输入及匹配的网站构建；本项实现不自动执行完整同步、媒体上传或线上切换。
