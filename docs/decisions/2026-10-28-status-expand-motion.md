# 2026-10-28：动态展开和收起只做高度过渡

用户 2026-10-28 看过展开／收起动效原型后选“建议”一列（“按建议的来”），Claude 落实。来源是用户的截图反馈：首页时间线里展开和收起没有动效，动态页里的又太浮夸。

- 首页时间线和动态页统一成同一个动效：点按“展开”或“收起”时，卡片从原来的高度平滑变到新的高度；短动态展开时卡片从贴合文字变成整栏，宽度一起变。展开 260 毫秒，收起 220 毫秒，曲线 `cubic-bezier(0.2, 0, 0, 1)`。
- 文字不变淡，不拉帷幕；进入页面时任何卡片都不动，只在点按时动。
- 首次展开要等正文读回来，“正在加载…”期间卡片保持原样，内容到了才过渡；读取失败不过渡。
- 收起时立刻换回折叠的内容，卡片从展开的高度收到折叠的高度；如果这条的开头已经在页头上方，滚回开头和收缩同时开始，滚动目标按收起后的位置算。
- 折叠时九行处的渐隐遮罩随内容一起换掉，不另加淡入淡出。
- 过渡中再点按，先结束上一段再开始新的，不排队。
- 访客偏好减少动态效果时直接切换、直接定位。
- 卡片的阴影、岛屿的气泡尖角和左边线、千禧的窗口边框在过渡中都不能被裁掉。

取代 [2026-10-20 设计自检第五批](2026-10-20-design-review-batch-five.md) 第十八项（收起，甲）里“卡片先往上卷回约 0.25 秒，再换回短卡片”这一半；同一项里“开头在页头上方时平滑滚回开头”和“减少动态效果时直接收起、直接定位”仍然有效。
