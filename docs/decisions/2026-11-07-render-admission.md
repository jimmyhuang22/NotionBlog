# 2026-11-07：浏览器渲染统一入口与准入

用户确认按交接方案实现浏览器代码／公式渲染的同源 POST 路由，并删除旧 Server Action 入口。浏览器的现有合并队列统一调用该路由。

公开输入先经过实例速率、并发和请求体预算，再进入既有解析与渲染。仅经已核验代理传递的地址用于访客计数，其他环境保留实例限制；各实例的内存计数独立于搜索。具体限额随真实批量请求表现校准。

限流使用既有 503／RATE_LIMITED 约定并返回 Retry-After。浏览器将拒绝视为失败，保留原文，下次需要时可重新请求，不自动重试。成功但无法渲染的单项仍沿用省略结果和原文降级。

本决定补充既有输入上限与渲染安全规则。接口与验收见[实施记录](../progress/2026-11-07-render-rate-limit.md)。
