# 2026-11-22：首页游戏标签带平台图标（F60）

状态：已采纳。补充 [2026-11-19 首页在玩的游戏](2026-11-19-home-game-frames.md)的丙一标签。用户想在“在 Steam 上玩”里看到平台图标，并且整体更和谐；看过三种原型（甲：图标放进标签、和字同色；乙：带厂商色小方块；丙：平台改成封面角标）后选甲。

## 决定

- 标签写法不变，只在认得的平台名前加一个单色图标：“在 [图标] Steam 上玩”“在 [图标] Steam、[图标] PlayStation 上玩”；没有平台记录仍写“在玩”。
- 图标约 13 像素、填文字颜色，不加底色、不用品牌色，四套外观、浅色深色都跟着标签走；图标和名字之间 4 像素，“、”前留一点空。
- 对应：Steam、PlayStation（含 PS4、PS5）、Nintendo Switch、Nintendo 3DS 用 Simple Icons（CC0）原样的图形；PC 是普通显示器，不用 Windows 标志。图形直接写进组件，不装依赖。
- Switch 2 没有现成图标，和 Switch 共用一个图标，不另画“2”：名字里已经写了 2，13 像素里的小数字只会发虚，也免得画成像官方标志的样子。`platformChip` 认出“Nintendo Switch 2”，简写成“Switch 2”（游戏卡和详情的平台块也跟着变短，颜色同 Switch）。
- 认不出的平台（如 Xbox）只写名字，不留空位；以后有合适的单色图标再补。
- 图标对读屏隐藏，读出来仍是“在 Steam 上玩”。
- 标签放不下时整体换到下一行；比整行还宽时才在平台之间断开，图标和名字始终在一起。
- 只改首页时间线游戏这一行；游戏卡、游戏详情上的厂商色平台块不变，以后要不要带图标另议。写哪些平台（最近一次游玩记录的平台）由 F59 另定，样子不用再改。
