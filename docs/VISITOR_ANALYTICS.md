# 访客分析

访客分析为可选服务。默认关闭，只在显式配置的自托管公开网站运行；演示、构建、CI、受保护预览均不采集。分析库与内容数据库、同步快照及网站 reader 分开维护。

## 数据与展示

同一网站使用一个 Umami Website ID，各部署配置不同 `node` 标签。地域由可信客户端地址推断，节点表示提供页面的部署，两者不能混用。分区 UV 不能直接相加作为全站去重人数。

第一阶段仅采集客户端已经导航到的页面路径、来源域名／站内前一页、语言和节点。浏览器型号及粗略地域由 Umami 根据 User-Agent 和可信 IP 推断。不会发送页面标题、正文、URL 查询参数、hash、搜索词、表单、登录身份或浏览器 Cookie。不启用回放、热图、错误内容采集和自动点击。

独立后台使用 Umami 登录，管理密钥不进入网站客户端。个人工作台先添加后台链接，后续如需摘要，只通过受限身份调用 API，不直接读取分析数据库。公开 Share URL 默认关闭。登录后台与公众事件入口分别管理。

## 运行配置

在已有受保护的公开网站配置中增加 `SITE_ANALYTICS_JSON`，值为 JSON 字符串，严格接受以下字段：

| 字段 | 用途 |
| --- | --- |
| `websiteId` | Umami 中已创建的网站 UUID |
| `hostname` | 统一统计的规范主机名，不含协议或端口 |
| `origins` | 允许采集的实际 HTTPS Origin 数组，最多 8 个；不包含管理预览 |
| `node` | 当前页面服务节点标签，小写字母、数字及连字符，最多 32 字符 |
| `endpoint` | 固定网关地址，以 `/collect` 结尾；使用 HTTPS，或本机 `http://127.0.0.1` |
| `secret` | 64 位随机十六进制网关口令，仅服务端保管 |
| `clientIpHeader` | `x-real-ip` 或 `cf-connecting-ip`；入口必须覆盖该字段并阻止绕过可信代理 |

这些字段不能放入 `NEXT_PUBLIC_*`、编译常量、公开配置或代码仓库。凭据、网站 UUID、真实主机与运维路径只写私人安装记录。清除该字段并按正常方式重启即可停用采集；旧客户端仍可能发请求，但服务端立即返回 404。

网站的 `/api/visitor-analytics` 接收同源 JSON POST。Origin 必须匹配允许名单，Fetch Metadata 若存在必须为 same-origin；地址必须来自配置的单一可信头，不推测任意 X-Forwarded-For 链。Origin 校验约束浏览器来源，不是能抵御非浏览器伪造的身份认证。代理配置是信任边界的一部分。

## 网关与 Umami

[独立网关](../deploy/analytics/gateway.mjs)监听回环端口，使用 `ANALYTICS_RELAY_SECRET`，可设置 `PORT`（默认 3106）及 `UMAMI_PORT`（默认 3105）。Umami 只监听回环；配置 `CLIENT_IP_HEADER=x-analytics-client-ip`。外部 HTTPS 入口只能到网关，不能绕过网关访问 Umami 的原始 `/api/send`。

`/collect` 只接受持有共享口令的站点服务端请求，转发前剥离 Cookie、认证和不可信地域头；原始采集路径对外返回 404。其他路径转发到正常 Umami 登录与后台。网关不打印访问日志；宿主与前置代理也应避免记录事件内容、IP 和认证头。

本次对接核对官方 Umami v3.5.0（`d3c62a805beda8643cb468924dda38617fb4c286`）的 `/api/send` 协议：发送 `type=event`、固定网站及节点，透传签名的 `x-umami-cache`，只向浏览器返回该缓存，不返回会话资料。升级后复核该协议、代理、认证和备份恢复，不使用浮动 `latest` 自动升级。

页面路径提交为尽力而为，发生网络故障不重试，避免结果不明时重复记数。每个进程有独立速率、并发与内存限制；不是跨实例总配额。请求最多 8 KiB、上游结果最多 8 KiB、整个网站转发期限 3 秒，故障不阻塞浏览。浏览器 DNT、GPC 或 `localStorage['umami.disabled']` 为真时不采集，浏览器拦截和关闭脚本仍会漏记。

## 验证与维护

上线前验证实际入口客户端 IP、两端标签、首屏及前进／后退各一次、预取及查询参数变化不新增 PV；演示和管理预览没有事件。上游暂停时页面仍正常，API 返回不可用，Dashboard 不把缺失数据显示成零访问。

分析存放地域、告知方式、数据保留与备份需按用户批准落实。无 Cookie 不能自动推导为无需告知或不存在跨境处理；统计 IP 在服务端处理，不代表基础设施没有日志。当前实现没有新增保留清理或备份调度，不能宣称已按建议期限自动清理。
